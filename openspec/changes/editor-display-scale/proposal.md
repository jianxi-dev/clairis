# Proposal: 菜单尺度放大一档 + 空大纲不显示入口

## Why

用户 2026-11-03 走查：块手柄弹出的转菜单「文字和图标都小，得调大一号；菜单窗口也有点小」；另外「无大纲时不要显示大纲按钮」——点开是「无标题」的按钮只是噪声。

菜单尺度在 E-7 里是写死的契约（236 / 行高 32），改数值属于规格变更，走本 change。

## What Changes

1. 块菜单宽度 236 → 264，行高 32 → 36，菜单字号 13 → 14，分组标签 11 → 12。
2. 菜单图标 18 → 20（`ICON_SIZE_PX`，与手柄、斜杠菜单共用同一尺寸来源）。
3. 网格单元高 56 → 62、标签 12 → 13，内边距同步。
4. 大纲入口：文档没有 ATX 标题时不渲染按钮。

## Capabilities

### Modified Capabilities

- `editing`：E-7 的尺度数值；E-10 的入口可见条件。

## Impact

`block-menu.ts`（宽/行高常量）、`icons.ts`（图标尺寸）、`editor.css`、`e2e/fixtures/editor-anchors.ts`；无 Rust 改动。
