# Design: 第二批真机走查（ui-polish-batch15）

## 1. 决策

### D1 视频连播与旋转适配

播放结束（`ended`）驱动播放列表前进，列表末尾按循环策略处理；旋转按视频元数据（mp4 rotation）在渲染层施加 `transform: rotate`，容器用 `object-fit: contain` + 可用尺寸适配，避免竖拍视频横躺。

### D2 轮盘召唤改为显式触发

取消「选中文字即弹轮盘」。保留点击圆心/手柄等显式入口，并新增全局快捷键开关（可配置、可关闭）。快捷键只在编辑态生效，不抢输入框按键。

### D3 轮盘形态可配 + 双击切换

新增「默认形态」配置：`core`（只显示圆心）/ `full`（整个轮盘）。双击圆心在同一位置切换两态，并把本次选择写回配置（下次打开沿用）。

### D4 轮盘位置可拖动

鼠标中键按下拖动轮盘，落点持久化到配置；越界时夹到窗口可视区。位置只影响轮盘，不影响选区工具条。

### D5 轮盘搜索

搜索入口为轮盘内快捷键（Ctrl/Cmd+F）。过滤数据来自动作注册表：按一/二级动作名称匹配，命中后只展示该动作及其可执行子动作；不展示层级名，不重复；结果最多 9 行，超出滚动；第一行默认选中；右侧快捷键列独立于滚动容器（列宽固定、纵向同步滚动）。

快捷键标注：第一行显示回车图标，其后依次 `cmd/ctrl+2`…`cmd/ctrl+9`（按当前平台显示修饰键）。

### D6 提示时长可配置

新增配置字段（秒，允许 1 位小数，范围 0.1–10）。前后端 schema、校验、桥接、消费、快照回滚按数据面六栏落地；格式化统一一位小数。

### D7 块对齐标记在编辑态隐藏

沿用现有 `::: {.align-*}` 作者语法；编辑态用装饰隐藏围栏行，源码态保留。不新增第二套语法，不改预览渲染。

### D8 音视频静音按文件隔离

静音状态挂在页签（文件）维度，页签喇叭只改自己的实例；多个媒体同时存在时互不影响。

### D9 音频静音立即停止与同目录列表

静音必须在一次事件内暂停播放器（`pause()` + `muted` 同步），SHALL NOT 保留约 1 秒的声音残留；现有「静音后仍响约 1 秒」是缺陷（用户 2026-11-11 更正），不是期望的淡出。播放列表按文档同级目录扫描音频扩展名，排序稳定（文件名自然序）。

### D10 PDF 按钮栏固定显隐

按钮栏支持「固定显示 / 固定隐藏」两态，快捷键与开关同源；状态只影响当前 PDF 视图，不写文档。

### D11 顶栏重构

移除顶部产品名与窗口按钮区。窗口按钮按「左栏是否钉住」落点：

- 未钉住 → 落在左侧栏目页签栏；第一个页签的内容起点相应右移，避免被按钮压住。
- 钉住 → 落在左边栏；第一个页签回到左缘原位。

左栏的「阅读空间」标题移除，保留图标与列表。

### D12 轮盘历史与颜色二级

历史分组在复制与前进之间插入剪切；颜色二级面板给透明项加棋盘格底与描边，字色/底色标签提高对比。

### D13 栏目更多操作菜单边界适配

菜单定位按视口右/下边界翻转：空间不足时向左/向上展开，保证完整可见；窗口缩放后重新计算。

## 3. 风险

- **快捷键冲突**：轮盘开关与搜索快捷键可能撞现有键位；落地前跑快捷键注册表冲突检查，冲突时报错而不是静默覆盖。
- **视频旋转**：不同容器（mp4/webm）旋转元数据来源不同；拿不到时保持原样，不猜。
- **顶栏落点**：两种左栏状态下的首个页签对齐是像素级；必须用计算几何断言，不靠肉眼。
- **音频停止**：必须确认静音后无残余缓冲继续出声；若个别格式仍有一段尾音，定位到播放器/解码层而不是加淡出掩盖。
