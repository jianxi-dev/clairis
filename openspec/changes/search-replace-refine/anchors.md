# 验收锚点 — search-replace-refine

锚点来源：#1114（搜索替换 1118 修正，10 项问题与 8 项方案）、现有实现观察（`SearchReplacePanel.tsx` 行尾 `enterKey` svg、搜索框清除、悬停只随替换态复位、⌘N 仅 `setSelected`、拖拽高度跨会话记忆）、主规格 `search-replace-float` S-3 / S-4、`design.md` D1–D8。R-1…R-5 对应 tasks.md 1.1–5.1。

断言值取自 #1114 明示形态（`↵`、`|` 数为 0、⌘1~⌘9）、设计系统条款（§7 控件密度、§4 字阶）与 token 名（`--sf-ctrl-height`）；不引入未定义像素值，密度具体数值以 design-system §7 定档为唯一来源。
