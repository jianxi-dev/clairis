# Proposal: 第十三批真机走查（ui-polish-batch13）

## Why

用户 2026-11-10 第十三次走查提出 14 条问题。其中 5 条是前一批交付的**回归或方向反转**（编辑态装饰丢失、视频恢复自动播放、HTML 缩略图恢复真实渲染、PDF 工具栏改显式切换、提示在弹窗期间仍出现），4 条是既有缺陷（高亮块图标不跟随、撤销需先聚焦、行宽上限不一致、轮盘格式刷无效），5 条是新增能力（胶囊选区工具条、页签栏空白双击新建、PDF 双击收放、悬浮小窗编辑、轮盘三级联动）。

不做会怎样：分栏/整屏后 md 编辑态退化为源码、视频打开是黑屏加载态、阅读空间 HTML 卡片没有画面、PDF 工具栏抢正文高度且无法固定、长文里想给选区加格式必须离开指针去够轮盘。

## What Changes

1. **编辑态装饰重建**：EditorView 被重建（分栏/移动/全屏/布局恢复）后，编辑态仍渲染富文本，不再退化成源码。
2. **轮盘视觉与三级联动**：颜色扇区换水滴图标；三层展开时轮盘本体透明度 25%；三层默认高亮中心格，指针沿二层滑动时三层高亮同向跟随；提示回滚为仅圆心操作说明。
3. **格式刷与胶囊工具条**：格式刷可刷行内样式与字色/背景色，取格式后目标选区一次到位；MD 编辑态选区支持胶囊工具条（两行按钮，常用动作居中贴近指针），设置中可切换「轮盘 / 胶囊」。
4. **高亮块**：emoji 覆盖与类型绑定，转换为其他高亮类型后跟随新类型默认图标；图标与标题之间不再留空档。
5. **撤销/重做快捷键**：⌘Z / ⌘⇧Z（含 Ctrl）在编辑态无需先点击正文即可作用。
6. **文案与上限**：栏目菜单「打开所在文件夹」→「打开文件位置」；状态栏宽度提示去掉「（点击调整）」；设置行宽滑块最大值与状态栏统一为 1400。
7. **页签栏**：双击空白处新建 MD 页签；任一弹窗/菜单打开期间不再出现悬停胶囊提示。
8. **视频**：打开即自动播放；去掉「加载中→点击播放」的中间态；多路播放互不影响声音；时间戳笔记换笔写图标。
9. **阅读空间**：HTML 卡片恢复真实缩略图（iframe 受控渲染，失败回退占位）。
10. **PDF**：默认显示工具栏；双击工具栏收起、再双击固定；收起后指针从顶部滑入以悬浮栏显示，正文滑入不触发；取消沉浸态自动收起。
11. **悬浮小窗**：md/html/文本小窗在钉住右侧增加预览/编辑切换，编辑态可直接改并保存。

## Capabilities

### Modified Capabilities

- `editing`：编辑态装饰生命周期、轮盘视觉与三级联动、格式刷、胶囊工具条与设置开关、高亮块图标与间距、撤销快捷键、弹窗期间提示抑制。
- `reading`：视频自动播放与多路独立、HTML 卡片缩略图、PDF 工具栏交互、悬浮小窗编辑。
- `application-shell`：状态栏宽度提示与上限、页签栏空白双击新建。
- `file-management`：栏目菜单文案（打开文件位置）。

## Impact

- 前端：`src/editors/**`、`src/components/**`、`src/styles/**`、`src/lib/**`、`src/ui/icons.ts`、`src/types/index.ts`。
- 配置：新增 `selectionToolbar?: "roulette" | "capsule"`（缺省 `roulette`，向后兼容）。
- 后端：无新增 Rust 命令；悬浮小窗保存复用既有 `write_text_file` / `save_file` 能力（实现时按现有命令选定）。
- 无数据迁移、无 schema 变更；回滚 = revert 对应 PR。

## Non-goals

- 不重画整套图标，只为「颜色」新增水滴字形、为「时间戳笔记」换笔写字形。
- 不引入新的设计刻度；胶囊复用既有半径/间距 token。
- 不改选区轮盘的几何常量与扇区语义。
- 不做 PDF 缩放/批注能力变更。
