# 验收锚点 — document-properties-inline

锚点来源：#1127（文档属性 1118：选择模型、托管日期只读、AB 形态切换）、现有实现观察（`DocPropertyBar.tsx` 的 `allSelectableSelected ? "反选" : "全选"`、标签行不可选、`isManagedDateKey` 行级只读但无展示位、`setVariant` 无按钮调用、variant 未持久化）、主规格 `doc-property-panel` P-2 / P-4、`design.md` D1–D4。R-1…R-2 对应 tasks.md 1.1–2.1。

断言值取自 #1127 明示形态（「全选 / 反选」、A 底部 / B 备注行右、窄窗 <720px）、设计系统条款（§2.3 AB 图标、§7 密度）与偏好符号（`docPropertyVariant`）；不引入未定义像素值，视觉数值以 design-system 条款为唯一来源。

## R-1 选择模型：字段名 + 标签，反选反转

| id | kind | claim | assert | source |
|---|---|---|---|---|
| A-1.1 | exact | 面板 0 个选中时「全选 / 反选」按钮文案 | "全选" | #1127 方案 1（0 个选中显示全选）/ D1 |
| A-1.2 | exact | 面板选中 1 个字段名时按钮文案 | "反选" | #1127 方案 1（≥1 个选中显示反选，不需全部选满）/ D1 |
| A-1.3 | state-machine | 选中部分后点「反选」→ 选择集状态 | 选择集 → 原集合补集（已选取消、未选选上） | #1127 方案 1（反选 = 反转选择集）/ D1 |
| A-1.4 | state-machine | 标签行参与选择：点击标签行 → 选中状态，反选时标签反转 | 标签行 → 选中；反选 → 标签取消 | #1127 用户故事 3 / D1 |
| A-1.5 | exact | 选中某字段时选中高亮落点 | 高亮落在字段名节点，值文本节点选中高亮数 = 0 | #1127 用户故事 4（值不进入选中）/ D1 |
