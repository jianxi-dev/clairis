# 验收锚点 — random-text-variety

锚点来源：上轮随机改色落地后用户反馈（随机时字色几乎不变，浅色主题总选默认文字，字体色板不动），PR #1720 修复。R-1 对应 E-48 修订；R-2 对应 E-56 修订。

## R-1 E-48 随机文字每次变化

| id | kind | claim | assert | source |
|---|---|---|---|---|
| A-1.1 | state-machine | 随机文字色只从彩色字体板选且排除当前 | 点击纯高亮面板「随机」后 `text` ≠ 当前文字色，且取自彩色字体板；按 ≥4.5 异相 → ≥4.5 → ≥3 异相 → ≥3 分级回落，均不可行时保持当前文字色，一次 ⌘Z 同时还原三项 | PR #1720 / 截图 |

## R-2 E-56 标注随机同规则

| id | kind | claim | assert | source |
|---|---|---|---|---|
| A-2.1 | state-machine | 标注随机文字色按叠底实际底色分级选色 | 点击标注面板「随机」后 `text` ≠ 当前文字色，按 10% 叠底后实际底色以 ≥4.5 异相 → ≥4.5 → ≥3 异相 → ≥3 分级选出，≥3 为下限，均不可行时保持当前文字色，面板保持打开，一次撤销同时还原三项 | PR #1720 / 截图 |
