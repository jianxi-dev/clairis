# Proposal — table-editing-polish（MD 编辑态表格与斜杠菜单交互改进）

> Spec issue: #738 ｜ requirements: docs/requirements/table-editing-polish/requirements.md

## Why

MD 编辑态正文表格是高频编辑入口，但当前交互在四处与预期不符：手柄图标不统一且钉在角落、表头也出手柄、手柄/弹出菜单被容器裁剪显示不全、行/列插入缺少外部指示点。更严重的是单元格内 "/" 菜单实际不可用（焦点被抢走后 "/" 累积在表外、插入落表外），分栏与高亮块内容区又完全没有统一插入能力——「能输入内容的地方都支持 + 手柄与 / 菜单」这一统一编辑心智未达成。

## What Changes

- 单元格手柄统一：统一表格图标（不再按空/非空切换两套）、上下居中贴单元格左边框线、表头不显示、圆角由 6px 调小。
- 行/列插入交互重做：滑入表格在上边框外/左边框外显示圆点，悬停变"+"，点击展开插入/删除（沿用现有 splice 语义）。
- 弹出菜单裁剪修复：上下文菜单定位改用触发控件 DOM rect，修复夹取基准与注释不一致，贴边翻转/夹取保证完整可见。
- 斜杠菜单统一「内容输入上下文」：表格单元格、分栏内容区、高亮块内容区的原生输入控件接入同一菜单组件与命令注册表；打开菜单后焦点保持在原控件、过滤词来自该控件、插入落点在触发位置。
- 单元格菜单命令从「仅 2 个行内命令」扩展为按上下文提供的命令安全集。
- 高亮块内容区由独立片段菜单改接统一斜杠注册表（片段能力保留为命令），并增加"+"手柄；分栏内容区同样增加"/"菜单与"+"手柄。
- 清理死代码（表格尾块定位、全角斜杠请求函数）与错误注释。

## Capabilities

### New Capabilities

（无——全部为既有能力的 requirement 修改与细化，不新增能力域。）

### Modified Capabilities

- `editing`: E-6「斜杠插入」扩展为覆盖内容输入上下文（表格单元格/分栏/高亮块内触发、焦点保持、插入落点、无残留）；E-6「表格单元格编辑」补充手柄统一/居中/表头不显示/圆角；E-7「编排层交互契约」补充行/列插入圆点交互与上下文菜单命令集；E-14「浮层定位」补充触发控件 rect 定位与裁剪修复。

## Impact

- 代码：`src/editors/decorations/table.ts`（手柄/边界/单元格菜单接线）、`columns.ts`、`callout.ts`（内容区接入）、`src/editors/slash.ts`（触发上下文/定位）、`src/editors/orchestration/placement.ts`、`src/styles/editor.css`（新增/调整 cm-* 类，须同步 manifest）、`src/editors/icons.ts`（沿用，不改数据）。
- 测试：`e2e/table-decorations.spec.ts` 扩展、新增容器上下文 e2e；`src/__tests__/editor/` 相关单测同步。
- 无后端/Rust 改动；无配置数据面变更；无新依赖。
