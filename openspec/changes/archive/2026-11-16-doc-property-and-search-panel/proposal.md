# 变更提案：文档属性面板与字面搜索/替换浮窗

## Why

md 顶端的 frontmatter 目前是「看不见的元数据」：预览渲染直接剥离，用户查看与编辑属性必须切到源码态手写 YAML，门槛高且易写错格式；字面搜索/替换依赖 CodeMirror 6 内置面板，结果无上下文预览、无快捷键直达，替换确认成本高。维护者已通过 13 轮原型迭代（`docs/design/explorations/frontmatter-search/prototype.html`）与定稿方案（`PLAN.md`）收敛全部交互形态，本期落地。

## What Changes

**功能一：frontmatter 属性面板（新）**
- 在编辑器/预览页签内容区顶部新增文档属性面板，三种模式：预览态只读、编辑态默认展开可折叠、源码态不渲染（保持原始 YAML）。
- 显示样式两态可配：**A 一行条 / B 精排双列**，设置浮层切换。
- 预览/编辑分别可设默认「展开 / 折叠 / 隐藏」；新建文档默认显隐为全局设置。
- 字段类型八类（文本/数字/日期/日期时间/下拉/复选/布尔/列表-[[]]文档链接），类型选择器 = 字段名前纯图标 + 图标文字菜单，值编辑器按类型智能渲染；数字千分位显示（仅显示层）。
- 字段行操作：全选（不含标题/标签位）、行手柄多选、图标操作条（复制/剪切/粘贴到所选行下/上移/下移/删除/取消）、拖拽单行与整块排序、粘贴键名去重。
- **选择模式**：有选中项时行内一切点击 = 选中/取消，A/B 统一（含标题与标签行）。
- 标签：彩色胶囊（稳定哈希配色，不可手工改色）、增删改名、输入建议（从已有标签选，↑↓/⏎/⌘1~9）。
- 字段名可改名（即 YAML 键，显示 = 输入原样）；别称表仅做类型识别（外部键如 createdate 自动识别为日期类型）。
- 新建文档默认仅 标题 + 创建/修改日期（自动托管只读，⌘⇧Y 显隐切换）。
- 属性模板：应用级配置，套用 = 只合并缺失键、单事务可撤销。
- 外部未识别字段以「?」类型显示，点类型图标收编。

**功能二：字面搜索/替换浮窗（新，替换 CM6 内置面板）**
- `Cmd/Ctrl+F` 在当前编辑器窗格内弹出浮窗：宽 600 默认居中，默认位置可设（左/中/右），可拖拽移动、右下角缩放，拖拽后位置会话内优先。
- 默认不分大小写子串搜索（无大小写/整词开关）；结果双行（定位行 `L行号 · 块` + 序位 `1/7`、两行上下文截断）；行尾固定快捷键 **⌘1~⌘9 直达、选中行显示 ⏎**（Enter 定位选中行），第 10 行起仅滚动。
- 命中分布条、替换模式行内「原词 → 新词」diff 预览、替换后自动跳下一处；**悬停全文预览卡仅替换模式显示**。

**分期说明**：AI 语义搜索与一键生成 MD 为功能三，按裁定 10 拆为后续独立 change，本期不含。

## Capabilities

### New Capabilities
- `doc-property-panel`：frontmatter 属性面板——三模式显示、A/B 两种显示样式、字段类型系统与智能编辑、字段行操作与选择模式、标签彩色胶囊与建议输入、自动托管日期、属性模板、外部字段收编、⌘⇧Y 显隐。
- `search-replace-float`：当前文件字面搜索/替换浮窗——浮窗形态与默认位置、扫描规则、结果列表与行尾快捷键、替换 diff 与自动跳转、局部快捷键优先级。

### Modified Capabilities

（无——`editing` 的轮盘搜索条款不受影响；`configuration` 仅新增配置字段，三层合并/原子写等既有需求不变。）

## Impact

- **新增**：`src/lib/frontmatter.ts`（解析/序列化/写回/稳定哈希配色/别称表）、`src/components/DocPropertyBar.tsx`、`src/components/SearchReplacePanel.tsx`、`src/lib/searchScan.ts`、配套 CSS（遵守 CSS manifest 约束）。
- **修改**：`ContentArea`（挂载属性面板）、`SettingsView.tsx`（AI 区外新增属性/搜索设置区）、`src/lib/shortcuts.ts`（⌘⇧Y 全局注册 + 搜索浮窗 ⌘1~9 局部 scope）、`searchKeymap`（移除 CM6 内置搜索面板接管）。
- **配置面（数据面）**：命中 `docs/agents/data-surface.md` 信号（默认值/开关/快捷键/预置元素设置/模板），design.md 必含六栏表，G0 阶段二 / G0-POST / G1 出口分别跑 `./scripts/cw-data-surface.sh`。
- **测试**：属性往返与配色纯函数、搜索扫描、替换事务单测；Playwright e2e；`verify.sh` 全绿交付。
- **风险**：⌘1~9 与「卡片直开 ⌘1–9」冲突——按局部优先（浮窗激活时抢占、Esc 归还）实现，见 design.md 冲突登记。
