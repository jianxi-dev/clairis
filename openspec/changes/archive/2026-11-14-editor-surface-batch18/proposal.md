## Why

文件级动作目前分散在格头 ⋯ 与页签右键两个菜单：右键里的「导出」是关闭菜单后再跳到格头导出子菜单的绕路，点一次会看到菜单闪跳；打印藏在导出二级项里，且直接打印当前 DOM——编辑态打出源码，mermaid 未绘制完成时打出空块，与屏幕上的 Markdown 预览不一致。另有一份含图片与视频引用的文档在预览中无法滚动回顶部，读者回不到开头。

## What Changes

- 文件右键菜单接管「导出 / 刷新 / 打开文件位置」：导出位于「复制路径」上方并就地展开全部二级项（Word/.mdpkg/图片/PDF/HTML/ZIP），打开文件位置位于「复制路径」下方，刷新位于「关闭」上方。
- 格头 ⋯ 菜单移除导出、刷新、打开文件位置三项，其余项与顺序不变。
- 打印从导出二级项抽出，成为文件右键菜单里紧贴导出下方的独立项；导出二级项不再含打印。
- 打印始终按 Markdown 预览态输出：正文版式与预览一致、mermaid 为绘制后的图形、不出现编辑器源码与应用外壳；打印结束恢复原模式与滚动位置。
- 修复含图片 Markdown 文档无法滚动回顶部的问题，并约束预览中图片裁剪的显示尺寸不超过容器宽度。
- **BREAKING**（内部 API）：格头菜单项定义与页签右键菜单动作集合调整，旧「导出」跳转函数删除。

## Capabilities

### New Capabilities

- 无新增能力域；滚动可达性归入既有 `reading`。

### Modified Capabilities

- `navigation`：格头 ⋯ 菜单项集合缩减；页签右键菜单文件动作集合与顺序扩展（导出子菜单就地展开、打印独立项）。
- `export`：EX-7 打印入口位置与打印内容来源改为 Markdown 预览态（含 mermaid）。
- `reading`：新增「含图片文档可滚动回顶部」的可验收行为。

## Impact

- 前端菜单：格头菜单定义、页签右键菜单渲染与动作分发。
- 打印：打印入口、打印专用视图与打印样式表；mermaid 渲染管线的复用。
- 预览：图片尺寸约束与滚动容器可达性。
- 测试：菜单顺序/可见性 e2e、打印 e2e（window.print 计数 + 打印媒体断言）、滚动可达性 e2e。
- 无后端、无依赖、无数据格式变更。
