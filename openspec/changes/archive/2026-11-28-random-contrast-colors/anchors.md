# 验收锚点 — random-contrast-colors

锚点来源：用户 2026-11-28 反馈（随机只换边框/背景、人工文字常低对比；实测浅色主题同色系 2.2–4.2、深色中档黄默认文字仅 3.08），PR #1700 修复。R-1 对应 E-48 修订；R-2 对应 E-56 修订；R-3 对应 E-57。

## R-1 高对比档与随机对比度

| id | kind | claim | assert | source |
|---|---|---|---|---|
| A-1.1 | exact | 字体板第 2 格改「高对比」 | 字体行第 2 格色值为 `#111111`（浅色主题）/ `#ffffff`（深色主题），由 `--hl-font-contrast` 承载 | PR #1700 / 截图 |
| A-1.2 | state-machine | 随机三元组按 WCAG 选文字 | 点击「随机」后 `bg` / `border` / `text` 同时改变，`bg` 与 `border` 同色相族，`text` 对比度 ≥4.5（默认文字达标时取默认），一次 ⌘Z 同时还原三项 | PR #1700 / 截图 |

|---|---|---|---|---|
| A-2.1 | state-machine | 标注随机按叠底实际底色选文字 | 点击标注面板「随机」后 `bg` 与 `border` 同名，`text` 按 10% 叠底后实际底色与字体板 WCAG 对比度选出（默认达标 ≥4.5 优先，否则取最高），一次撤销还原三项 | PR #1700 / 截图 |
