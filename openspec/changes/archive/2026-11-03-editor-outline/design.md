# Design: 编辑器大纲浮层

## D1 解析只做一件对的事

**决定**：`extractHeadings(markdown)` 是唯一解析入口：ATX 标题（`#`–`######`）、跳过围栏代码块（``` 与 ~~~、最多 3 空格缩进、未闭合围栏吃到文末）、行号 0-based。预览模式用 `headingsFromDom` 读 h1–h6，形状相同、行号 -1。

**理由**：侧栏旧实现是简化正则，既不认 `~~~` 也不认未闭合围栏；两处各写一套必然漂移。

**失败后果**：代码示例里的 `#` 出现在大纲里；侧栏与浮层对同一文档给出不同标题数。

## D2 导航按行号，不按文本

**决定**：编辑/源码模式点击标题 → `doc.line(line+1).from` + `EditorView.scrollIntoView(pos, {y:'start'})`；预览模式 → 标题元素 `scrollIntoView({block:'start'})`。

**理由**：按标题文本 `indexOf` 定位在同名标题（「小结」「小结」）时会跳到第一个，且 H1/H2 相同文本会互相串。

**失败后果**：点第二个同名标题跳到第一个。

## D3 浮层形态与可达性

**决定**：按钮固定在内容区右上角（`right: 46px`，让开预览的 Aa 设置钮）；悬停展开、点击钉住、Esc 收起、点外部收起；当前可见标题高亮（编辑按 CM6 viewport，预览按 DOM 位置）；切换文档/模式重置高亮。

**理由**：与 md-bundle 的 ghost 图标交互一致，同时不遮挡阅读设置入口。

**失败后果**：与 Aa 钮重叠、页签切换后大纲停留在旧文档。

## Verification

- 单测：`Outline.test.ts` 直接测共享解析器（含 ```、~~~、未闭合、7 个 `#`、行号、尾部 `##`）。
- e2e：按钮可见、列表跳过代码块、点击滚动到标题（距离 < 80px）、Esc 收起、预览模式列出 DOM 标题、切页签跟随。
- `bash scripts/verify.sh` 全绿。
