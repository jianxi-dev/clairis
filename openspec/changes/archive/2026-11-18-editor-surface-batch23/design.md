# 设计 — editor-surface-batch23

来源：重启的 #1054（搜索浮窗）/ #1050（大纲）/ #1049（预览态选区工具条）/ #1044（日期时间字段）用户反馈；参考 `openspec/changes/archive/2026-11-18-editor-surface-batch21` 与 `2026-11-18-editor-surface-batch22` 制品及主规格。需求四要素以四条 issue 正文与评论为唯一真相源，不再另行访谈。

## Context

本 change 是对 batch21 / batch22 四项交付的**修正**，不引入新机制：

- 搜索浮窗：batch21 已做外框 / 状态栏同构，本轮按用户复看补顶栏标题、关闭按钮位次、输入框清空与字号，并删状态栏冗余文案。
- 大纲：batch21 已做「拖动轨迹 + 正文同步 + 同级徽标仅首个」；用户复看后改为「插入位置指示条 + 每项持有标识但仅悬停显示 + 标识更浅」，其中「正文顺序同步」是缺陷复现，必须重新作为验收锚点。
- 选区工具条：batch21 已做「鼠标落点优先 + 视口钳制」；本轮只改显示时机（拖选完成后再显示）。
- 日期时间：batch21 已改为「显式日期 + 时间两个控件」；本轮按用户反馈收敛为单一面板。

第一原则：**沿用既有机制、只补差异**——继续复用既有浮窗外壳 / 状态栏显隐、大纲落点计算、选区工具条定位、值编辑器 onBlur 提交链路，不另立机制。

## Goals / Non-Goals

**Goals:** 搜索浮窗顶栏标题与关闭按钮位次、输入框一键清空、状态栏文案收敛、结果区与快捷键字号各上调一档；大纲插入位置指示条 + 正文顺序同步 + 层级标识仅悬停显示且更浅；选区工具条拖选完成后再显示；日期时间字段单一面板。

**Non-Goals:** 不改搜索 / 替换匹配语义与扫描范围；不改 9 行上限、快捷键列常驻、状态栏贴底与显隐机制；不改选区工具条的横向定位与视口钳制；不做设置页信息架构；不引入第三方日期库。

## Decisions

### D1 搜索浮窗顶栏 / 状态栏 / 输入框 / 字号（#1054）

- **顶栏标题与关闭按钮位次**：浮窗顶栏 SHALL 显示标题「搜索和替换」；关闭按钮 SHALL 位于顶栏最右侧，SHALL NOT 位于视图切换（替换 ⇄）图标之后。顶栏边框 / 圆角 / 底色沿用 S-1 既有「与阅读空间文件卡片悬浮窗同构」条款，不另写一套。
- **状态栏文案**：删除「（局部 · 浮窗内）」，新文案为「↑↓ 切换 · ↵ 定位选中 · ⌘1~9 直达 · Esc 关闭」。显隐机制沿用既有（打开显示、离开失焦约 2 秒隐藏、悬停 / 聚焦恢复），贴底与无残留占位条款不变。
- **输入框一键清空**：搜索输入框 SHALL 提供一键清空按钮，输入非空时可用；点击后清空关键词（不关闭浮窗、不改变替换模式）。
- **字号**：结果区文字（定位行 + 上下文片段）与行尾快捷键徽标的字号 SHALL 按 `docs/design/system/spec.md` §4 字阶各上调一档；实现以 §4 字阶值为准，不写刻度外值。
- 设计依据：#1054 用户反馈；code obs `src/styles/search-float.css` `.search-float-top` 10px / `.search-float-context` 11px / `.search-float-key` 10px；`docs/design/system/spec.md` §4。

### D2 大纲插入指示条 / 正文顺序同步 / 层级标识（#1050）

- **插入位置指示条**：拖动大纲条目期间 SHALL 渲染**插入位置指示条**（落点指示条），指示条 SHALL 随指针位置实时移动，松手后消失；SHALL NOT 只渲染 ghost / 占位轨迹。
- **正文顺序同步**：松手后正文标题顺序 SHALL 与大纲顺序一致（编辑 / 预览均生效），SHALL NOT 只改显示顺序而正文不动。本条是既有 requirement 的缺陷复现，必须作为验收锚点并先红后绿。
- **层级标识**：每个大纲项 SHALL 持有层级标识节点（`H{n}` 徽标）；标识默认隐藏，仅鼠标悬入的那一项显示其标识，其余项保持隐藏。标识颜色 SHALL 取比次级文字色更浅一档的语义色（`docs/design/system/spec.md` §6，`--app-text-3`），SHALL NOT 与标题文字抢眼。
- 归属说明：canonical 落点为 `editing` E-10「编辑器大纲浮层」（batch21 同落点），非 `navigation`。
- 设计依据：#1050 用户反馈；code obs `src/components/Content/OutlineMenu.tsx`；`docs/design/system/spec.md` §6。

### D3 选区工具条显示时机（#1049）

- 预览态选区工具条 SHALL NOT 在拖选过程中显示；SHALL 在选区完成（鼠标松开）后于鼠标落点显示。既有「鼠标落点优先、否则选区中心」横向定位与视口左右钳制保持不变。
- 设计依据：#1049 用户反馈；code obs `src/components/Content/SelectionPill.tsx`。

### D4 日期时间单面板（#1044）

- **面板结构**：日期时间字段的值编辑器改为**单一 popover 面板**，面板内 = 月历网格（选日期）+ 时分步进控件（选时间）。
- **提交**：面板提交时 SHALL 把日期与时间组合为 `YYYY-MM-DDTHH:mm`；日期字段保持仅日期（不扩时间）。
- **键盘可达**：Tab 在月历与时分控件间移动，Enter 提交，Esc 取消。
- **onBlur 衔接**：面板内操作（点月历 / 步进）SHALL NOT 触发提前提交；沿用既有值编辑器 onBlur 提交链路，面板关闭或失焦时提交。
- 设计依据：#1044 用户反馈；`doc-property-panel` P-3；code obs `src/components/Content/DocPropertyBar.tsx`。

## Risks / Trade-offs

- [字号「一档」的基准] → 以 §4 字阶为准：定位行 10→11、上下文片段 11→12、行尾快捷键徽标 10→11；实现以 token / 字阶值为准。
- [标识「再浅一档」] → 取 §6 `--app-text-3`；如设计系统后续调整语义色阶，回改。
- [#1050 正文顺序同步是缺陷复现] → 必须作为验收锚点，先红后绿；真机多页签 / 预览态各验一次。
- [日期时间面板与 onBlur] → 面板内操作不得触发提前提交；Esc 取消回原值。
- [真机偏差（DQ-9）] → 字号 / 布局测量类（#1054）、拖拽指示与正文同步（#1050）、日期时间组合语义（#1044）触及真机偏差类信号，headless 绿单独不构成关闭，须附真机清单项。
