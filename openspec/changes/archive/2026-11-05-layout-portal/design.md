## Context

- 现状：App = 顶栏 + 单/双栏内容区（`useStore` 的 tabs/分屏/侧栏可见性/readingMode），无门户、无网格、无悬浮预览；设置散落在对话框（`SettingsDialog`）；图标为编辑器局部 `icons.ts`，无全站类型色 token。
- 目标形态：批准设计《门户与布局规格 v1.0》（`docs/design/approved/layout-portal/spec.md`，2026-11-01 定稿，构建依据、冲突以其为准）；原型 biaoyue-prototype-v11（决策票 #31）。
- 既有决策约束：模式切换 CSS display 不重建（ADR 0002）；store 只存纯文本（ADR 0004）；可折叠阅读空间方向已由 ADR 0009 裁定；API key 只存钥匙串（ADR 0005）；`.html` 预览安全边界按 reading 域现行规格。
- 关联进行中 change：editor-block-parity 触及 `src/editors/markdown/icons.ts`——本 change 的图标基座是全站层（组件/样式 token），每票开工前须跑 overlap 预检。

## Goals / Non-Goals

**Goals:**

- 12 条构建验收（规格 §14）中 1–11 条逐条全过（第 12 条 contentweave 属 Out of Scope）
- 场景化外壳：门户/工作区/网格/设置四场景，全部视图状态文本化、持久化、可回滚
- 全站视觉一致性：universe-icon + 8 类类型色 + 密度/尺寸 token

**Non-Goals:**

- 语音输入与 ASR 选型、本地 LLM/多 agent（规格 §15 延后）
- 生成物离线单文件（contentweave，另立 change）
- ⌘P 统一文件面板行为变更、斜杠菜单分类重构（G-01）
- omarchy 主题联动具体事件映射（构建期确认来源，不阻塞其它验收）

## Decisions

### D1 场景路由在 App 顶层，工作区状态保活

新增应用级场景状态 `portal | workspace | grid | settings`（默认 portal，存在历史时也先见门户——规格未要求跳过门户）。场景切换允许 remount（ADR 0002 只约束 pane 内预览/编辑/源码模式切换）；工作区布局树与页签状态全部在 store 持久保活，回到工作区无损。网格/设置关闭即回工作区（Esc 层级关闭语义）。备选「四场景全部常驻 DOM 靠 display 切换」——内存成本高且门户/网格数据可按需重建，弃。

### D2 pane 树 = store 内递归模型 + 递归组件渲染

数据模型按规格 §3 原文：`node = { id, dir, ratio, children }`、`leaf = { id, tabs, activeTabId }`，与现有「分屏」的扁平双栏模型并存迁移：布局树成为唯一分栏真相，旧扁平分屏字段由迁移票收编（expand–contract：先并存、迁完删除）。渲染为递归组件 + 分隔条拖拽（240px 下限钳制）；每 leaf 沿用按 panelId 的 EditorView 实例机制，leaf id 即 panelId 命名空间（`leaf-<id>`），不把 EditorView 放进 store（ADR 0004）。布局树序列化进视图规格持久化（D11）。

### D3 阅读空间 = 单容器三态状态机

三态（折叠/悬停浮层/钉住）实现为单容器的状态机：折叠 12px 边缘条；悬停态 absolute 覆盖（不挤压正文）+ 移开 300ms 收回计时器；钉住 flex 常驻。密度三档与两式布局是列表渲染参数（`defaultLayout/defaultDensity/cardHeight` 进视图规格）。卡片缩略图见 D4。段（现在/置顶/最近/分类）为固定数据源分段；分类 = 过滤 chips（8 类带计数），不做瀑布行。

### D4 缩略图管线：懒生成 + 磁盘缓存 + 六类型来源

4:3 缩略图（72×54，网格更大）按类型取材：图片=真图；PDF=首页（pdfium WASM 已自托管）；视频=海报帧；有图 MD=marked 解析首图；HTML=渲染页（复用 HtmlPreview srcdoc 离屏渲染）；音频=粉波形占位；纯文本=真实排版预览；无图 MD 无缩略图。全部懒生成（进入视口才生成）+ 按文件指纹缓存，避免大目录卡顿。备选「打开目录时全量预生成」——大目录首开不可接受，弃。

### D5 悬浮预览窗 = 锚定坐标纯函数 + 拖动会话态

锚定坐标计算写成纯函数（输入：宿主场景、锚点行/卡几何、窗尺寸；输出：x/y 与锚定边），可单测可断言；贴边翻转=锚定边互换。拖动位置是会话态（保持到关闭，重开回默认锚定）。真内容渲染按文件类型复用既有渲染管线（markdown/HTML/text/PDF），内部滚动。双开关（阅读空间悬停/网格模式）进视图规格 `preview.json`。

### D6 AI 两形态共享同一对话 store

小窗与停靠窗格是同一对话 store 的两个宿主容器（切形态不换 store、不丢历史）；停靠=把 AI 宿主作为 pane 树的特殊 leaf 插入（默认右侧 28%），脱离=还原小窗。确认卡三档、撤销条、快照沿 AI entry V1 既有机制扩展；视图改写=对视图规格文件的受控写（走确认卡+快照，预设 6 条为参数化指令）。唯一入口=顶栏星芒，⌘K 快捷浮层与选区动作保持既有行为。

### D7 设置 = 场景 + 左导航路由 10 区

设置成为独立场景（⌘,），左导航 10 区每区一页；外观区含主题（浅/深/暖）+字号+跟随系统（默认开）；AI 服务区列表 7+1 provider，key 只走钥匙串命令；悬浮预览区承接 D5 双开关；快捷键区读 D10 注册表渲染核心 7 条+完整列表。现有 `SettingsDialog` 内容迁移进对应分区后移除（expand–contract，迁移票收编）。

### D8 扩展管理面消费既有扩展点基建

目录扫描与 `list_extensions` 已由已归档 extension-points change 提供；本 change 做管理面：导入=拷贝进扩展目录即启用（拖入文件夹/.zip/点击选择）、管理列表（名称/来源徽章/开关/打开/卸载）、导出打包、AI 生成（走 agent 循环产出 manifest+SKILL.md 默认启用）。

### D9 图标体系 = 全站 Icon 组件 + 类型色 CSS token

universe-icon 以 SVG path 表 + 统一 Icon 组件接入（24 viewBox、fill=currentColor、18/24 两档），无运行时依赖；8 类类型色落为 `src/styles/` token（色值见规格 §10）；标签三级（自动/始终文字/仅图标）为全局设置。编辑器内图标沿 editor-block-parity 既有 path 约定，两线共用同一 Icon 组件后收编（涉及同文件，开工前 overlap 预检）。

### D10 快捷键 = 集中注册表，一表驱动三处

全部快捷键集中一张注册表（键位/作用/家族/作用域），驱动：实际 keymap 绑定、tooltip 键位显示、`?` 总览浮层、设置快捷键区。避免三处各写一份漂移。Esc 层级关闭（先清搜索→再关面板）按浮层栈实现。

### D11 持久化 = 视图规格文件 + 快照

`$APPCONFIG/user/views/rail.json | grid.json | preview.json` + 布局树，落应用配置目录（沿用原子写）；快照最近 10 份（配置/视图/布局可回滚）；会话记忆（预览窗拖动位置、AI 小窗位置尺寸）随写随存。Rust 侧新增 views 读写命令（复用 config_cmd 的原子写模式），前端经既有 invoke 封装调用。

### D12 切片顺序与集成 checkpoint

16 张垂直切片按依赖排序（图标基座→门户→pane 树→页签格头→拖拽→阅读空间两票→悬浮窗→AI→网格两票→设置两票→扩展→快捷键→收尾核查）。QG-6 集成 checkpoint：每完成 ≤4 票执行一次（第 4/8/12/16 票后），合并到集成分支→构建→浏览器打开一次→记录「用户现在能看到什么」。

### D13 弹层定位 = 最短路径第一原则（设计哲学 P7）

所有弹层（⋯ 菜单、滑杆下拉、悬浮预览窗、AI 小窗、快捷键总览）的显示位置与默认焦点，以「鼠标落点/键盘焦点 → 目标动作的路径最短」为第一判据：优先贴触发点就近弹出、不横移跳位；其次才是跨场景的显示统一性与简洁性；特殊情况（视口边缘）在就近与完整显示间取最短折中（夹取/翻转不增加点击距离）。一致性考虑不得以拉长点击距离为代价。本规格中已固化的实例：悬浮窗 y 跟随悬停行、x 恒定不随鼠标横移（A-5.3）；网格贴卡右缘弹出（A-5.3）；底部动作区 hover 就近显隐（A-5.6）。后续各票实现弹层时按本条裁定位置取舍，16.1 红线核查引用。

### D13 最短路径第一原则（设计哲学 P7，2026-11-04 维护者补充）

所有弹层类定位（落区预览、格头菜单、色板/二级面板、悬浮预览窗、AI 小窗、确认卡）服从统一判据优先级：**① 最短路径**——弹层先出现在离鼠标落点最近、点击代价最小的位置，「落点→目标动作」一步可达；**② 统一性**——同类弹层锚定方式一致（如悬浮窗贴栏右缘+12）；**③ 简洁性**——不引入多余装饰与位移；**④ 特殊情况**——仅在 ① 不能满足时做视口夹取与翻转避让，且不得以增加点击距离为代价换取对齐。落区判定与悬浮窗锚定的纯函数（D2/D5）实现时按此优先级取解；e2e 断言锚定坐标时以「落点邻域」而非固定点为准绳（视口边缘例外须显式记录）。

## Risks / Trade-offs

- [16 票体量大，中途漂移] → QG-6 每 4 票集成 checkpoint；tasks.md 与票面锚点绑定，验收逐条打勾
- [与 editor-block-parity 在 icons.ts 同文件冲突] → 每票开工前 G1 第 0 步 overlap 预检；D9 优先做全站组件层，编辑器内收编放最后
- [缩略图管线性能（大目录/HTML 离屏渲染）] → D4 懒生成+缓存；HTML 渲染页生成失败降级为橙页占位并在票上记录（不静默）
- [拖拽换位语义复杂（五种落区×两种拖拽源）] → 落区判定纯函数化 + 状态机 e2e 断言（T3 六态往返无残留）
- [pane 树迁移触及现有分屏] → D2 expand–contract：布局树与旧扁平分屏并存，迁移票收编后删除旧字段
- [场景 remount 丢编辑状态] → 场景切换仅门户/网格/设置↔工作区，EditorView 与内容全在 store/editorRef 保活；票面 e2e 覆盖「进出场景内容不丢」

## Migration Plan

- 无破坏性数据迁移：视图规格文件新增，旧配置不读坏；旧扁平分屏字段在布局树稳定后由收编票删除
- 回滚：快照机制（最近 10 份）覆盖配置/视图/布局；单票按 PR 粒度回滚
