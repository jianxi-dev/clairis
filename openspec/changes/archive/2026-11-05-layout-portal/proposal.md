## Why

路线图阶段 3「空间与入口」的核心缺口：当前应用启动即进工作区，无门户、无网格概览、无悬浮预览、AI 单形态、设置未分区。门户与布局规格 v1.0 已于 2026-11-01 定稿（原型 #31 十二轮迭代），Wayfinder #22 裁定实现走实现期 OpenSpec change——本 change 即该裁定的落地（规格票 [#170](https://github.com/jianxi-dev/clairis/issues/170)）。

## What Changes

- 新增门户启动首屏：问候语 + 继续阅读 hero 卡 + 最近文件富卡 + 分类磁贴 8 类 + 快速动作 + 空态引导（取代现有启动欢迎页形态）
- 新增工作区 pane 递归树：右分/下分、每格多页签、全屏、拖拽换位（中心互换/四边移动/边缘到根层）、文件四向落区、最小 240px、布局持久化
- 新增阅读空间竖排栏：三态（折叠/悬停浮层/钉住）、堆叠/标签双布局、密度三档（32/56/112px）、卡片规格（彩色图标/真摘要/4:3 缩略图/进度/可点路径）、滑杆下拉、粘性搜索
- 新增网格概览（⌘⇧\）：顶部单行全下拉、bento tile 三型、缩略图优先、时间粘性分组、完整键盘导航与 ⌘编号直开
- 新增悬浮预览窗：真内容渲染、四边四角缩放、栏右缘锚定、拖动位置保持、阅读空间悬停/网格点击双开关
- AI 两形态：顶栏星芒唯一入口、小窗 285×260 ⇄ 停靠嵌入窗格（共享对话历史）、确认卡三档、撤销+快照、视图改写预设
- 设置改为左导航 10 区（外观/编辑器/阅读空间/网格概览/悬浮预览/AI 服务/扩展/快捷键/数据与备份/关于），含跟随系统外观
- 新增扩展管理面：拖入即用、管理列表、导出分享、AI 生成（消费已归档 extension-points 基建）
- 统一图标体系：universe-icon、类型色 8 类、标签三级、图标抽屉、禁 emoji
- 落地完整快捷键家族 + `?` 总览浮层 + tooltip 键位
- 视图状态持久化：视图规格 json（rail/grid/preview/布局树）+ 快照回滚 + 会话记忆

## Impact

- **前端全层**：App 外壳与场景路由（`src/App.tsx`、`src/components/Layout.tsx`）、stores（布局树/场景/视图规格）、新组件族（门户/网格/悬浮窗/阅读空间/设置分区）、`src/styles/`（类型色与密度 token）
- **Rust 侧**：视图规格与布局树持久化需要配置目录读写扩展（沿用原子写模式；API key 仍只走钥匙串）
- **编辑器**：pane 树复用按 panelId 的 EditorView 实例机制与 CSS display 模式切换（ADR 0002/0004 不变）
- **e2e**：新增门户/pane 树/阅读空间/网格/悬浮窗/设置/快捷键用例（浏览器层 + mock IPC 两套）
- **依赖**：universe-icon 图标引入（SVG path 表方式，无运行时依赖）
- **联动约束**：与 editor-block-parity 的 `icons.ts` 改动存在同文件潜在冲突——每票开工前执行 overlap 预检（G1 第 0 步）
