# 任务 — editor-surface-batch21

> 切片原则（QG-7）：每张票做完用户能在界面上看到变化；1 任务 = 1 票，票标题前缀 `[change=editor-surface-batch21/<任务号>]`。
> 故事编号指 spec issue #1038 的 User Stories 1–23（1–18 为初批，19–23 为搜索浮窗追加批次）。
> **Blocked by 语义**：`Blocked by` 为硬边，未解除不得开工；`gated` 表示须先有结论才能开工。
> 集成 checkpoint（QG-6，票数 ≥6）：每完成 ≤4 票合并到集成分支跑一次四件套并浏览器打开一次，记录「用户现在能看到什么」。
