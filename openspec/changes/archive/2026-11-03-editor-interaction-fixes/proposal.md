# Proposal: 编辑态交互缺陷修复（块菜单 / 手柄 / 表格工具条）

## Why

用户实测反馈五条交互问题，逐条复现后确认都是实现偏离已定契约，不是新功能：

1. **块菜单位置不对**：菜单开在锚点行下方且贴正文左缘，而不是贴着触发手柄、以指针行为中心（md-bundle #453 / #466 / #487 的验收态）。
2. **图标不统一**：文字字形图标（¶ / H1–H3）在 16px 槽位里只有约 7px，与路径图标不成列，读起来像「没有图标」（#484）。
3. **菜单打开后滑动鼠标冒出其它手柄**：hover 门控仍会对菜单背后的内容召唤手柄，出现第二个药丸。
4. **「在下方添加」要点击才出现、且替换父菜单**：应悬停即向右展开二级面板并保留父菜单（#456 / #480）。
5. **颜色与工具条没接进来**：单元格工具条只在多选/显式选择时出现，单击进单元格看不到底色控件。

另外发现两个同源缺陷：

6. **围栏代码块里的 Markdown 被当成真语法渲染**：代码里的 `# 标题`、`- 项`、`> 引用`、`**粗**` 按块级/行内语法显示（真实代码块显示成标题大小）。
7. **手柄召唤不稳定**：keyup 落在编辑器外时抑制标志卡死，手柄「有时不出来」；点击手柄空转不开菜单。

## What Changes

1. 摆放契约细化为「纵向取指针行、横向贴手柄、居中优先、越界夹取、限高到较大一侧」。
2. 文字字形图标放大到与路径图标等光学尺寸。
3. 菜单打开期间不 retarget、不召唤其它手柄；指针移动解除卡死的抑制标志。
4. 点击手柄等价于悬停召唤（直接开菜单）。
5. 「在下方添加」悬停 150ms 向右展开二级面板，父菜单保留、不改变高度。
6. 围栏代码块区间对标题/列表/引用/分割线/行内强调装饰全部免疫。
7. 单元格单击即显示工具条（合并按钮单选时禁用，底色可用）。

## Capabilities

### Modified Capabilities

- `editing`：E-7 编排层交互契约（摆放语义、二级面板、hover 稳定性）；新增 E-9 单元格工具条可见性。
