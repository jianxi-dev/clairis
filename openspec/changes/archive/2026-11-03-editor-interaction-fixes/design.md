# Design: 编辑态交互缺陷修复

> 对齐 md-bundle 已验收的交互契约（#453 / #466 / #480 / #484 / #487 / #456），只改实现不改产品方向。

## D1 块菜单摆放

**决定**：`resolvePlacement` 增加 `align` 三态，块菜单用 `center-right`：

- 横向：贴手柄右缘 + 4px；右侧放不下翻到手柄左侧，仍溢出再夹取（#453）。
- 纵向：以指针所在行的中点为菜单中点；放不下时夹进容器内离居中最近的合法位置（#466）。
- 高度：封顶到锚点较大一侧的可用空间，超出时 `maxHeight + overflow-y:auto`，不得被推离锚点（#487）。

**失败后果**：菜单与指针脱节、靠近底部整体跳位（#453/#466 的原始现象）。

## D2 二级面板

**决定**：「在下方添加」悬停 150ms → `openInsertMenu(trigger="below", anchorRect=该行矩形)`，`align="right"` 开在父菜单右侧；父菜单保留且高度不变（#456/#480）。面板高 360px 封顶并滚动。父菜单收起时一并释放二级面板。

**失败后果**：悬停不展开（要点击）、父菜单被替换、外框跳动导致定位失效（#480 的根因）。

## D3 围栏代码块免疫

**决定**：`code.ts` 导出 `fencedCodeRanges(text)`（含未闭合围栏到文末）；标题 / 列表 / 引用 / 分割线 / 行内强调装饰在命中区间内一律跳过。

**失败后果**：代码示例里的 `# 标题` 以大字号渲染、`- 项` 变成列表——用户直接把代码块读错。

## D4 手柄稳定性与工具条可见性

**决定**：

1. 指针移动时解除 hover 门控的抑制标志（keyup 落在编辑器外会永久卡住）。
2. 块菜单打开期间不改召唤对象、不召唤其它手柄。
3. 点击手柄（位移 < 4px）等价于召唤菜单。
4. 存在单元格选区即显示工具条；单选时合并按钮禁用，底色仍可改。

**失败后果**：手柄「有时不出来 / 点了没反应」、菜单背后冒出第二个药丸、用户认为颜色与工具条没接进来。

## Verification

- `e2e/block-menu.spec.ts`：菜单贴手柄右侧、居中断言（含夹取后的最近合法位置）、每行有图标、点击召唤、二级面板向右且父菜单高度不变、菜单打开时不冒出第二个手柄。
- `e2e/editor-display-parity.spec.ts`：围栏内的 `#`/`-`/`>`/`**` 均不作块级/行内装饰。
- `e2e/table-decorations.spec.ts`：单击显示工具条、底色写入源码、拖选后合并可用并生效。
- `bash scripts/verify.sh` 全绿。
