# 提案：确立品牌 slogan 与对外叙事（标月）

## Why

产品已有名字「标月」（出自《圆觉经》"修多罗教，如标月指"）与一句话定位（vision.md §二），但没有 slogan 与分层叙事：用户第一眼看不到品类信号（不知道"标月"是读写应用），典故与产品能力的连接也没有权威口径。2026-11-02 完成一轮跨模型碰撞（Claude 提案 × Codex 对抗评审），收敛出一套可落地的品牌文案体系，需要固化为产品真相源，避免后续文档、官网、应用商店文案各自漂移。

## What Changes

- 新增品牌叙事规格：主 slogan、传播钩子、首屏副标、上墙短句、名称语义（标月=动作）、典故口径（借象不借教）与文案禁区。
- 修订 `docs/product/vision.md`：在"一句话定位"（what）之前加入 slogan（why），新增"品牌叙事"小节与文案禁用清单。
- 不改产品行为、不改代码、不改应用名与标识符（app-identity 规格 A-1 不受影响）。

碰撞定案（两模型收敛结果）：

| 层级       | 定案文案                                             |
| -------- | ------------------------------------------------ |
| 主 slogan | 标月：你只管月亮，工具交给 AI。                                |
| 上墙短句     | 指向月亮，然后退后。                                       |
| 传播钩子     | 月亮不在设置里。                                         |
| 首屏副标     | 一款被你拥有、可被 AI 塑形的读写应用。布局、键位、导航，一句话改；改坏了，一句话退回。    |
| 典故口径     | 借象不借教——手指指月，看的是月；标月不是一根更漂亮的手指，而是指向月亮的那一下——你看见了月亮，它就退开。 |

名称语义定案（2026-11-02 维护者质询后修正）：经文「标月指」是名词（那根手指）；产品名截取的「标月」是**动宾动作**——指向月亮的那一下。产品不自认是手指（工具），自认是帮你完成指向的动作；动作完成即结束，天然支撑「退开」叙事。上墙短句「指向月亮，然后退后」正是动作叙事，被该定义加强。

文案禁区（碰撞中判死刑的表达）：~~"软件是指，内容是月"~~（语病）、~~"最诚实的指"~~（硬凑解经）、~~"AI 掰正手指"~~（动词暗示工具原本是歪的）、~~"会消失的读写工具"~~（消失=数据丢失联想）。

## Capabilities

### New Capabilities
- `brand-narrative`: 品牌叙事与对外文案口径——slogan 层级、典故使用边界、文案禁用清单、各渠道（首屏/应用商店/about 页）的文案分层规则。

### Modified Capabilities

（无——本变更不改变任何既有 spec 层面的可验收行为；app-identity 只管应用名与标识符，slogan 属于新增叙事能力。）

## Impact

- 文档：`docs/product/vision.md`（修订）、`docs/product/` 可能新增 `brand.md`（叙事细则，可选）。
- 规格：`openspec/specs/brand-narrative/spec.md`（新建，归档时生成）。
- 代码：无。
- 后续受益方：官网、README、应用商店文案、启动页——均以本规格为文案真相源。
