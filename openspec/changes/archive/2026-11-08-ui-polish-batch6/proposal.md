# Proposal: 界面细化与编辑器工具条批量修复（第六批）

## Why

用户 2026-11-08 第二次真机走查，一次报出 23 项问题与优化。与第五批不同，这批没有崩溃或数据损坏，全部是**视觉与交互的精度问题**：多余线条与文字、尺寸不合手、悬停反馈不一致、图标语义重复、菜单落位与层级不顺。

这类问题的共同点是「单看每项都很小，合在一起就是产品的手感」。散落热修会互相踩文件（页签栏、状态栏、阅读杆、块菜单各自被多处改动），所以按表面收成一个 change，每片配真实渲染的 e2e 探针。

## What Changes

1. **顶栏与页签栏**（反馈 1 / 5 / 14 / 23）
   - 移除只写「标月」二字的品牌顶栏；沉浸入口只留图标不写字
   - 页签选中不再画蓝色描边，改为页签自身高亮、其余置灰
   - 页签区与栏目边框重叠导致的加深底边去掉
   - 页签右键菜单各项补图标
2. **状态栏**（反馈 2 / 10 / 11 / 12）
   - 状态栏高度降低
   - 主题按钮加下拉箭头，悬停弹出主题选择弹窗（为后续扩展主题留位）
   - 双击状态栏切换显示/隐藏；隐藏后指针滑到窗口底部 0.5 秒内自动显现，移开隐藏
   - 网格概览前新增主页入口，回到程序启动页
   - 页面宽度点击弹出调整面板：三档预设 + 滑块
3. **阅读空间卡片与悬浮窗**（反馈 6 / 7 / 8 / 9 / 13）
   - 卡片底部行：图标缩小、收藏改爱心、文件夹路径默认即可交互（悬停有变化、悬停显示完整路径）、整行下移贴近底边、修掉缩略图与进度/底部行重叠
   - 悬浮窗宽度恢复上一版并再加一个缩略图宽；悬停唤出区域收窄到缩略图宽度（缩略图左侧不唤出）
   - 悬浮窗底部动作行改为悬停浮现，按钮尺寸与卡片内同款（含 PDF 卡片）
   - pin / pinOff 造型收细：梯形下移、斜杠缩短
   - 大纲未钉住时不显示边框，钉住时显示较细边框
4. **编辑器工具条与菜单**（反馈 15 / 16 / 18 / 20 / 21 / 22）
   - md 编辑态复用 md-bundle 的选区工具条；html 编辑态的两种工具条不再出现在 md 编辑态
   - 工具条与二级菜单按最短路径原则落位（就近翻转，不出窗口边界）
   - 空行前新增手柄滑入即显示菜单，菜单跟随指针位置
   - 转换手柄菜单把缩进与对齐合并为一项，二级菜单承载两者，对齐相关项补图标
   - 转换手柄菜单宽度与新增手柄菜单一致；标题与无序列表前两行间距调低
   - 颜色菜单弹出二级后不再消失
5. **图标与快捷键**（反馈 3 / 17 / 19）
   - md 图标去重与重绘：分栏（1–5 栏）、表格（封口网格）、数据看板、插入 HTML / CSS、流程图、视频/文件、内嵌网页不再互相重复；剪切块换直观造型
   - 视频播放倍速菜单 0.5×–2.0×，变速不影响音高与清晰度
   - 撤销/重做同时支持 ⌘Z 与 Ctrl+Z（macOS 上 Caps 位置更顺手的用户不必迁就 Cmd）

## Capabilities

### New Capabilities

（无。全部落在既有 capability 的 requirement 内。）

### Modified Capabilities

- `application-shell`：G-3 单一顶栏（收缩：品牌顶栏移除，chrome 只剩分栏内元素）、状态栏（新增：高度、双击隐藏与悬停显现、主题弹窗、主页入口、宽度弹窗）
- `navigation`：页签条与格头（改：选中态与底边）、阅读空间卡片规格（改：底部行尺寸/收藏/路径/位置）、悬浮预览窗（改：宽度与唤出区域、底部动作行）、图标体系（改：pin/pinOff 造型、md 图标去重）
- `editing`：块菜单结构（改：缩进与对齐合并、菜单宽度与间距）、手柄召唤（改：新增手柄滑入显示且跟随指针）、大纲浮层（改：边框随钉住状态）、工具条归属（改：md 复用 md-bundle 选区工具条；html 工具条不进 md）、菜单落位（复述最短路径，修实现偏差）、新增 颜色面板二级保持、新增 撤销与重做双快捷键
- `file-management`：C-6 视频预览播放器（改：倍速播放）

## Impact

- 代码：`App.tsx`、`components/Toolbar.tsx`（移除）、`components/TabBar.tsx`、`components/StatusBar.tsx`、`components/Rail/ReadingRail.tsx`、`components/Preview/FloatingPreview.tsx`、`components/Content/VideoPlayer.tsx`、`components/Content/OutlineMenu.tsx`、`editors/orchestration/*`、`editors/icons.ts`、`ui/icons.ts`、`editors/keybindings.ts`、`styles/editor.css`、`styles/reader.css`
- 测试：扩展/新增 `e2e/` 用例（页签选中态、状态栏双击与悬停、宽度弹窗、主题弹窗、阅读杆底部行、悬浮窗唤出区域、倍速菜单、菜单落位、颜色二级、快捷键）
- 风险：菜单与工具条是多处共用组件，改动需逐项回归；不做破坏性数据变更，无迁移
