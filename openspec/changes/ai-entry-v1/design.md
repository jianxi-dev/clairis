# Design: AI 入口 V1

## D1 ⌘K 浮层

- 位置：底部居中，非模态；`⌘K` 打开并聚焦输入；`Esc` 关闭；点外部关闭。
- 提交后：用户消息上屏 → 调 `run_agent_turn` → 结果以纯文本 + 「改动摘要」展示。
- 改动摘要来源：提交前取 `list_config_snapshots` 的当前头，提交后再取一次；有新增快照 = 有改动。
- 空态：一句提示 + 两个示例指令（如「换成深色主题」「字号调到 18」）。

## D2 撤销

- 提交前记录 `before = 最新快照名`（没有则 null）。
- 有改动 → 显示撤销条 3 秒；撤销 = `restore_config_snapshot(before)`；若 before 为 null，则恢复到 defaults（提示「已恢复默认」）。
- 撤销后 UI 重新加载配置（复用 C2 的 `config-changed` 或直接 load）。

## D3 选区动作

- 编辑器选区非空 → 浮动胶囊（改写 / 翻译 / 润色）。
- 触发后把「任务 + 选区文本」作为一次指令发给 `run_agent_turn`，要求在正文里只返回替换后的文本。
- 展示前后 diff（并排或行内），应用 = 用选区替换为结果（一次事务，可撤销）；取消 = 关闭并保留原文。

## D4 快照面板

- 入口：撤销条旁的「历史」或设置内；列出最近 10 份（人话时间），一键恢复；恢复前提示「当前状态也会被保存」。

## D5 确认密度

`AppConfig.aiConfirmDensity: "always" | "session-silent" | "never"`，默认 `session-silent`。
- `always`：每次 AI 改动前弹卡，确认后才继续（本版实现为「先预演、后执行」：先 dry-run 展示将改项，再执行）。
- `session-silent`：直接执行，事后撤销条兜底。
- `never`：只靠撤销条。

> 若 C3 未提供 dry-run，`always` 档降级为「执行前二次确认本轮指令」并在票上标注降级原因。

## D6 人话与图标

- 错误映射：校验错误 →「字号需要在 8–96 之间」；网络 →「连接不上服务，检查 AI 服务设置」。
- 图标用现有 `lucide-react` 线性图标；禁 emoji。
