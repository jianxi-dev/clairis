# 变更提案：文档属性块嵌入正文流（对账 二.5，#1157）

## Why

维护者 2026-11-19 第三轮验收对账（二.5 由「待补充」转为已定义）：目前的文件属性操作块渲染在内容区**上方、滚动容器之外**，不随正文滚动，与原型「属性块是文档内容第一个块」不符。要求属性块整体嵌入正文内——随文档流滚动、位于正文标题之前，编辑态可编辑、预览态只读，A 一行条 / B 精排双列两态保持。字段与字段属性后续会持续扩展，本 change 只把结构位（嵌入点）做正，并为插件化留扩展点（本期不做插件运行时）。

## What Changes

- **编辑态嵌入**：属性块从「内容区上方固定宿主」迁入正文流首块（CodeMirror 块级 widget + React portal，等效实现亦可，见 design）。随文档滚动、位于正文标题之前；折叠/展开不改滚动语义。
- **预览态嵌入**：属性块渲染在预览内容流顶部（`PreviewView` 之前），随预览内容滚动。
- **源码态**：维持不渲染（frontmatter 原文可编辑），与 P-1 既有约束一致。
- **宽度与视觉**：块宽 SHALL 对齐正文测量宽 `--type-measure`；圆角卡片、行间细分割线、卡片下方紧跟正文标题（沿用 §7 与 P-10 视觉锚点，不新增像素值）。
- **规格修订**：P-1 MODIFIED——落位从「内容区上方」改为「正文流首块」，新增嵌入相关场景；其余 P-2…P-10 不动。
- **扩展点**：面板组件保持单一入口（`DocPropertyBar`），字段渲染继续走既有类型注册表；design 记录「字段属性/插件化」的扩展边界，本期不实现插件运行时。

## Capabilities

### New Capabilities

（无。）

### Modified Capabilities

- `doc-property-panel`：P-1（属性块落位改为正文流首块；新增「嵌入正文流首块」「块随文档滚动」「块宽度对齐正文测量宽」场景；保留全部既有场景）。

## Impact

- **前端**：`src/components/Content/ContentArea.tsx`（移除滚动容器外宿主，改为预览流顶部 + 编辑态块 widget 挂载点）；`src/editors/decorations/`（新增块级 widget 与 decoration 注册）；`src/styles/doc-property.css`（嵌入态容器/测宽样式）；`DocPropertyBar.tsx` 保持组件接口不变（仅新增可选 `embedded` 呈现类）。
- **数据面**：不新增配置字段/图标/菜单/开关；沿用既有类型图标与 `--type-measure`，无需六栏表（G0 用脚本确认）。
- **测试**：e2e（编辑态块在正文首块且随滚动移出视口、预览态在标题之前、源码态不渲染、A/B 两态在嵌入后仍正常）；`bash scripts/verify.sh` 全绿。
- **不在范围**：插件运行时、字段属性扩展本体、多文档批量属性编辑。
