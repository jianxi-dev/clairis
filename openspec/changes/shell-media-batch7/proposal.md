## Why

用户 2026-11-08 第三次真机走查报出 8 项问题，全部落在「每天都在碰的界面」上：主题弹层在指针到达前消失、图片右键要等、图标认不出、视频不能截图/旋转/缩放、沉浸模式收不干净、同一语义的暗色图标在六处有六种实现、悬浮窗看不了长图与真实网页、多栏只能手拖。

第 1 项是同一类缺陷的**第三次**复发（`#328` 导出子菜单被卸载、`#374` 颜色二级面板被父级关闭、本次主题弹层），只修个例必然第四次复发，因此本 change 同时把「悬停浮层生命周期」写成设计规则与验收状态列。

## What Changes

1. **主题弹层与状态栏主题入口**
   - 指针从按钮移向弹层时不再自行关闭：进入弹层/桥接区即取消关闭定时器；用透明桥接消除 6px 死区；外部点击、`Esc`、滚动、卸载均有明确关闭与清理。
   - 底部「双击隐藏 → 热区唤出」状态下不再因状态栏卸载而丢失弹层。
   - 单击状态栏主题图标**循环切换主题**（`system → light → dark → warm → system`）；悬停仍打开面板，面板项点击仍直接设定。
   - 补齐 `aria-haspopup` / `aria-expanded` / `role="menu"` / `role="menuitem"`；宽度面板补外部点击与 `Esc` 关闭。
   - 新增「悬停浮层生命周期」设计规则文档；UI 状态矩阵新增「弹层」状态列。
2. **图片右键菜单**：预览区右键图片改为应用自绘菜单（渲染前不等待任何 IPC），四项：打开所在文件夹 / 另存为… / 复制文件路径 / 关闭预览；抑制 WebKit 原生菜单。
3. **「关闭其他」图标**：重绘为单一实心 × + 两条短横线，去掉虚线与第二枚小 ×。
4. **视频播放器**
   - 播放键两侧加「上一集 / 下一集」。
   - 新增「截取当前画面」（PNG，系统另存为，默认名含时间码）。
   - 新增「画面」面板：旋转 90° 步进、缩放 1×–4×（按钮 + 双指捏合 + 缩放后拖拽平移）、亮度 50%–150%。
   - 容器尺寸变化（拖分隔线 / 格全屏 / 窗口缩放）后自动重新适配，不再需要切一次网页全屏。
   - 控制条按钮间距收紧；顺序改为「截图在全屏前、画中画在全屏后」。
   - 音频文件不显示画面类控件。
5. **沉浸模式**
   - 状态栏自动隐藏（底部热区 500ms 临时唤出）；左侧阅读空间自动隐藏，**钉住则保持可见**。
   - 取消单条全局悬浮页签条，改为**每栏独立页签条**：指针进入哪一栏就显示该栏自己的页签条，移出 400ms 收起，拖拽期间不收起。
   - 退出沉浸后按派生可见性自动恢复，不写回用户偏好、不做状态快照。
6. **chrome 图标颜色统一**：新增一对前景色 token（默认暗 / 悬停亮），统一状态栏右侧图标（AI 除外）、未选中页签名、栏目右侧按钮、阅读空间卡片底行与路径；全屏按钮悬停不再变蓝；移除 `opacity-60` / `opacity-70` / `text-gray-400` 拼凑。
7. **阅读空间悬浮窗**：图片按内容区宽度适配、高度自适应、纵向可滚动（与主预览一致）；HTML 改为本地资源地址直载 + 允许脚本的沙箱，不再用 `srcDoc` + 禁脚本；二进制 / HTML 不再先整份读入前端。
8. **一键布局栏目**：状态栏主页图标后新增按钮，按栏数与各栏选中页签文件类型自动排布；媒体栏优先获得更大面积；保留全部页签、顺序、选中态、编辑模式与焦点栏。

## Capabilities

### New Capabilities

（无。全部落在既有 capability 的 requirement 内。）

### Modified Capabilities

- `application-shell`：状态栏（改：主题入口点击循环、弹层生命周期、宽度面板关闭、ARIA）、沉浸模式（改：状态栏与阅读空间自动隐藏、每栏独立页签条、退出恢复）
- `navigation`：图标体系（改：「关闭其他」造型、chrome 前景色、全屏按钮悬停色）、悬浮预览窗（改：图片按宽滚动、HTML 直载）、新增「一键自动布局栏目」
- `reading`：悬浮窗媒体渲染与 HTML 渲染方式（改：与主预览一致）
- `file-management`：C-6 视频预览播放器（改：上下集、截图、旋转/缩放/亮度、容器自适应、控件顺序与间距、音频不显示画面控件）

## Impact

- 代码：`src/components/StatusBar.tsx`、`TabBar.tsx`、`Content/PaneTreeView.tsx`、`Content/VideoPlayer.tsx`、`Content/PreviewView.tsx`、`Preview/FloatingPreview.tsx`、`Rail/ReadingRail.tsx`、`ImmersivePeekBar.tsx`、`App.tsx`、`ui/icons.ts`、`styles/tokens.css`、`styles/editor.css`、新增自动布局纯逻辑模块。
- 测试：扩展/新增 `e2e/` 用例（主题弹层与循环、图片右键、图标、视频控件与自适应、沉浸、颜色一致性、悬浮窗媒体、自动布局）；`src/__tests__/` 覆盖自动布局纯函数与主题循环。
- 文档：新增「悬停浮层生命周期」设计规则；`docs/agents/ui-test-matrix.md` 增「弹层」状态列。
