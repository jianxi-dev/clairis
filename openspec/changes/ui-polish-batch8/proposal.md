# Proposal: 界面精度与交互一致性修复（第八批）

## Why

用户 2026-11-09 第四次真机走查，一次报出 17 项问题。这批仍然没有崩溃或数据损坏，但性质比前两批更重：

- **有三项是此前已提出、至今未落实的旧账**（HTML 工具条归属、大纲按钮位置与边框、主题下拉三角），说明「已验证」与「用户可见」之间仍有断点。
- **出现一处功能性阻塞**：AI 停靠到右栏后，从卡片打开文件与 `Ctrl+O` 都打不开；只有 AI 小窗形态正常。这是用户可感知的能力失效，不是观感问题。
- 其余为视觉与交互精度：拖拽页签误选文字、PDF 工具条与底色不跟主题、页签选中态与图标分级、悬浮窗行为、图标造型、宽度面板刻度、视频控制条与截图路径。

17 项横跨页签栏、栏目头、状态栏、阅读空间、悬浮预览、PDF、HTML 编辑器、视频播放器，多处改同一批文件。散落热修会互相踩，按表面收成一个 change，每片配真实渲染的 e2e 探针。

## What Changes

1. **页签与栏目**（反馈 1 / 5 / 9）
   - 拖拽页签经过正文时不再选中文字（拖拽会话期间全局禁选）
   - 页签选中文件名为白/黑；未选中页签图标置灰；只有当前栏目的当前文件图标保留类型色；其他栏目的当前文件名仍用选中色；取消栏目聚焦时的蓝色内描边
   - 页签右键菜单新增「悬浮小窗」，与文件卡片一致地唤出悬浮预览
2. **PDF**（反馈 2）
   - 顶栏页码区去掉外边框（全站唯一带框控件）
   - PDF 正文外围底色跟随主题，不再固定为组件默认色
3. **状态栏与图标**（反馈 3 / 7 / 14）
   - 亮色主题图标 6 条光线等距（当前缺两条斜线，视觉上不均）
   - 自动布局图标改为魔法棒
   - 主题入口不再显示下拉三角
4. **栏目头与分栏**（反馈 4 / 17）
   - 全屏按钮默认隐藏，指针滑入栏目头才显示（全屏态常显退出按钮）
   - 栏目宽高不再设 240px 硬下限，允许拖到 0；关闭到 0 的栏按现有空栏回收规则处理
5. **悬浮预览与阅读空间**（反馈 6 / 8）
   - 悬浮窗底部动作行：指针移出即隐藏；按钮交互与卡片同款；补路径按钮（同卡片）；整组按钮起点后移一个按钮位
   - 阅读空间卡片路径按钮悬停只变文字色，不再铺底色
6. **AI 停靠**（反馈 10）
   - 停靠态下从卡片双击/打开按钮、`Ctrl+O` 打开文件必须落到普通内容栏并显示；不得把页签塞进 AI 栏
7. **HTML 编辑**（反馈 11 / 12）
   - HTML 可视化编辑工具条只在 HTML 编辑态出现，md 编辑态不出现
   - 选中区块后双击只定位光标，不选中邻近文字；选中区块可拖拽调整宽高（写回内联样式）
8. **大纲**（反馈 13）
   - 按钮距右缘恰为一个按钮宽（不含外边框）；未钉住无边框、钉住细边框（复述并收紧已有条款）
9. **页面宽度面板**（反馈 15）
   - 滑块上限 1400px；宽松档 1200px；三个刻度柱居中、并排相接、更窄更矮；进度条短于旧版但仍长于按钮组
10. **视频播放器**（反馈 16）
    - 进度条悬停显示当前位置缩略图；还原上一版按钮间距与高度；倍速/画面/二级菜单图标按原型规范；放大缩小补按钮、旋转移到字幕前；截图直接写剪贴板并弹胶囊提示；全屏态禁止展开二级菜单；视频快捷键并入快捷键总览；自绘图标统一尺寸、快捷键图标去外框

## Capabilities

### New Capabilities

（无。全部落在既有 capability 的 requirement 内。）

### Modified Capabilities

- `application-shell`：状态栏（改：主题图标光线等距、去下拉三角、自动布局图标换魔法棒）、分栏（改：最小尺寸取消、全屏按钮悬停显示）
- `navigation`：页签条与格头（改：拖拽禁选、选中态与图标分级、去栏目聚焦描边、右键菜单加悬浮小窗）、阅读空间卡片规格（改：路径悬停无底色）、悬浮预览窗（改：动作行自动隐藏与卡片同款、路径按钮、起点位移）、AI 两形态（改：停靠态打开文件落到内容栏）
- `reading`：PDF 预览（改：页码区无边框、外围底色跟随主题）、阅读宽度与面板（改：上限 1400、宽松 1200、刻度柱居中相接）
- `editing`：大纲浮层（改：距右缘一个按钮宽、未钉住无边框、钉住细边框）、HTML 可视化编辑（改：工具条归属、双击只定位、选中块可拖拽改宽高）
- `file-management`：C-6 视频预览播放器（改：进度条缩略图、控制条尺寸还原、图标规范、截图入剪贴板、全屏禁二级菜单、快捷键并入总览）
