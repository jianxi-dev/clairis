# Design: 界面细化与编辑器工具条批量修复（第六批）

## 背景

23 项反馈全部是视觉精度与交互手感问题，无数据层变更。设计上只做两件结构性的事：**给菜单落位立一条可复用的规则**（D-16），**把 md 编辑态的工具条来源统一到 md-bundle**（D-15）。其余是就地调整。

## D-1 顶栏移除

`App.tsx` 不再渲染 `Toolbar`。`components/Toolbar.tsx` 整个删除（当前只有品牌文字），`styles/editor.css` 里 `.app-chrome` 的顶栏规则若仅供它使用则删，若分栏内共用则保留并改名。验收看的是「窗口顶部没有一条只写产品名的横条」。

## D-2 沉浸入口图标化

`StatusBar` 里沉浸按钮去掉 `沉浸` 文字，只保留 `immersive` 图标；`title` 与 `aria-label` 保留「沉浸阅读（⌘⇧F）」，可访问名不丢。

## D-3 页签选中态

去掉选中页签的外描边（`outline`/蓝线），改为：选中页签底色提亮 + 文字主色，非选中页签文字降到 `--app-text-2`。判定基准是计算样式：选中页签 `outline-width: 0px`，且与非选中页签的 `color` 不同。

## D-4 页签区底边框去重

页签容器自身有 `border-bottom`，所在的栏目容器也有边框，两者叠在一起形成 2px 深色带。做法：页签容器不再画底边，边界由栏目容器承担；全屏（单格）与分栏两种形态的底边视觉必须一致。

## D-5 页签右键菜单图标

菜单项数据结构本就是 `{label, icon?, action}`；补齐 `icon` 字段即可，图标统一走 `src/ui/icons.ts` 的名称。无图标项（分隔线）不算缺。

## D-6 状态栏高度与显隐

- 高度：`py-1` 改为更矮的垂直内距（以计算高度断言，目标 ≤ 26px @ 默认字号）。
- 双击状态栏任意空白处切换隐藏；隐藏态渲染一条 0 高度触发器，`pointerenter` 后 500ms 显现，`pointerleave` 立即隐藏。用定时器而不是 CSS transition-delay，便于测试与取消。
- 隐藏态不影响 ⌘⇧\ 等全局快捷键。

## D-7 主题弹窗

主题按钮右侧加 chevron 图标；悬停（`pointerenter`）打开弹窗，列出 亮色 / 暗色 / 暖色 / 跟随系统 四项，点击即设并关闭。弹窗用 `createPortal` 到 body 定位在按钮上方，避免被状态栏的层叠上下文裁剪。数据源做成数组，后续加主题只加一项。

## D-8 主页入口

状态栏 `grid` 按钮前插入 `home` 按钮，行为 = 回到程序启动页（与启动时落点一致，复用现有「回首页 / 门户」动作，不新造路由）。图标 `home`，`aria-label="主页"`。

## D-9 页面宽度弹窗

点状态栏上的 `1200px` 打开面板：三档预设（窄/标准/宽，取现有合法档位）+ 一条滑块（与 `readerWidth` 合法区间同界）。拖动即预览，关闭面板保留当前值。值写入 `editorStore.config.readerWidth`，与既有持久化一致。

## D-10 阅读空间卡片底部行

- 图标尺寸从当前值降到 14；按钮点击热区仍用内距保证 ≥ 28px，不缩小可点区域。
- 「收藏」文案与 `bookmark` 图标换为 `heart`（空心/实心随状态）。
- 文件夹路径：默认即可交互（与右侧按钮同一 hover 底色变化），`title` 给出完整路径；长路径中段省略。
- 整行下移贴近卡片底边；同时修正卡片在最小高度下缩略图与进度条、底部行三者重叠的问题（给缩略图一个可压缩的最小高度，进度与底行各自占固定行高）。

## D-11 悬浮预览窗宽度与唤出区域

- 宽度：恢复上一版基准，再增加一个缩略图宽度。实现为「缩略图宽度」是唯一变量，其余是常量偏移，避免下次调宽又要改公式。
- 唤出判定：命中区域宽度等于缩略图宽度（贴在卡片缩略图一侧），指针落在缩略图左侧的正文区不唤出。

## D-12 悬浮窗底部动作行

默认不渲染；指针进入悬浮窗底部区域（高度约 36px）时浮现，与卡片内底部行同尺寸同图标，避免「看起来更大更蠢」。移出后隐藏。PDF 卡片同样适用（此前 PDF 卡片没有这一行，属缺陷）。

## D-13 图标造型

- `pin`：梯形下移 0.6 单位、斜杠 `M5 19L19 5` 缩短为 `M7 17L17 7`；`pinOff` 同源。
- md 图标去重：分栏图标按 1/2/3/4/5 画出真实分割比例；表格用封口网格（外框闭合 + 两条内线）；数据看板用「柱+折线」组合；插入 HTML 用 `</>`；插入 CSS 用 `#`；流程图用菱形+箭头；视频/文件拆成两个不同形；内嵌网页用「浏览器框 + 内容线」。剪切块换成「剪刀 + 虚线框」以外的直观形（刀口剪断一条虚线）。

## D-14 大纲边框

`OutlineMenu` 未钉住时 `border: none`；钉住时 `1px solid var(--app-border)`（比现状细一档）。

## D-15 工具条归属（md 复用 md-bundle）

- html 编辑态的两条工具条（格式条 + AI 改写条）只能在 html 编辑态出现；md 编辑态的入口不得挂到它们上面。
- md 的选区浮动工具条从 md-bundle 迁移能力与观感（改写/翻译/润色 + 格式组），图标复用 Clairis `icons.ts` 名称，不引入 md-bundle 的图标实现。
- 验收：md 编辑态选中文本后出现的按钮集合 == md-bundle 集合；html 编辑态选中文本不出现 md 那套。

## D-16 菜单落位：最短路径原则

统一一条规则，替换各处零散的 flip 逻辑：

1. 首选落点：触发元素正下方、左对齐。
2. 空间不足时按「移动距离最短」选择备选：上翻 → 左移 → 上翻且左移。
3. 任何情况下不超出视口 8px 边距。
4. 二级菜单：优先右侧对齐父项顶部；右侧不足则左侧展开（同样取距离最短）。
5. 手柄类菜单（新增/转换）跟随指针：以指针为锚点，应用同一套规则。

实现放在 `orchestration/placement.ts`（已有文件），导出单一 `placeMenu(anchorRect, menuSize, viewport)`，各菜单调用它，不再各写一套。

## D-17 新增手柄 hover 菜单

空行前的 `+` 手柄 `pointerenter` 即显示菜单（不再需要点击），菜单以指针为锚点按 D-16 落位；`pointerleave` 延迟 120ms 关闭以允许指针移入菜单。

## D-18 转换手柄菜单结构

- 缩进与对齐合并为同一项「对齐与缩进」，二级菜单包含：左/中/右对齐、减少缩进、增加缩进；对齐组带图标。
- 菜单宽度与新增手柄菜单一致（同一常量）。
- 标题项与无序列表项之间的前两行间距调低（减少 `padding`/`gap`）。

## D-19 颜色菜单二级不消失

当前二级（色板）在父菜单 `pointerleave` 时被一并关闭。改为菜单栈管理：打开二级时把父项标记为 `keepOpen`，父级关闭判断忽略 `keepOpen` 项，直到选择颜色或点击外部。

## D-20 撤销/重做快捷键

`keybindings.ts` 同时注册 `Mod-z` 与 `Ctrl-z`（以及 `Mod-Shift-z` / `Ctrl-Shift-z` / `Ctrl-y`）。CodeMirror 的 `Mod` 在 macOS 解析为 Cmd，故需显式加 `Ctrl-` 变体。HTML 编辑态的快照栈走同一键盘映射。

## D-21 视频倍速

`VideoPlayer` 控件区加倍速按钮，菜单 0.5/0.75/1.0/1.25/1.5/2.0；设置 `playbackRate` 同时确保 `preservesPitch`（含 `webkitPreservesPitch`）为 `true`，音高不变。切换视频/重新加载后重置为 1.0。

## 非目标

- 不做主题系统重构（只留扩展位）。
- 不改阅读杆卡片的数据来源与排序。
- 不动 PDF 渲染管线（第五批已交付）。
