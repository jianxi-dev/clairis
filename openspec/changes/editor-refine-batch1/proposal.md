## Why

editor-foundation-batch1 / editor-interaction-batch2 / editor-batch3-lowcost 三批归档后，用户 2026-11-23 验收反馈 8 类问题（spec issue #1386）：菜单行无可见快捷键区、文件名右键菜单仍是旧小圆角；高亮块三色面板无可达入口、标注菜单无高亮类型行；有序列表手柄图标退化成无序；图片编辑与 Quiet 差距集中（选中态/缩放/裁剪标识/拖动柄/常驻/多余「保存」文字/描述区常驻/手柄偶发缺失）；转换手柄按块显示不跟行走；附件手柄沿用图片图标；表格/高亮块手柄落左上角；附件卡多格式效果未实现。这些多为本仓已登记 requirement 未真正生效或仅覆盖一半面，验收口径是**把 contract 落到可见行为**，而非新增能力。对账已确认：#5 选豆包式行手柄，#8 高度选①（自适应 + 600px 上限 + 内部滚动 + 底缘渐隐），其余全按默认。

## What Changes

- **菜单快捷键区 + 圆角统一**：块菜单 / 浮条 / 轮盘 / 文件名右键菜单每行右侧新增可见快捷键显示区（kbd 样式，无快捷键留白）；文件名右键菜单容器接入菜单圆角 token，旧小圆角字面量移除。
- **高亮块调色入口 + 高亮类型行**：点击高亮块 → 上方浮条出现颜色图标 → 点开可调填充/边框/文字三色（复用批次 3 已交付的三色面板与一次改色一步撤销）；标注类子菜单顶部新增「高亮类型」单行（既有类型预设含「纯高亮」置于顶部）。
- **有序列表手柄图标还原**：图标映射还原有序编号图标，与无序区分；映射仍按首行内容判定。
- **图片编辑 Quiet 对标八件**：编辑图标选中态、编辑态图片保持原尺寸不缩小、裁剪角标加大、裁剪样式拖动柄、裁剪态常驻（单次拖动不弹回）、移除「保存」文字、描述区默认隐藏仅按钮控制显隐（裁剪态强制隐藏）、修复《中汽系统搭建情况对称1110.md》图片手柄偶发缺失。
- **豆包式行手柄**（对账 #5 裁决）：手柄按可视文本行显示，每行一个跟行走；层级联动转换——上级行手柄转换联同下级一起转换，末级行只转当前行；子级按自身层级编号规则排号；有序/无序列表转高亮=外套高亮、列表保持原格式；表格/代码块等非文本行块不产生行手柄。
- **附件手柄图标**：转换手柄图标按附件扩展名映射为附件类图标，机制同图片扩展名映射。
- **手柄位置统一**：表格与高亮块的手柄位置统一到块左侧垂直居中，不再落在左上角。
- **附件卡多格式效果**：md 默认展开（宽度=正文同宽；高度自适应 + 上限 600px + 内部滚动 + 底缘渐隐）；md/docx 提供样式调整面板（对齐+宽度，面板式同图片）；docx 提供显示位置（对齐）调整；修复附件引用行首加空格后整块退化为源码的 bug。

无 **BREAKING** 外部契约变更；手柄由「块级单手柄」改为「文本行级行手柄」属编辑态交互契约的 internal 变更，由 `editing` requirement 显式 supersede。

## Capabilities

### New Capabilities

- 无新增能力域。

### Modified Capabilities

- `editing`：
  - 菜单快捷键列与菜单圆角统一（块菜单 / 浮条 / 轮盘 / 文件名右键菜单）。
  - 高亮块调色入口与高亮类型行（浮条颜色图标 + 标注子菜单类型行）。
  - 豆包式行手柄：行级显示、跟行走、层级联动转换、列表转高亮外套保留。
  - 块手柄图标与位置：有序列表图标还原、附件扩展名图标、表格/高亮块手柄左侧垂直居中。
  - 图片编辑 Quiet 对标：选中态、不缩小、裁剪角标、拖动柄、裁剪常驻、去「保存」文字、描述区显隐、手柄缺失修复。
  - 附件卡多格式：md 展开尺寸/滚动/渐隐、md/docx 样式面板、docx 位置、空格退化回归。

## Impact

- 前端编排层：`src/editors/orchestration/block-handle.ts`（行手柄渲染、图标映射、位置）、`block-menu.ts`（快捷键列、三色面板入口）、`block-convert.ts`（层级联动转换）、`floating-toolbar.ts`（高亮块颜色入口）、`menu-metrics.ts` / `src/styles/editor.css`（菜单 token 与 kbd 样式）。
- 装饰层：`src/editors/decorations/image.ts` / `imageCrop.ts` / `imageToolbar.ts`（图片编辑八件）、`fileEmbed.ts`（附件卡多格式）、`callout-attrs.ts` / `callout-types.ts`（高亮类型与颜色属性）。
- 组件层：`src/components/TabBar.tsx`（文件名右键菜单圆角与快捷键列）。
- 图标：`src/editors/icons.ts`（块手柄图标注册表；有序编号 / 附件扩展名图标条目，若词表缺条目则补）。
- 测试：`src/__tests__/**` 纯函数单测（行↔块映射、层级联动转换、扩展名→图标）+ `e2e/*.spec.ts`（可见行为）+ `e2e/tauri/`（图片/附件状态机）。

- 数据面：本 change 不触及配置字段 / 主题 / 图标注册表等可配置面（手柄图标映射为代码内常量，非配置面）。若实施中发现触及，须回填 design.md「## 数据面」六栏表。
