## Why

batch19 汇集用户 2026-11-14 反馈的 21 项编辑表面问题（9 缺陷 + 7 优化 + 5 新增，父规格票 #833）：手柄与菜单「该消失不消失 / 该出现不出现」、mermaid 手柄定位失稳、分栏与表格单元格退化为源码、编辑态边框宽度不一致、图片工具条状态错误，以及新增手柄菜单结构、插入文件内嵌渲染、标题逐级字体、左边栏固定隐藏等。这些问题直接阻断编辑动作，或破坏编辑态与预览态的一致性预期。

## What Changes

- 手柄与菜单：A1 二级菜单移出消失、显示期间不误触发下层手柄；A3 mermaid 手柄识别与菜单贴合；A8 图片 / 视频手柄补六点并与标题手柄对齐；A2 提示外壳统一胶囊。
- 分栏与单元格：A4 分栏进入不重复显示、移除无意义小方框、`+` 滑入显示菜单、间隔线可见；A5 单元格 / 分栏内外渲染一致；A9 表格手柄与单元格菜单复用全局菜单。
- 渲染与边框：A6 代码块 / 引用块 / mermaid 边框与正文文本块对齐。
- 图片工具条：A7 裁剪选中态且不自动缩小、描述默认隐藏、更换「添加描述」图标。
- 菜单重构：B1 新增手柄菜单分「基础」（纯图标）与「常用」（带文字）；B3 分栏弹窗加说明与实时已选栏数。
- 状态栏与页签：B2 页面宽度弹窗进度条与选中块同色；B4 页签右键「移动到」换图标、「导出」hover 展开二级；B7 页签名下拉信息窗（文件名 / 可点击路径 / 最近保存时间）。
- 插入文件：B5 pdf / md / html / 内嵌页面内嵌渲染，默认一屏高、可调高宽、可滚动、滚动定格、悬浮预览、新标签页打开。
- 工具条回滚：B6 md 编辑态选中文字的横向工具条回滚到上一版。
- 新增能力：C1 标题逐级自定义字体（默认取 md-bundle 预览态字体）；C2 栏目页签空白处拖动移动窗口；C3 左边栏固定隐藏 / 显示 + 快捷键 + 设置开关；C4 文本 / 脚本文件行号与预览态语法色；C5 颜色菜单「恢复默认」。
- **BREAKING**（内部 API）：新增手柄菜单项集合与顺序、页签右键菜单项图标 / 承载、标题字体配置字段新增。

## Capabilities

### New Capabilities

- 无新增能力域；B5 内嵌文件渲染归入 `reading`，C1 标题字体归入 `reading` + `configuration`。

### Modified Capabilities

- `editing`：E-17 手柄召唤与滑入菜单（A1 / A3 / A8）、E-22 编辑态悬停提示胶囊化（A2）、E-8 编辑态与预览态同貌（A6）、E-12 单元格富文本编辑（A5 / A9）、E-11 块菜单结构与图标体系（B1 / B3）、E-35 图片描述默认隐藏与切换（A7）、选区浮动工具条（B6）、颜色面板二级保持（C5）；新增「文本与脚本文件行号」（C4）。
- `reading`：预览分栏渲染（A5）、A-10 阅读宽度与标题配色（C1）、新增「内嵌文件渲染」（B5）、新增「文本与脚本预览语法」（C4）。
- `navigation`：页签条与格头（B7 / C2）、页签右键菜单文件动作（B4）、左边栏展开与固定快捷键（C3）。
- `application-shell`：G-12 页面宽度四档与悬停弹窗（B2）、G-12 分栏语义与分隔线独立性（A4）。
- `configuration`：新增「标题字体逐级配置」（C1）、CF-6 阅读设置归属与设置窗自适应（C3）。

## Impact

- 前端：块手柄 / 菜单 / 浮层（`src/editors/orchestration/*`、`src/editors/decorations/*`）、图片工具条、分栏与单元格装饰、页签与左边栏、状态栏宽度弹窗、颜色面板、设置面板。
- 配置：`src-tauri/src/config.rs` 新增标题字体字段（C1）与左边栏固定隐藏开关（C3）；`src/hooks/useConfig.ts` 桥接。
- 图标：`src/ui/icons.ts` 与 `src/editors/icons.ts` 同步（A7 / A8 / B4）。
- 测试：菜单 / 手柄 e2e、内嵌文件 e2e、字体配置与设置开关 e2e、行号与预览语法 e2e。
- 无后端命令新增、无导出管线改动、无依赖变更。
