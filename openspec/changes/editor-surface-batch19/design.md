# 设计 — editor-surface-batch19

来源：spec issue #833；需求四要素 `docs/requirements/editor-surface-batch19/requirements.md`（含 L-1 需求输入包）。

## D1 手柄菜单生命周期与 mermaid 定位（A1 / A3 / A8）

- A1：二级菜单（对齐与缩进、在下方添加行）显示后，指针移出「父菜单 ∪ 二级面板」并集即自动消失；菜单栈打开期间进入全局禁召唤会话——指针在下层文字移动 SHALL NOT 触发新的新增 / 转换手柄，栈关闭后恢复。
- A3：mermaid 块手柄的定位以**块装饰的屏幕矩形**为锚（与单元格 / 容器菜单同一条锚定规则），不得停在其边框右上角；「使用图标增强表现」处须能识别出手柄（块型判定不得被图标增强语法误判为普通段落）；「伪动画时间轴」展开的转换菜单垂直中心与手柄中心偏差 ≤2px，不脱离。
- A8：图片 / 视频转换手柄图标补齐拖拽四点（六点手柄），显示位置与标题手柄对齐（同一召唤区与同一中心线）。

## D2 提示外壳统一（A2）

一切自绘悬停提示只渲染一种外壳：胶囊（圆角半径 ≥ 提示高度的一半），与设计系统 §6 语义色一致；SHALL NOT 出现矩形外壳。同一类提示（按钮提示、轮盘扇区提示、页签名信息窗）共用同一外壳常量，消除「时胶囊时矩形」。

## D3 分栏与单元格渲染一致（A4 / A5）

- A4：点击进入分栏栏目 SHALL 聚焦已有内容，不得重复显示同一段文字；移除栏目左上角无意义小方框（DEFAULT＝移除）；栏目前 `+` 鼠标滑入保持可见并显示选择菜单（复用 E-26 分栏选择）；分栏之间的间隔线 SHALL 可见（最小 1px，取设计系统分隔线 token）。
- A5：分栏内容区与表格单元格的「内」渲染 SHALL 与「外」正文一致——单元格 / 分栏内都按正文渲染（标题、列表、粗斜体、代码），SHALL NOT 退化为源码格式。编辑态容器内边距 / 边框宽度由 E-8 统一，本条只约束渲染一致性。

## D4 编辑态边框对齐（A6）

代码块、引用块、mermaid 块在编辑态的左右边框 SHALL 与正文文本块的左右边框对齐，且三者彼此一致；宽度补偿通过块自身最大宽度 / 内边距实现，SHALL NOT 改动 `.cm-line` 基础行宽（沿用 E-23 块宽度统一）。边框线宽取设计系统分隔线 token。

## D5 图片工具条状态（A7）

- 点「裁剪」进入裁剪态：裁剪按钮呈选中态；裁剪后图片显示尺寸取裁剪矩形比例，SHALL NOT 自动缩小（保持既有缩放锚点）。
- 「添加描述」默认未选中、描述输入区默认隐藏；点「添加描述」转选中并显示输入区（延续 E-35）。
- 「添加描述」图标更换为 ic-image-caption 语义图标（实现票按 `src/editors/icons.ts` 命名约束选定），图标与文字贴合。

## D6 表格手柄复用全局菜单（A9，依赖 B1）

- B1 先行：A9 SHALL 复用 B1 之后的全局新增 / 转换菜单组件与项集，单元格入口不得另立菜单。
- 鼠标滑入表格显示表头转换手柄（表格图标 + 六点拖拽）；滑入单元格显示单元格转换手柄与单元格新增「+」手柄（参考三张截图）；单元格转换 / 新增手柄菜单与全局菜单观感一致。
- 行列手柄补齐：表格上缘 / 左缘的行列插入热点不得只剩孤立灰点（当前截图只有 2 / 3 个点）。

## D7 新增手柄菜单重构（B1 / B3）

- 新增手柄菜单分两段：**基础**只显示图标（仿转换手柄），顺序 H1~H3 标题、有序列表、无序列表、任务、引用、分割线、代码块、链接；**常用**显示文字，含标题、高亮、分栏、表格、图片、视频或文件、公式、内嵌网页。
- 两段沿用 E-11 的菜单宽度 / 行高常量；基础段每格只显示图标，常用段图标 + 文字。
- B3：新增手柄的「分栏」弹窗顶部加说明文字「选择栏目」；选择时上方实时显示已选栏数（复用 E-26 的 5 根柱子滑选）。

## D8 状态栏页面宽度弹窗配色（B2）

进度条颜色与 4 档中被选中块颜色一致，其余 3 档使用相近色（同一色相、降低不透明度 / 明度区分）；色值取设计系统 §6 语义色，不新增色板。

## D9 页签菜单与信息窗（B4 / B7）

- B4：页签右键「移动到」图标更换为不与「打开文件位置」重复的图形；「导出」子菜单鼠标滑入即自动展开二级（无需点击），移出父项后保持可见（与 E-11 颜色面板二级保持同规则）。
- B7：页签名悬浮提示改为下拉信息窗（参考《文件信息》截图）：① 文件名（最大字号）；② 完整路径，每层文件夹可单击打开（在文件管理器中定位该层）；③ 最近保存时间。外壳为胶囊卡片。

## D10 插入文件内嵌渲染（B5）

- pdf / md / html / 内嵌页面等插入后内嵌真实内容渲染，SHALL NOT 只显示文件名 / 链接。
- 默认一屏高；可调整显示高宽；内容可滚动。
- 滚动定格：滚动到某区域后鼠标滑出即定格，再次打开保持该定格（DEFAULT＝持久化到文档级 view-state，复用 `scroll_positions` 结构）。
- 可切换「只显示文件名 / 链接」或「显示内容」；仅显示名称 / 链接时鼠标滑入弹出悬浮窗预览内容（复用既有悬浮预览窗）。
- 点击支持本产品打开的链接文件，在新标签页打开。

## D11 工具条回滚（B6）

md 编辑态选中文字的横向工具条按钮功能回滚到上一版：以 Git 历史中最近一次可用的工具条实现为基准恢复按钮集合与行为，SHALL NOT 叠加本批其他工具条改动。回滚范围限定 md 编辑态横向工具条，HTML 可视化编辑态工具条不受影响。

## D12 标题逐级字体（C1）

- 每一级标题（H1–H6）可自定义字体，字体从本机已安装字体中选择。
- 默认字体＝md-bundle 预览态字体（`--type-font-sans`，来源见 L-1 第 6 条），与 E-8 现状一致。
- 配置落点：`heading_fonts`（结构化字段，按级别键控）；编辑态与预览态共享该配置（标题面覆盖，正文 / 代码字体不变）。

## D13 窗口拖动（C2）

鼠标点按「栏目页签空白处」并移动可拖动窗口：空白处为页签条未被页签 / 按钮占据的区域；按下并移动超过阈值后进入窗口拖动（调用 Tauri 窗口拖动），未超阈值视为点击。

## D14 左边栏固定隐藏 / 显示（C3）

- 新增「固定隐藏」态与快捷键：隐藏后鼠标滑入触发区也不显示，左侧箭头区域彻底消失；取消固定后箭头恢复、鼠标滑入自动显示。
- 设置中增加对应开关；配置落点 `rail_pin_hidden`（布尔）。
- 与既有 `railState`（collapsed / hover / pinned）三态衔接：固定隐藏是 collapsed 的强化态，箭头热区一并收起。

## D15 文本 / 脚本行号与预览语法（C4）

- 编辑态对非 Markdown 的纯文本 / 脚本（代码）文件显示行号；Markdown 编辑态仍遵守 E-8「无行号槽」。
- 预览态支持语法颜色显示与代码块缩进格式（复用既有代码高亮 token 与语言别名表）。

## D16 颜色菜单恢复默认（C5）

颜色菜单在背景色下方新增「恢复默认」按钮：点击后把字色 / 背景色恢复为文档默认（清除 `mdb-color-*` 与背景标记），按钮与既有色板项同宽、取设计系统语义色。

## D17 测试取点

- 手柄 / 菜单：二级菜单节点数（移出→0）、显示期间下层手柄节点数（0）、mermaid 手柄与菜单中心偏差（≤2px）、表格手柄节点与位置。
- 分栏 / 单元格：进入分栏后重复文本数（0）、间隔线可见、单元格渲染节点（非源码）。
- 边框：代码块 / 引用块 / mermaid 与正文左右边框 x 坐标差（0）。
- 图片：裁剪按钮选中态、裁剪后显示尺寸、描述输入框 display、图标 path 变更。
- 菜单重构：基础段纯图标（文字节点 0）、常用段文字、分栏弹窗说明与实时栏数。
- 内嵌文件：iframe / 内嵌节点存在、默认高度、可调、滚动定格（重开保持）、名称态悬浮预览、链接新标签页。
- 字体：标题计算 font-family 等于配置值；默认等于 `--type-font-sans`。
- 设置：左边栏固定隐藏开关写入配置并生效；行号节点存在；预览语法 token 存在；颜色菜单「恢复默认」项存在。
