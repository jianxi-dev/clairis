# Biaoyue（标月）

桌面 Markdown 阅读 / 编辑器 —— Tauri 2 + React 18 + TypeScript，前端 Vite + CodeMirror 6 + Zustand，Rust 后端在 `src-tauri/`。

## 从这里开始

| 你想做什么 | 去哪里 |
| --- | --- |
| 浏览全部文档（产品 / 架构 / 设计 / 研究 / 交付 / 历史） | [docs/README.md](./docs/README.md) |
| 了解 Agent 如何读取本仓库与项目约定 | [AGENTS.md](./AGENTS.md) |
| 查共享词汇表与架构决策摘要 | [CONTEXT.md](./CONTEXT.md) |
| 看变更记录 | [CHANGELOG.md](./CHANGELOG.md) |
| 看本次文档迁移的逐项去向与账目 | [docs/MIGRATION-REPORT.md](./docs/MIGRATION-REPORT.md) |

文档的唯一权威入口是 [`docs/README.md`](./docs/README.md)；本文件只做项目级导航，不复制产品正文。

功能行为规格真相源在 `openspec/specs/`，进行中变更在 `openspec/changes/`。
