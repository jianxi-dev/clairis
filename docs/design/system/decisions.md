## 维护规则

1. **新增行**：任何一次"用户在真机上裁决了一个具体视觉参数"都必须落一行，否则同一争论会重开。
2. **行格式固定四列**：部件 / 决定 / 出处 / 日期。出处写票号或 PR 号；**已落地的行必须带 PR 号**，仅原型阶段的裁决写评审轮次并标注是否落地。
3. **不写推断**：台账只登记已发生的裁决，不写"建议""可以考虑"。
4. **不复制到别处**：任何设计稿或规格文档需要引用某行时写"见台账 <部件>"，不复制内容。
5. **一行只讲一件事**：一个部件同时改了尺寸和边框，拆两行。
