# A-5 沉浸式阅读设计规格 v2

> 来源：July 12, 2026 印哥 + Hermes 设计讨论 → Codex R1 对抗复审
> 变更：移除 snapshot/soft-exit/Cmd+Option 触发。沉浸，只有两个状态。
> 阶段：Phase R

---

## 1. 核心哲学

沉入或浮出。没有"半沉浸"，没有"试探着下沉"，没有"恢复你进入前的状态"。

渐晰的沉浸是一口呼吸——要么在，要么不在。

---

## 2. 进入沉浸

### 2.1 触发

| 触发器 | 行为 |
|--------|------|
| `Cmd+\` | 切换沉浸（进入/退出） |
| 读完文档触发收卷后 | 进入下一篇时自动进入沉浸 |

### 2.2 过渡动画

0.3s，所有 chrome 淡出（opacity + 微 translateY）。主文档区不动。

```
0ms:   当前状态
0-300ms: 工具栏 opacity 1→0, translateY 0→-3px
          侧栏 opacity 1→0, scale 1→0.98
          Tab 栏 opacity 1→0
300ms: 沉浸态
```

### 2.3 不做 snapshot

进入沉浸前不记录任何状态。工具栏可见性是独立的长期偏好，与沉浸无关——工具栏隐藏的用户的工具栏永远隐藏，工具栏显示的用户的工具栏永远显示。

---

## 3. 沉浸态内部

### 3.1 浮出 chrome

| 操作 | 行为 |
|------|------|
| 鼠标移动到屏幕上边缘 2px 悬停 > 400ms | 工具栏淡入（同 opacity 过渡） |
| 鼠标移出上边缘 2s 后 | 工具栏淡出 |
| `Shift+Cmd+T` | 切换所有 chrome 显示/隐藏（按住松开的 toggle，不是按住保持） |

**Cmd+Option 不参与**——避免与 `Cmd+Alt+1/2/3/4`（P1 场景切换）和 macOS 系统快捷键冲突。

### 3.2 沉浸态字号调整

`Cmd+=/-`：字号 +1/-1，范围 12-32。改的是全局字号（同 A-6 主逻辑），所有元素按倍率跟随。无数字提示浮现。

---

## 4. 退出沉浸

| 操作 | 视为 |
|------|------|
| `Cmd+\` | 切换退出 |
| `Esc` | 退出（不再区分轻退出/完全退出，一个 Esc 直接退） |
| `Cmd+↑` Desk | 退出 + 打开 Desk |
| `Cmd+P` 文件面板 | 退出 + 打开面板 |
| `Cmd+N` 新建 | 退出 + 新建 |
| `Cmd+O` 打开 | 退出 + 文件选择器 |
| `Cmd+W` 关闭 | 退出 + 关闭当前文档 |

**退出过渡：** 0.3s 淡入。工具栏回到用户设置的可见性状态（独立偏好，不改）。

---

## 5. 特殊场景

### 5.1 编辑态进入沉浸

不弹确认，不直接保存。沉浸只隐藏 chrome，不触发任何文件操作。

光标位置用现有 `cursorPos` 字段在沉浸退出后恢复。无新增字段。

进入路径：`Cmd+\` 切换沉浸 → 0.3s 过渡 → 沉浸态编辑区（工具栏隐藏）

退出路径：`Esc` / `Cmd+\` → 0.3s 淡入 → 工具栏回到用户设置的可见性状态，光标位置还原

### 5.2 分屏 + 沉浸

分割线在沉浸态不显示。两个文档并排。字号跟随全局（单字号，见 A-6 R2 单轨道）。

### 5.3 全屏 + 沉浸

macOS 原生全屏下正常工作。退出 Esc 只退沉浸，不退全屏。再次按 macOS 全屏控制或 `Ctrl+Cmd+F` 才退全屏。

---

## 6. 字号与沉浸

字号是全局状态，沉浸态不创建独立字号。

沉浸态 Ctrl+=/- → 改全局 `fontSize`，退出沉浸态后字号不变（因为一直是同一个值）。

存储：现有 `config.json.fontSize`，零新增字段（详见 A-6 R3 §7 Store 变更）。

---

## 7. 不做的事

1. **不做"软退出"/"轻退出"**——二元状态
2. **不做 Pre-Immersion Snapshot**——工具栏可见性是用户偏好，不随进出翻转
3. **不做 Cmd+Option hold-to-reveal**——用 Shift+Cmd+T toggle
4. **不做"沉浸式主题"切换**——P2 仪式系统处理
5. **不做"自动进入沉浸"设置**——用户主动触发
6. **不做全窗口 blur/focus 检测**——只在用户操作时响应

---

## 8. 验收标准

| # | 场景 | 预期 |
|---|------|------|
| 5.1 | 工具栏可见时按 Cmd+\ | 0.3s 淡出，进入沉浸 |
| 5.2 | 沉浸态按 Esc | 0.3s 淡入，退出沉浸 |
| 5.3 | 沉浸态按 Cmd+\ | 5.2 同上 |
| 5.4 | 沉浸式鼠标移悬屏幕顶部 >400ms | 工具栏淡入，移走 2s 后淡出 |
| 5.5 | 沉浸态 Shift+Cmd+T | 切换 chrome 显示/隐藏（toggle） |
| 5.6 | 编辑态 dirty 按 Cmd+\ | 直接进入沉浸，不弹确认 |
| 5.7 | 读完触发收卷 | 退出沉浸 |
| 5.8 | 关闭沉浸文档再打开 | 工具栏保持用户设置的可见性 |
| 5.9 | 全屏+沉浸 | Esc 只退沉浸，全屏保留 |
| 5.10 | 分屏+沉浸 | 分割线隐藏，两文档字号相同 |
