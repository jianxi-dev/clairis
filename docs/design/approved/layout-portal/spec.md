## 0. 设计哲学（构建时必须遵守）

**总纲**：少即是快——把复杂性留给系统，把界面还给内容。

| | 原则 | 落地要求 |
|---|---|---|
| P1 | 不用不显示 | 次级动作/文字/图标一律 hover 才显；低频控件收进下拉或「更多」 |
| P2 | 所见即可操作 | 卡片数字直开、路径点穿、分栏拖换位、悬浮窗拖缩放 |
| P3 | 一致即成习 | 一图标一概念、一类型一颜色、快捷键三级家族 |
| P4 | 可塑即可久 | 视图规格/配置/扩展皆文本，用户与 AI 可改；扩展包拷入即用 |
| P5 | 可逆即敢用 | 确认卡（人话）+ 快照 + 撤销，覆盖一切 AI 改动 |
| P6 | 默认即成 | 精选默认（卡片+堆叠、285×260 小窗、点击预览）、零门槛、生成物离线可看 |

**12 条红线**：见设计哲学文档；构建验收逐条打勾。

## 2. 门户（启动首屏）

| 元素 | 规格 |

## 3. 工作区：pane 递归树

**数据模型**
```
node = { id, dir: 'row' | 'col', ratio: 0..1, children: [node, node] }
leaf = { id, tabs: [fileId], activeTabId }
```

**规则**
- **分裂**：对聚焦 leaf 右分（`dir:'row'`）/下分（`dir:'col'`）；新 leaf 获得焦点
- **关闭**：关最后一页签 → 删除 leaf，兄弟扩展；根 leaf 不显示关闭
- **最小尺寸**：240px（宽与高）；分隔条双向拖拽；比例持久化
- **全屏**：`⌘⇧↵` 或格头按钮；全屏时隐藏其他格与分隔条；再按/`Esc` 恢复
- **页签**：每格多页签；`⌘T` 新页签（当前格）；`⌘W` 关页签（最后一签关格）；拖拽排序；页签 = 类型色图标 + 标题 + ×
- **拖拽换位**：拖格标题栏 → 落别格**中心=互换**、落**四边=移动重排**、落**窗口边缘=移到根层**、`Esc` 取消；与「拖文件到四向落区=在该格分裂/替换」严格区分
- **模式**：预览 / 编辑 / 源码；`⌘⇧M` 循环；格头模式图标点击 = 预览↔编辑；源码在 ⋯ 菜单
- **格头**：页签条；右侧 = 模式图标 · **全屏**图标 · ⋯
- **⋯ 菜单（7 项，均带图标）**：导出 / 分享 / 右分 / 下分 / 源码模式 / 定位 / 复制路径（**不含全屏**）
- **持久化**：布局树（结构/比例/页签/活动页签/焦点）序列化，重启恢复

## 4. 阅读空间（左侧竖排栏）

**三态**
| 态 | 规格 |
|---|---|
| 折叠 | 12px 边缘条 + 文件计数徽标 + chevron；正文满宽 |
| 悬停浮层 | 240px，**absolute 覆盖，不挤压正文**；移开 300ms 收回 |
| 钉住 | 240px，flex 常驻，正文变窄（min-width:0） |

**头部**（左→右）：标题/模式签 · 弹簧 · **滑杆下拉** · **钉住** · 收起
**滑杆下拉**（低频控件收纳，P1）：布局（堆叠/标签）· 密度（紧凑/舒适/卡片）· 快照（查看/恢复）· **设为默认**

**段**（堆叠布局下）：现在 / 置顶 / 最近 / 分类
**布局两式**：堆叠（段叠放 + 粘性段头）/ 标签（分段页签 + 单列表）
**分类**：**过滤 chips**（全部 + 8 类，带计数），点击过滤——**不使用瀑布式分类行**

**密度三档（默认为「卡片」）**
| 档 | 高度 | 内容 |
|---|---|---|
| 紧凑 | 32px | 类型图标 + 标题（1 行）+ 时间（右） |
| 舒适 | 56px | 类型图标 + 标题 + 第二行「父路径 · 时间」+ 置顶标 |
| 卡片 | **112px**（默认；`density.cardHeight` 可调 88–160） | 见下 |

**卡片（卡片密度）**
- 左：**彩色类型图标**（18px）+ 标题（粗体 1 行，可换 2 行）
- 摘要：**真内容 2 行**；**无缩略图时通栏**
- 右：**4:3 缩略图**（72×54）——有图 MD（首图）/ HTML（橙页）/ PDF（红文档页）/ 视频（紫海报+播放）/ 图片（真图）/ 音频（粉波形）；纯文本与无图 MD 无缩略图
- chips：类型 chip（类型色）+ 置顶标；**无「已生成」标签**、**无书签**
- meta：**任务进度（有任务）或 阅读进度（无任务）** + 日期 + 文件夹名（**路径文字可点 → 在 Finder 中显示；无 folder 图标**）
- 选中态：柔和强调底
- hover 动作（**右上角、纯图标、无底衬、不压缩略图**）：打开 / 分屏→ / 分屏↓（定位已移除，路径可点替代）

**搜索**：顶部粘性；即时过滤 + 命中高亮；内置 **×** 清除（有内容才显示，清空后保持聚焦）；`Esc` 先清后收

**默认值**：密度=卡片、布局=堆叠；「设为默认」写入视图规格，AI 也可改

**与网格搜索**：**完全独立**（各自查询/筛选、各自记忆）

## 5. 网格概览

**打开**：`⌘⇧\`；**不聚焦搜索框**，默认选中**第一张卡**

**顶部单行**：搜索（`/` 聚焦，× 清除）· **类型下拉** · **排序下拉** · **分组下拉** · 网格/列表 · 结果计数
（**所有顶部控件用下拉，禁止点击循环**）

**Tile 规格（4 列）**
| 类型 | 尺寸 | 内容 |
|---|---|---|
| 大 | 2×2 | 仅置顶/继续阅读；标题 + meta + 4–6 行真摘要 + 进度 |
| 中 | 2×1 | 标题 + meta + 2–3 行 |
| 小 | 1×1 | 类型图标 + 标题（+2 行，纯文本可到 2–8 行按尺寸自适应） |

- **缩略图优先**：4:3 预览区（图片真图 / PDF 文档页 / 视频海报+播放 / HTML 渲染页 / 有图 MD 首图 / 纯文本真实排版预览）
- 类型色 **2px 顶条**；标题 + 日期 · 文件夹（可点穿透）+ 进度条
- hover：轻微上浮 + **右上角图标动作**（打开 / 分屏→ / 分屏↓）
- 分组：时间粘性头（今天/昨天/本周/更早）；筛选：类型 / 置顶
- **无「详细」开关**（默认全详细）；内容随卡片尺寸与类型自适应

**键盘（定稿语义）**
| 键 | 行为 |
|---|---|
| `j` / `k` | **上下整行切换（一行一行）** |
| `h` / `l` | 行内左右一张 |
| `PageDown` / `PageUp` | **整页**（scrollTop ±= 容器高 − 24px） |
| `Home` / `End` | 首 / 尾 |
| `Enter` | 打开；`⌘↵` 分屏；`⇧↵` 定位 |
| `/` | 聚焦搜索；`Tab` 切筛选；`Esc` 先清搜索再关闭 |
| 按住 `⌘` | 显示**当前视口**卡片编号 1–9（滚动/翻页/筛选后重算） |
| `⌘1–9` / `⌘⇧1–9` / `⌘⌥1–9` | 当前格打开 / 右分 / 下分 第 N 张 |

## 6. 悬浮预览窗

| 项 | 规格 |
|---|---|
| 内容 | **真文档渲染**（标题/段落/引用/列表/代码/媒体占位），内部滚动 |
| 尺寸 | 最小 260×200；**四边 + 四角**拖拽缩放；贴边翻转时锚定边互换 |
| 锚定 | **阅读空间：x 恒定 = 栏右缘 + 12，y 跟随悬停行**（不跟随鼠标横向，不左右跳）；网格：贴卡片右缘 + 12，y 贴卡顶 |
| 交互 | 标题栏拖动（位置保持到关闭，重开回默认锚定）· `×` 关闭 · 钉住 · 底部动作区（**hover 才显**：打开 / 分屏→ / 分屏↓；路径文字可点） |
| 开关 | 阅读空间悬停：默认开（250ms）；网格：悬停 / **点击（默认）** / 关闭——二者独立 |
| 会话记忆 | 拖动位置保持到关闭；关闭后下次重新锚定 |

## 7. AI

| 形态 | 规格 |
|---|---|
| **唯一入口** | 顶栏星芒图标（全产品仅此一个） |
| **小窗（默认形态）** | **285×260**，默认**右下角**（距边 16px）；标题栏拖动；**四边四角缩放**；`×` 关闭；头部「停靠到右侧」→ 嵌入窗格 |
| **嵌入窗格** | 插入分栏树（默认右侧 28% 宽）；可拖宽/关闭/再分；⋯「脱离为小窗」；与小窗**共享同一对话历史** |
| 快捷浮层 | `⌘K` 单发指令（非模态底部） |
| 选区动作 | 选中正文 → 浮动胶囊（AI 改写 / 翻译 / 润色）→ 前后 diff → 应用 |
| 确认卡 | **人话描述**（禁技术语言）；三档密度：每次必弹 / **本会话总是后静默（默认）** / 不弹只靠撤销 |
| 可逆 | 撤销条（3s 淡出、hover 重现）+ 快照（最近 10 份） |
| 视图改写 | 可改：布局/密度/卡片高度/区块颜色/图标内外显隐/预览开关/面板宽窄；预设 6 条：按主题分组 / 只留置顶和最近 / 置顶段放大 / 网格改列表 / 网格按类型分组 / 加未读筛选 |
| 语音 | 第二输入源；每个输入面挂麦克风；正文三件套（状态栏连续听写 / `⌘⇧Space` PTT / 选区替换）；草稿=浅灰斜体 decoration（不落盘），停止=普通事务（可撤销）；ASR 引擎留待定 |

## 9. 扩展

- **形态**：文件夹（`manifest.json` + `SKILL.md`），可打包传播
- **导入**：拖入文件夹 / .zip 或点击选择 → **即启用**（无安装步骤）
- **管理**：列表（名称 / 来源徽章 内置|AI 生成 / 启用开关 / 打开文件夹 / 卸载）
- **导出/分享**：把自定义扩展打包
- **AI 生成**：输入「说出你要的功能」→ 生成中 → 新扩展卡（默认启用）+ SKILL.md 预览

## 10. 图标体系

- **源**：universe-icon（24×24 viewBox、`fill="currentColor"`、18（密集）/24（主操作）px）
- **哲学**：一概念一图标；同概念全产品同图标；不混风格；**禁 emoji**
- **标签三级**（设置）：自动（主入口图标+文字，重复处仅图标）/ 始终显示文字 / 仅图标
- **类型色（8 类）**：Markdown `#6366f1` · HTML `#f59e0b` · 文本 `#64748b` · PDF `#ef4444` · 视频 `#a855f7` · 图片 `#10b981` · 代码 `#06b6d4` · 音频 `#ec4899`
- **图标抽屉**：设置内可查看全部在用图标（名称/尺寸/已有-新绘）

## 11. 快捷键（定稿表）

**全局**
| 键 | 行为 |
|---|---|
| `⌘P` | 统一检索（文件 + AI 指令） |
| `⌘\` | 阅读空间展开/收起 |
| `⌘⇧\` | 网格概览 |
| `⌘K` | AI 快捷浮层 |
| `⌘⇧A` | AI 小窗（⇄ 停靠窗格） |
| `⌘,` | 设置 |
| `⌘⇧V` | 悬浮预览窗开关 |
| `?` | 快捷键总览 |
| `Esc` | 层级关闭（先清搜索 → 再关面板） |

**类型过滤**（阅读空间 / 网格 / 检索内）：`⌥1`–`⌥8` = MD/HTML/文本/PDF/视频/图片/代码/音频；`⌥0` = 全部
**模式**：`⌘⇧M` 循环（预览/编辑/源码）
**文件**：`⌘O` 打开 · `⌘S` 保存 · `⌘N` 新建 · `⌘T` 新页签 · `⌘W` 关页签/格 · `⌘⇧P` 置顶
**工作区**：`⌘↵` 打开选中 · `⌘⌥→` 右分 · `⌘⌥↓` 下分 · `⌘⇧↵` 全屏当前格 · `⌘⇧F` 沉浸
**导航**：`j/k` 上下整行 · `h/l` 行内左右 · `PageUp/PageDown` 整页 · `Home/End` 首尾 · `Enter` 打开 · `/` 搜索
**卡片直开**：按住 `⌘` 显示视口编号；`⌘1–9` 当前格 · `⌘⇧1–9` 右分 · `⌘⌥1–9` 下分
**AI/其他**：`⌘⇧E` 生成学习页 · `⌘⇧T` 翻译 · `⌘⇧.` 快速捕获 · 按住 `⌘⇧Space` 语音

**设计规则**：单 `⌘` 高频 / `⌘⇧` 二级 / `⌘⌥` 分栏 / `⌥` 过滤 / 不用三修饰键 / tooltip 显示键位

## 12. 信息元素规范

## 13. 状态与持久化（视图规格字段）

```jsonc
// $APPCONFIG/user/views/rail.json
{
  "defaultLayout": "stack",        // stack | tabs

  "cardHeight": 112,               // 88..160
  "sectionOrder": ["now","pinned","recent","types"],
  "colors": { "pinned": null },    // AI 可改区块色
  "iconPlacement": "inside",       // inside | outside
  "search": { "enabled": true }
}
// $APPCONFIG/user/views/grid.json
{ "groupBy": "time", "sort": "recent", "mode": "grid", "tiles": { "large": ["pinned","continue"] } }
// $APPCONFIG/user/views/preview.json

// 布局树（工作区）

```

- 会话记忆：预览窗拖动位置、AI 小窗位置与尺寸

## 14. 构建验收清单（逐条通过才算完成）

1. 门户四块齐全，无「来源」
