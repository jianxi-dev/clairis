# layout-portal

已批准的门户与布局设计（布局规格 v1.0）。门户 + pane 树 + 阅读空间 + 网格 + 预览窗 + AI 两形态 + 设置 + 扩展 + 图标 + 快捷键。

## 设计要点

门户与布局模型定稿：门户 + 工作区 pane 递归树（N 栏/每格多页签/全屏/拖拽换位）+ 阅读空间竖排栏（三态/双布局/三密度/卡片规格/滑杆下拉）+ 网格概览（bento/缩略图优先/下拉控件/行切换键盘/动态编号）+ 悬浮预览窗（贴栏右缘锚定/四边四角缩放/拖动/关闭/双开关）+ AI 两形态（小窗 285×260 ⇄ 嵌入窗格，唯一入口）+ 设置左导航 10 区 + 便携扩展 + universe-icon 图标体系 + 完整快捷键家族。
