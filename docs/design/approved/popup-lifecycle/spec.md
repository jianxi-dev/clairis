# 标月 — 悬停浮层生命周期规则

> 适用范围：任何「指针悬停打开、且指针需要从触发器移动到面板内」的浮层——主题面板、宽度面板、导出二级菜单、颜色二级面板、大纲浮层、工具栏二级菜单。
>
> 本规则由三次同源缺陷倒逼而成（`#328`、`#374`、`shell-media-batch7/1.1`）。逐条不是风格偏好，每一条都对应一次真实「点了就没了」。

## 为什么需要一条规则

三次缺陷的代码各不相同，失效机制是同一个：**关闭逻辑只考虑「指针离开触发器」，没考虑「指针正在走向面板」**。

| 事件 | 现象 | 根因 |
|---|---|---|
| `#328` | 导出子菜单被卸载 | hover 与 click 两种打开方式互斥，切换时把子树卸载 |
| `#374` | 颜色二级面板打开后父菜单消失 | 父项 `pointerleave` 关闭时未把「二级已打开」计入 |
| `1.1` | 主题面板在点击前消失 | 150ms 关闭定时器在指针进入面板时未被取消；触发器与面板之间有 6px 死区 |

只修个例，第四次会落在另一个浮层上。所以规则必须独立成文，并被验收清单引用。

## 六条规则

### R1 进入即取消

指针进入面板（或其桥接区）时，必须取消已排期的关闭定时器。关闭只能在「指针离开触发器与面板的并集」后重新排期。

实现形态：`cancelClose()` 清空 timer 并置 `null`；`scheduleClose()` 先 `cancelClose()` 再排期；面板与桥接区的 `pointerenter` 绑定 `cancelClose`。

### R2 间隙归零

触发器与面板之间的视觉间隙必须由面板自身的透明内边距或桥接元素覆盖；不得让「两个元素之间的空白」承担视觉分离。

实现形态：面板外层容器贴住触发器，`padding-bottom: 8px` 作为无背景的桥接，可见面板盒子在该内边距之内。指针穿过的是容器，不是空白。

### R3 关闭冗余

除 hover 离开外，必须同时具备：

- 外部 `pointerdown` 关闭，且对「触发器」与「面板」分别做 `contains()` 守卫；
- `Esc` 关闭；
- 页面滚动与窗口尺寸变化关闭（面板是固定定位，滚动后锚点会漂）。

只有 hover 一种关闭途径的浮层，在触控板/键盘/滚轮场景下必然出问题。

### R4 卸载清理

组件卸载时必须清除定时器与所有监听器。未清理的定时器会在卸载后调用 `setState`。

### R5 父级卸载安全

若触发器的父容器可能因其他交互卸载（例如状态栏「双击隐藏 → 底部热区临时显现」），浮层不得随父容器一起消失。父容器须能感知「有浮层打开」并暂缓卸载。

实现形态：状态栏向父级上报 `popupOpen`；父级渲染条件为「隐藏 且 非临时显现 且 无浮层打开」时才卸载。

### R6 可访问性

- 触发器：`aria-haspopup="menu"`、`aria-expanded`；
- 面板：`role="menu"`；
- 选项：`role="menuitemradio"`（或 `menuitem`）且用 `aria-checked` / `aria-selected` 表达当前值。

`aria-expanded` 必须反映真实展开状态，不得恒为 `false`。

**键盘通路不可缺省**：声明了 `aria-haspopup="menu"` 就必须能用键盘打开菜单——触发器聚焦时 `ArrowDown` / `ArrowUp` 打开面板并把焦点移到当前项；面板内方向键移动、`Esc` 关闭并把焦点归还触发器、`Tab` 关闭。只有指针通路时，读屏与纯键盘用户面对的是一个「声称有菜单却打不开」的控件。

**分层关闭**：`Esc` 只关闭最上层浮层，必须 `stopPropagation`，不得同时触发全局 `Esc`（退出沉浸、清搜索、关全屏）。

## 点击语义（与悬停共存时）

悬停打开与点击执行可以共存，但语义必须显式定义并写进规格：

- 悬停 = 浏览（打开面板，不改变状态）；
- 单击触发器 = 执行主操作（如循环切换主题）；
- 点击面板项 = 精确设定。

三者冲突时以「悬停不改变状态」为准，避免指针路过就改设置。

## 验收方式

任何新增或修改悬停浮层的票，必须覆盖 `docs/agents/ui-test-matrix.md#弹层` 的状态列，并至少包含：

1. **缓慢横越**：用分步移动在间隙处停顿 ≥200ms，再进入面板，断言面板仍可见；
2. **面板内停留**：进入后停留 ≥500ms，断言仍可见；
3. **三条关闭路径**：外部点击、`Esc`、滚动；
4. **父级卸载**：在父容器可能卸载的场景（隐藏态状态栏）下重复第 1 条；
5. **ARIA**：`aria-haspopup` / `aria-expanded` / `role` 与当前值。

只用 `locator.hover()` 的瞬移用例视为未覆盖——它不会派发中途的 `pointerleave`，正是三次缺陷都能穿过测试的原因。

## 反例清单

- ❌ 把关闭延迟从 150ms 调到 400ms，但不取消定时器 —— 慢速移动仍会丢面板。
- ❌ 用纯 CSS `:hover` 加 `:has()` 代替状态管理 —— 跨 portal 不成立，也无法分步观测。
- ❌ 只加外部点击关闭，保留原 hover 关闭 —— 主诉缺陷未修。
- ❌ 面板与触发器之间留 6px 空白并寄望用户「移得快一点」。
