# 选区轮盘工具条（Selection Roulette）

> 状态：**已批准（2026-11-08，维护者五轮评审通过）**。本文件是选区轮盘的批准设计；
> 行为进 `openspec/specs/editing/spec.md`，单点视觉裁决落 `docs/design/system/decisions.md`。
> 交互原型（评审用，不入库）：`.lavish/selection-roulette.html`。

## 1. 一句话

把编辑态选中文字后出现的**横向 12 项工具条**，改成**以鼠标落点为圆心**的径向轮盘：
根环 8 个扇区，子级**只在父扇区方向就近展开成等宽扇形**（不绕整圈、项少不拉开间距）；
「转换」的选项随光标所在块类型变化，「颜色」是内圈文字色 / 外圈背景色的双圈。

## 2. 现状与目标集合

### 2.1 clairis 现有（`src/editors/orchestration/floating-toolbar.ts`，12 项）

AI 改写 / AI 翻译 / AI 润色 / 字号 / 加粗 / 斜体 / 下划线 / 删除线 / 链接 / 对齐 / 文字颜色 / 删除。

### 2.2 md-bundle 对照（`packages/editor/src/floating-toolbar.ts`，默认 11 项）

颜色 / 对齐 / 加粗 / 删除线 / 斜体 / 下划线 / 插入链接 / 行内代码 / 分栏 / 复制 / 转换（13 种块类型）。

### 2.3 目标集合

| 组 | 项 | 作用域 |
|---|---|---|
| 行内格式 | 加粗 / 斜体 / 下划线 / 删除线 / 行内代码 / 链接 | 选区 |
| 颜色 | 文字色（默认 + 8）**与**背景色（无 + 15），同面板双排 | 选区 |
| 段落 | 对齐（左 / 中 / 右 / 清除）+ **缩进 / 减少缩进** | 所在块 |
| 转换（三层） | 段落（正文 / 引用 / 高亮 / 分割线）· 标题（H1–H6）· 列表（无序 / 有序 / 待办）· 代码块 · 表格 | 所在块 |
| 分栏 | 1–5 栏，**每项画自己的栏数图标** | 所在块 |
| AI | 改写 / 翻译 / 润色 | 选区 |
| 历史 | **后退** / **前进** / 复制 / 删除 | 文档 / 选区 |
| 清理 | **清除格式** | 选区 |
| 模式 | **格式刷**（圆心） | 跨选区 |

**相对现状新增**：行内代码、分栏、转换、复制、背景色 / 恢复默认、对齐清除、缩进、分割线、格式刷、清除格式、后退、前进。

## 3. 为什么是轮盘

参考对象：Quicker「轮盘归档」——围绕鼠标展开、悬停展开子轮盘、`Ctrl+F` 筛选、圆心切换模式、历史可撤销。

| 维度 | 横向工具条（现状） | 径向轮盘（本方案） |
|---|---|---|
| 找项 | 每题从左到右扫一遍 | 方位固定，形成肌肉记忆后不用看 |
| 项数上限 | 12 项约 480px 宽，再加就压正文 | 根环 8 固定，靠分层扩到 40+ |
| 覆盖正文 | 横条压住选区上方一整行 | 环形 + 就近扇形，只压指针周边 |
| 手不离开选区 | 要移到横条再做水平定位 | 圆心就在鼠标落点，径向定位 |

**诚实代价**：首次发现性变差（缓解：扇区常显 2 字标签）；
环带会压住指针附近文字（缓解：内半径 30px，指针处只遮挡圆心 62px）；
触控板精度（缓解：角度命中 + 方向键 + 数字键）。

## 4. 轮盘结构

### 4.1 两层，逐层就近

```
   ┌──────────────┐
   │   根环 8 扇  │  ← 常显：14px 图标 + 11px 两字标签，圆心 = 鼠标落点
   │   ┌──────┐   │
   │   │ 圆心  │   │  ← 格式刷开关 + 已刷次数角标
   │   └──────┘   │
   └──────────────┘
        └── 扇形：贴着父扇区方向展开（92–122px），**只放形象图标**，15° 一格
             ├── 分组项（标题 › / 列表 › / 高亮 ›）→ 第三层**在同一位置替换**，圆心变返回
             └── 颜色例外：内圈文字色（96–138）、外圈背景色（148–190）两圈同时在场
```

### 4.2 根环方位（记忆口诀：左格式、右结构、上智能、下历史）

| 方位 | 扇区 | 展开内容 |
|---|---|---|
| 12:00 | **智能** | 改写 / 翻译 / 润色 |
| 01:30 | **转换** | **随块类型变化**（见 §4.4） |
| 03:00 | **对齐** | 左 / 中 / 右 / 增加缩进 / 减少缩进（不做「清除对齐」） |
| 04:30 | **分栏** | 1 / 2 / 3 / 4 / 5 栏（每项画自己的栏数图标） |
| 06:00 | **历史** | 后退 / 前进 / 复制 / 删除 |
| 07:30 | **清格** | 直接执行 |
| 09:00 | **格式** | 加粗 / 斜体 / 下划线 / 删除线 / 行内代码 / 链接 |
| 10:30 | **颜色** | 内圈文字色 9 + 外圈背景色 16（两圈同时可见） |

**分组理由**：左手（格式、颜色）是高频文字操作，右手（转换、对齐、分栏）是段落结构，
上侧 AI 低频高价值（避开误触），下侧历史/删除低频且破坏性（放最远）。

### 4.3 扇形：只放图标，固定窄格

二级 / 三级**不显示文字**，只有形象图标（`title` 与右侧状态栏「悬停」行给出名称）。好处是块可以窄：

- 每格固定 **15°**，紧挨着排，1px 描边分隔（0.35° 缝隙）。
- 环带很薄：92–122px，图标落在 107px 处——比带文字的版本近了约 15px。
- 项数 ≤ 8：8 项 = 120°，6 项 = 90°，始终在指针同一侧。

| 项数 | 总跨度 |
|---|---|
| 3 | 45° |
| 5 | 75° |
| 6 | 90° |
| 8 | 120° |

滚轮 / 方向键在当前层里移动高亮；不再有翻页。
**切换扇区的驻留**：已有展开层时，指针停在另一个根扇区上要 **300ms** 才切过去（无展开层时 90ms）——
这样「直线穿过」不会误触别的块，不必沿着环走。

### 4.4 「转换」：动态第二层 + 必要的第三层

第二层由**光标所在块类型**决定（交付时用参数表配置），标题 / 列表 / 高亮三个分组可下钻到第三层：

| 层级 | 内容 |
|---|---|
| 第二层·段落 | 标题 › / 列表 › / 高亮 › / 引用 / 代码块 / 表格 / 分割线 |
| 第二层·标题 | **正文** / 标题 › / 列表 › / 高亮 › / 引用 / 代码块 / 表格 / 分割线 |
| 第三层·标题 | 一级 ~ 六级标题（6） |
| 第三层·列表 | 无序 / 有序 / 待办（3） |
| 第三层·高亮 | 提示 / 信息 / 注意 / 警告 / 危险（5，落 `> [!kind]`，每类各有图标） |

动态点：已经在标题里时第二层多出「正文」；交付时这张表按块类型参数化，可继续加类型。
第三层**不往外铺**，而是在同一扇形区域替换第二层、圆心变 `‹` 返回——半径不变，仍守「就近」。

### 4.5 颜色 = 双圈

颜色不是等权动作，是调色板。它展开成**两圈同心的色轮**：

- **内圈**（96–138）：文字色 9 格（默认 + 8 色），每格画**着色字母 A**（默认项加斜杠），
  与「背景色」的色块在形状上就能区分。
- **外圈**（148–190）：背景色 16 格（无 + 15 色），色块 16px。
- 每格扇面本身就是该色的 16% 淡染，悬停加深到 34%——远看是一圈颜色，近看才是可点目标。
- 不再使用浮层色板：与轮盘同一套几何，所以「弹出不统一」不再存在。

## 5. 交互规则

| 事件 | 行为 |
|---|---|
| 出现 | 选区稳定 ~90ms 后出现（80ms 淡入 + 60ms 缩放）。**不能**在 `mouseup` 当场出现 |
| 圆心锚点 | 鼠标落点（`coordsAtPos(selection.main.head)`）；键盘选区用选区末端的 client rect |
| 圆心死区 | 指针离开锚点 24px 前，圆心不响应 hover / 点击 |
| 越界 | 整轮（420×420 包围盒）夹进视口安全区 |
| 悬停根扇区 | 90ms 驻留后就近展开扇形 |
| 离开整只轮盘 | 240ms 后收回扇形（根环与扇形间 10px 空隙不会误收） |
| 点击叶子项 | 执行。**格式类保持展开**（连击加粗+斜体）；破坏性/历史/插入类执行后收起 |
| 点击色块 | 立即套用，轮盘保持展开（可连续设文字色 + 背景色） |
| 滚轮 / 方向键 | 在当前层里移动高亮；`Enter` 执行 |
| `Ctrl+F` / `⌘F`（环内） | 圆心长出输入框，按关键词过滤全部动作（跨层平铺），回车执行首个匹配 |
| 数字键 `1–8` | 按 12:00 起顺时针直接进对应扇区 |
| `Esc` | 逐层后退：筛选 → 收回扇形 → 关闭 |
| 格式刷模式下再选区 | 自动把已存格式刷到新选区，**仍展开轮盘**；`Esc` 或再点圆心退出 |

### 5.1 三条被原型推翻的直觉（实现时必须照做）

1. **不能在 `mouseup` 当场弹轮盘。** 双击选词时，轮盘会盖在第二次点击的落点上，
   第二次点击把选区打散，用户看到的是「选中了但工具条不出现」。必须等选区稳定后再出现。
2. **圆心必须有死区。** 锚点就是指针位置，所以轮盘一出现，指针正压在圆心上（格式刷）。
   不加死区的话，选完字轻微一动就进了刷子状态。
3. **格式刷不能变成模式陷阱。** 若刷子激活时不再显示轮盘，用户就没有入口退出（只能猜 `Esc`）。
   原型改为：刷完格式仍然展开轮盘，圆心始终可达。

## 7. 四个新功能的行为定义

### 7.1 格式刷（圆心）

- **取格式**：选区存在时点圆心 → 读取行内包装 → 存为 `{bold, italic, underline, strike, code, color, bg}`。
- **刷格式**：之后每次新选区自动套用（幂等），计数角标显示已刷次数。
- **退出**：`Esc`、再点圆心。
- **不做**：段落级格式（对齐/分栏/块类型）不进格式刷。

### 7.2 清除格式（07:30）

剥掉选区内的 `**` `*` `~~` `<u>` `` ` `` `<span class="mdb-color-*">` `<span class="mdb-bg-*">`。
**保留**链接 `[text](url)` 与纯文本。一次 `dispatch`，单步可撤销。

### 7.3 缩进 / 减少缩进（03:00）

按 24px 一档，0–4 级；源码写成 `::: {.indent-N}` 围栏（与对齐同族）。

### 7.4 后退 / 前进（06:00）

映射 CodeMirror `undo` / `redo`（与 `Mod-z` / `Mod-Shift-z` **同一份历史**，不是两套）。
工具提示写「撤销 / 重做」，按钮标签保留「后退 / 前进」。

## 8. 评审结论（2026-11-08，维护者裁决）

### 第一轮：D1–D5

| # | 问题 | 结论 |
|---|---|---|
| D1 | 前进/后退语义 | 撤销 / 重做（与快捷键共用历史） |
| D2 | 字号是否留在工具条 | **移出**：它是全局阅读设置，不是选区属性 |
| D3 | 根环密度 | 8 扇区 |
| D4 | 半径与间隙 | 以原型手感为准（落台账） |

| 三主题切换，无控制台错误 | ✅ |

原型阶段抓到的三个真 bug（已修，实现时别重犯）：

- 轮盘在双击第二次点击前出现 → 选区被打散（见 §5.1 第 1 条）。
- 历史快照写在「变更前」，撤销/重做拿到同一份（快照必须在变更**之后**提交）。
- `parent.normalize()` 会合并文本节点，把刚设好的 Range 指向已移除节点而塌陷——
  清除颜色时必须只解包「与选区相交」的 span，不能让文本搬家。

## 11. 原型

`.lavish/selection-roulette.html`——可交互，不是截图：

- 左侧是真实排版的 Markdown 编辑区（可选中任意文字）。
- 选中即出轮盘；悬停展开就近扇形、分组进三级、`Ctrl+F` 过滤、数字键、方向键、`Esc` 逐层后退。
- 圆心点一次进入格式刷，再选文字看它自动刷格式。
- 「后退 / 前进」真实作用在编辑区的本地历史栈上。
- 顶栏可切亮 / 暗 / 暖三主题，右侧实时显示**源码层**结果（`**粗**`、`<span class="mdb-color-red">` …），
  证明「所见」和「写进 markdown 的东西」是一回事。
