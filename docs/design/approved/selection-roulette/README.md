# 选区轮盘工具条（Selection Roulette）

> 状态：**已批准（2026-11-08 起，维护者七轮评审）**。本文件是选区轮盘的批准设计；
> 行为进 `openspec/specs/editing/spec.md`，单点视觉裁决落 `docs/design/system/decisions.md`。
> 交互原型（评审用，不入库）：`.lavish/selection-roulette.html`。

## 1. 一句话

把编辑态选中文字后出现的**横向 12 项工具条**，改成**以鼠标落点为圆心**的径向轮盘：
根环 8 个扇区，点击根扇区后在**同一侧就近**展开等宽图标扇形；分组项的三层画在**二层外环**，
用同一套扇形、以**指针当前方向**为中心对称展开——离鼠标最近。

## 2. 现状与目标集合

### 2.1 现状（`src/editors/orchestration/floating-toolbar.ts`，12 项）

AI 改写 / AI 翻译 / AI 润色 / 字号 / 加粗 / 斜体 / 下划线 / 删除线 / 链接 / 对齐 / 文字颜色 / 删除。

### 2.2 md-bundle 对照（`packages/editor/src/floating-toolbar.ts`，默认 11 项）

颜色 / 对齐 / 加粗 / 删除线 / 斜体 / 下划线 / 插入链接 / 行内代码 / 分栏 / 复制 / 转换（13 种块类型）。

### 2.3 目标集合

| 组 | 项 | 作用域 |
|---|---|---|
| 行内格式 | 加粗 / 斜体 / 下划线 / 删除线 / 行内代码 / 链接 | 选区 |
| 颜色 | 内圈文字色（默认 + 8）、外圈背景色（无 + 15） | 选区 |
| 段落 | 对齐（左 / 中 / 右）+ 缩进 / 减少缩进 | 所在块 |
| 转换 | 动态：代码块 / 表格 / 标题 › / 列表 › / 高亮 › / 引用 / 分割线 | 所在块 |
| 分栏 | 1–5 栏（每项画自己的栏数图标） | 所在块 |
| AI | 改写 / 翻译 / 润色 | 选区 |
| 历史 | 后退 / 前进 / 复制 / 删除 | 文档 / 选区 |
| 清理 | 清除格式 | 选区 |
| 模式 | 格式刷（圆心） | 跨选区 |

**相对现状新增**：行内代码、分栏、转换、复制、背景色 / 恢复默认、缩进、分割线、格式刷、清除格式、后退、前进。

## 3. 为什么是轮盘

参考对象：Quicker「轮盘归档」——围绕鼠标展开、子轮盘、`Ctrl+F` 筛选、圆心切换模式、历史可撤销。

| 维度 | 横向工具条（现状） | 径向轮盘（本方案） |
|---|---|---|
| 找项 | 每题从左到右扫一遍 | 方位固定，形成肌肉记忆后不用看 |
| 项数上限 | 12 项约 480px 宽，再加就压正文 | 根环 8 固定，靠分层扩到 40+ |
| 覆盖正文 | 横条压住选区上方一整行 | 环形 + 就近扇形，只压指针周边 |
| 手不离开选区 | 要移到横条再做水平定位 | 圆心就在鼠标落点，径向定位 |

**诚实代价**：首次发现性变差（缓解：根环常显 2 字标签、二三层 tooltip + 右栏「悬停」行）；
环带会压住指针附近文字；触控板精度靠角度命中 + 方向键 + 数字键兜。

## 4. 轮盘结构

### 4.1 三层

```
   ┌──────────────────┐
   │    根环 8 扇区     │  ← 14px 图标 + 11px 两字标签，圆心 = 鼠标落点
   │     ┌──────┐      │
   │     │ 圆心  │      │  ← 格式刷；有三级时变「‹ 返回」
   │     └──────┘      │
   └──────────────────┘
        ├── 二层：点击根扇区后，贴着该扇区方向就近展开（92–122px），15° 一格、只放图标
        └── 三层：画在二层外环（126–152px），与二层同一套扇形，中心 = **被点击的二层区块**
```

### 4.2 根环方位（口诀：左格式、右结构、上智能、下历史）

| 方位 | 扇区 | 展开内容 |
|---|---|---|
| 12:00 | 智能 | 改写 / 翻译 / 润色 |
| 01:30 | 转换 | 动态（见 §4.4） |
| 03:00 | 对齐 | 左 / 中 / 右 / 增加缩进 / 减少缩进 |
| 04:30 | 分栏 | 1 / 2 / 3 / 4 / 5 栏 |
| 06:00 | 历史 | 后退 / 前进 / 复制 / 删除 |
| 07:30 | 清格 | 直接执行 |
| 09:00 | 格式 | 链接 / 下划线 / 斜体 / 加粗 / 行内代码 / 删除线 |
| 10:30 | 颜色 | 两圈色条（见 §4.5） |

### 4.3 二层：固定窄格，只放图标

- 每格固定 **15°**，紧挨着排，1px 描边分隔（0.35° 缝隙）；项少就短，**不摊开**。
- 环带 92–122px，图标落在 107px——比带文字的版本近约 15px。
- **不显示文字**，只有形象图标；名称走 `title` 与右栏「悬停」行。

| 项数 | 3 | 5 | 6 | 8 |
|---|---|---|---|---|
| 总跨度 | 45° | 75° | 90° | 120° |

### 4.4 「转换」：动态二层 + 三层

二层由**光标所在块类型**决定（交付时参数表配置），分组项可下钻：

| 层级 | 内容 |
|---|---|
| 二层·段落 | 代码块 / 表格 / 标题 › / 列表 › / 高亮 › / 引用 / 分割线 |
| 二层·标题 | **正文** / 代码块 / 表格 / 标题 › / 列表 › / 高亮 › / 引用 / 分割线 |
| 三层·标题 | 一级 ~ 六级标题（6） |
| 三层·列表 | 无序 / 有序 / 待办（3） |
| 三层·高亮 | 提示 / 信息 / 注意 / 警告 / 危险（5，落 `> [!kind]`，各有图标） |

三层与二层**同一套扇形**（15° 一格、紧挨排列、只放图标），区别只在中心：
**中心 = 被点击的那个二层区块的中心角**。这样三层的分格与二层同角对齐，
从圆心看出去，隔线是**一条连续的直线**（不是错位的折线）；径向只多 19px（107→126）。
不铺整圈、也不跟指针：指针随手一动中心就漂，隔线就对不齐了。二层保留可见并降到 70%。

### 4.5 颜色 = 两圈窄色条

- **内圈**（90–106，16px 窄条）：文字色 9 段（默认 + 8 色）。段本身是实色，上面放一个
  **平切于圆的字母 A**（基线沿切线、随段角旋转；浅色自动换深色字；默认项加斜杠）。
- **外圈**（111–127，16px 窄条）：背景色 16 段，只有色条，**没有色卡**。
- 两圈只隔 5px，从内圈挪到外圈几乎不用移动鼠标。
- 不使用浮层色板：与轮盘同一套几何。

## 5. 交互规则

| 事件 | 行为 |
|---|---|
| 出现 | **按住鼠标拖选期间绝不出现**；松开后 90ms 在鼠标落点出现（80ms 淡入 + 60ms 缩放） |
| 圆心锚点 | 鼠标落点；键盘选区用选区末端的 client rect |
| 越界 | 整轮（420×420 包围盒）夹进视口安全区 |
| 展开 | **只有点击根扇区才展开下级**；悬停只高亮；再点同一扇区收回 |
| 一级降权 | 展开下级后，根环与二层都降到 **70%** 不透明度（更透会看不清） |
| 三层 | 画在二层外环（126–152px），**同一套扇形、以被点击的二层区块为中心**（隔线与二层共线）；二层降到 70%，圆心变 `‹` |
| 离开整只轮盘 | 400ms 后收回下级 |
| 点击叶子项 | 执行。格式类保持展开；破坏性 / 历史 / 插入类执行后收起 |
| 点击色条 | 立即套用，轮盘保持展开（可连续设文字色 + 背景色） |
| 滚轮 / 方向键 | 在当前可操作层里移动高亮；`Enter` 执行 |
| `Ctrl+F` / `⌘F` | 轮盘下方弹**筛选面板**（输入框 + 结果行，跨层平铺）；轮盘没开时先按当前选区就位再弹 |
| 数字键 `1–8` | 按 12:00 起顺时针直接进对应扇区 |
| `Esc` | 逐层后退：筛选 → 三层 → 二层 → 关闭 |
| 格式刷模式下再选区 | 自动把已存格式刷到新选区，**仍展开轮盘**；`Esc` 或再点圆心退出 |

### 5.1 三条被原型推翻的直觉（实现时必须照做）

1. **不能在 `mouseup` 当场弹轮盘。** 双击选词时，轮盘会盖在第二次点击的落点上，第二次点击
   把选区打散，用户看到「选中了但工具条不出现」。必须等选区稳定后再出现。
2. **圆心死区是错的（第七轮推翻）。** 曾给圆心加「指针离开 24px 才生效」的防误触，
   结果用户选完字指针没动、直接点圆心时被吃掉，格式刷看起来失效。点击式展开本身就是明确动作，
   死区必须没有：选完即可点圆心取格式。
3. **格式刷不能变成模式陷阱。** 若刷子激活时不再显示轮盘，用户就没有入口退出。
   刷完格式仍然展开轮盘，圆心始终可达。

另外两条实现口径：**筛选输入框绝不能在输入过程中重建**（会打断中文输入法组合过程，
表现为「打字没反应」）；**历史快照必须在变更之后提交**，否则撤销/重做拿到同一份。

## 6. 视觉与几何

| 项 | 取值 | 出处 |
|---|---|---|
| 浮层底色 / 描边 / 阴影 | `--app-surface` / `--app-border` / `--app-shadow` | spec §5、§6 |
| 盘面与纸面的层次 | `color-mix(surface 90%, text-strong 10%)`；暗色下扇形再提一档 | 待落台账 |
| 强调色（悬停 / 激活） | `--app-accent` + `--app-accent-soft` | spec §6 |
| 图标 | 14px（密集工具条档），二三层 15px | spec §2.1 |
| 标签字号 | 根环 11px；二三层无标签 | spec §4 |
| 圆角 | 扇形外缘 8px / 圆心 `--radius-full` | spec §5 |
| 根部半径 | 圆心 31 / 内 30 / 外 86 | 待落台账「选区轮盘」 |
| 二层半径 | 92 – 122，间隙 0.35°，格宽 15° | 待落台账 |
| 三层半径 | 126 – 152，格宽 15°，中心 = 被点击的二层区块 | 待落台账 |
| 颜色带 | 内 90 – 106、外 111 – 127（各 16px） | 待落台账 |

三主题（亮 / 暗 / 暖）都要过；颜色只用 token 与 `color-mix`，不写死色值。

## 7. 四个新功能的行为定义

### 7.1 格式刷（圆心）

- **取格式**：选区存在时点圆心 → 读取行内包装 → 存为 `{bold, italic, underline, strike, code, color, bg}`。
- **刷格式**：之后每次新选区自动套用（幂等），圆心角标显示已刷次数。
- **退出**：`Esc`、再点圆心。
- **不做**：段落级格式（对齐 / 分栏 / 块类型）不进格式刷。

### 7.2 清除格式（07:30）

剥掉选区内的 `**` `*` `~~` `<u>` `` ` `` `<span class="mdb-color-*">` `<span class="mdb-bg-*">`。
**保留**链接 `[text](url)` 与纯文本。一次改动，单步可撤销。

### 7.3 缩进 / 减少缩进（03:00）

按 24px 一档，0–4 级；源码写成 `::: {.indent-N}` 围栏（与对齐同族）。

### 7.4 后退 / 前进（06:00）

映射 CodeMirror `undo` / `redo`（与 `Mod-z` / `Mod-Shift-z` **同一份历史**，不是两套）。
提示写「撤销 / 重做」，按钮标签保留「后退 / 前进」。

## 8. 评审结论（维护者七轮）

### 第一轮：D1–D5

| # | 问题 | 结论 |
|---|---|---|
| D1 | 前进/后退语义 | 撤销 / 重做（与快捷键共用历史） |
| D2 | 字号是否留在工具条 | **移出**：它是全局阅读设置 |
| D3 | 根环密度 | 8 扇区 |
| D4 | 半径与间隙 | 以原型手感为准（落台账） |
| D5 | 执行后是否收起 | 格式类保持展开，其余收起 |

## 9. 落地路径

   ② 命令补齐（行内代码 / 分栏 / 转换动态表 / 复制 / 背景色 / 缩进 / 分割线）；

   `A-4` 颜色两圈窄条、无浮层；`A-5` 全部动作可达且写入源码正确；`A-6` 格式刷跨选区幂等且无死区；

   细则见 `HANDOFF.md` §7.5。

原型阶段抓到的四个真 bug（实现时别重犯）：

- 轮盘在双击第二次点击前出现 → 选区被打散（§5.1 第 1 条）。
- 历史快照写在「变更前」，撤销/重做拿到同一份（快照必须在变更**之后**提交）。
- `parent.normalize()` 合并文本节点，把刚设好的 Range 指向已移除节点而塌陷。
- 每次按键都整只轮盘重渲染 → 输入框被重建、中文输入法组合被打断（表现为「打字没反应」）。
