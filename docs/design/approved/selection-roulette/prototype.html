选区轮盘工具条

选中一段文字，工具条不再从上方滑出，而是在指尖展开成一只轮盘。

左侧是格式，右侧是结构，上方是智能，下方是历史。方位固定，用熟了不用看。

把常用的 加粗、斜体 与 红色文字 直接写进 Markdown 源码，不引入私有语法。

换行与分栏

分栏走 Pandoc fenced div，对齐走 ::: {.align-center}。

悬停扇区展开子环，滚轮翻页，Ctrl+F 输入关键词直接筛。

点一下圆心进入格式刷，之后每选一段文字都会自动刷上刚才取到的格式。

放错了就按后退，和 ⌘Z 共用同一条历史。

怎么试

  1. 在左侧选中任意文字，轮盘以鼠标落点为圆心出现。
  2. 悬停「格式」「对齐」，扇形贴着指针就地展开，不绕整圈。
  3. 「转换」里点段落 › / 标题 › / 列表 › 进第三层，圆心变返回。
  4. 「颜色」是两圈：内圈文字色、外圈背景色，点色块即套用。
  5. Ctrl+F / ⌘F 过滤全部动作；点圆心取格式，再选文字自动刷。
