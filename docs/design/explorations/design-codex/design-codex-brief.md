## 需要 Codex 头脑风暴的 4 个方向

### 方向 A: 取代文件树
传统文件树是 1970 年代 Unix 遗产。寻找革命性替代方案。
已有方案: 时间轴流、AI 智能伴侣侧栏、无限画布、情绪花园、Cmd+K 极简
需要 Codex 贡献更多突破性思路

### 方向 B: 编辑器情绪陪伴系统
核心理念: "编辑器感知你的写作状态，并做出情绪化响应。不是功能，是陪伴。"
传感器维度: 打字节奏、删除/改写率、文件切换频率、连续写作时长、时段
需要 Codex 设计更丰富的情绪响应场景和传感器组合

### 方向 C: 阅读体验突破
写作和阅读并重。阅读态应有完全不同于写作态的 UI 人格。
关键点: 出版级排版、沉浸阅读模式、主动阅读工具（高亮/旁注/阅读镜）、阅读智能（节奏/书签/摘要）
需要 Codex 贡献更多"让用户爱上阅读"的创新

### 方向 D: 空间记忆 + 归来体验
每次打开回到精确离开位置。不止于此——要让用户期待回来。
归来分场景: 日常归来、久别重逢、深夜归来
需要 Codex 设计更多"让用户喜欢看到回来的页面"的创意

## 设计原则
- 科技感、时尚、新颖、高级
- 克制 vs 功能: 优先做减法
- 每个交互都要有"温度"
- 反传统，不拘泥于过去的行为习惯
