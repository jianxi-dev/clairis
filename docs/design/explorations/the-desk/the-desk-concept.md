# The Desk — 无侧栏空间记忆原型

> 来源：4 轮 Codex 创意碰撞输出
> 关联：PLAN-REVIEW-LOG.md, PLAN.md

## 核心理念

编辑器不是文件管理器。编辑器是一张书桌。**文档不应该被"找到"，它们应该在物理空间中等待你。**

The Desk 替代侧栏的方式不是"另一个导航 UI"——它是编辑器本身的**状态转换**。你不需要打开一个面板，你把头从当前页面抬起来，看到你工作的地方。

## 交互规格

### 触发（进入 The Desk）

| 方式 | 描述 |
|------|------|
| **触控板** | 三指捏合（类似 Mission Control 的肌肉记忆） |
| **键盘** | `Cmd+↑`（直觉：向上看/抬起头的动作） |
| **鼠标** | 移到屏幕最上边缘悬停 400ms（极少用，仅作为发现路径） |

### 桌面布局规则

**文档不是图标，是缩小到 1/4 的页面缩略**，显示标题 + 首行 + 时间标记。

```
        ┌──────────────────────┐
        │ 设计哲学.md           │      ← 字体清晰可读
        │ 设计的本质不是解决…    │      ← 首行文字
        │                      │
        │ last edited 3h ago    │      ← 时间标记
        └──────────────────────┘
```

**位置决定意义（非随机）：**

| 位置 | 含义 |
|------|------|
| **中央偏左**（伸手就能碰到） | 刚刚还在写的 — 最近活跃 |
| **右侧堆叠** | 刚在参考的 — 引用/对照 |
| **左上方远处** | 几小时前写的 — 稍远记忆 |
| **半透明/位于边缘** | 几天前的 — 知道存在但不突出 |
| **叠在一起** | 同一主题的一组文档 |

### 交互

| 动作 | 结果 |
|------|------|
| 点击文档 | 展开到全屏编辑/阅读 |
| 拖拽文档到另一个文档上 | 两者建立关联（反向链接） |
| 拖拽文档到"废纸篓"区域（右下角微痕） | 归档（不是删除） |
| 悬停 | 显示稍大预览 + 打开时间 + 字数 |
| `Cmd+F` 在桌面状态 | 搜索所有文档（不是搜索栏，是桌面浮墨） |
| 空白处右键 | "新文档出现在手边" |
| `Esc` 或 `Cmd+↓` | 回到当前文档 |
| 不做任何操作 15 秒 | 淡出回到当前文档（桌面不是停留的地方） |

## 视觉氛围

- 桌面底色：极淡木质纹理或柔灰（`#f5f0eb` 暖灰，类似未上蜡的纸）
- 阴影：每个文档页有柔和阴影（`box-shadow: 0 4px 20px rgba(0,0,0,0.06)`）
- 动画：升起时 0.3s ease-out，落下时 0.2s ease-in
- 过渡不打断：当前页升起时，文字逐渐淡化成缩略，不是"切屏"
- 暗色模式：桌面变成深色木质或石板质感（`#1a1a2e` 深蓝灰）

---

## Codex 的风险警告

> "空间记忆听起来很美，但如果位置是随机的，就会坍缩成 Pinterest。"

**必须满足的约束：**
1. 位置必须是稳定的 — 同一文档每次退回到桌面时在同一个位置
2. 文档数必须稀疏 — 桌面上最多 7±2 个文档（认知负荷上限）
3. 超过 9 个文档时 → 最近的 5 个 + 2 个关联 + 2 个被遗忘的（Ink Relics 推荐）
4. 用户不能手动"整理"桌面（一旦可整理，就变成了另一个文件树）

---

## 实现路径（渐进式）

```
Phase 1    键盘触发（Cmd+↑）→ 桌面上只显示最近 5 个文档
            固定位置，无拖拽，无动画 MVP

Phase 2    加入触控板手势 + 平滑上升动画
            文档关联推荐（同主题聚类）

Phase 3    可交互桌面（拖拽关联、归档）
            Ink Relics 集成
            阅读完成后的"桌面浮现"自动触发
```
