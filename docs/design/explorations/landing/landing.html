产品特性

为你而生的读写伴侣，五大核心能力

四模式画布

文档 / 灵感 / 磁场 / 空间导航。Cmd+1/2/3/4 切换内容形态，让每个思维场景都有匹配的界面。

展卷仪式

非阻塞开卷动画，可跳过。收卷微型总结，每次阅读都有开幕与落幕。TTI 硬保证 < 1.0s。

统一文件面板

Cmd+P，三视图智能切换：空查询 = 当前上下文，输入 = 全局搜索，选中文本 = 局部相关。不管理文件，软件帮你找。

AI 对话 · 本地优先

Cmd+SideA 唤起，默认本地 Ollama，可选云端。右侧悬浮/嵌入双形态，不影响专注。

隐私至上

100% 本地读写，不上传任何文档内容。统计权限 600，不可被第三方 App 读取。

悬浮面板 · 嵌入停靠

可拖拽、最小化、悬停收起、图钉吸附。四种场景组合 —— 专注 / 研究 / 检阅 / 灵感。

PERFORMANCE · BY DESIGN

<1.0s

TTI 冷启动红线。M1 < 700ms，M3 < 600ms。

100%

本地至上。文档内容零上传，离线可用。
