# 技术调研（research/technical）

## 职责

存放技术方案、库选型、实现可行性方面的调研（如编辑器方案、性能实验、平台适配探索）。用于支撑架构与技术选型。

## 进入条件

- 内容为技术调研结论，非已接受的架构决策。
- 一旦形成架构决策，应记录为 ADR（`../../architecture/decisions/`），本目录保留调研过程。
- 新增文档须带 frontmatter（`title` / `type: research` / `status` / `last_updated`），规范见 `../../GOVERNANCE.md`。

## 权威级别

属于第 6 层 research / history，**默认不参与实现裁定**。已采纳的技术决定以 ADR 为准。
