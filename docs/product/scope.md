# 范围边界（做什么 / 不做什么）

本文档只在**产品级**上界定 Biaoyue 的范围与方向性取舍，回答“做什么、不做什么”。**不含逐功能清单**；逐功能可验收行为以 `openspec/specs/` 为准。阶段方向见 [交付路线图](../delivery/roadmap.md)。

## 一、做什么（产品级范围）

- **阅读与编辑 Markdown / HTML / 纯文本文件**：以本地文件为核心的桌面阅读与编辑体验。
- **可折叠阅读空间**：左侧竖排栏以三态（折叠 / 悬停浮层不挤压 / 钉住）组织文件，正文满宽或按需让位；导航由阅读空间 + 网格概览 + 统一检索承担。
- **内容生成（contentweave 并入）**：把 Markdown 源文件渲染为离线单文件 HTML 学习页，作为阅读与创作的延伸。
- **AI 可塑**：用自然语言调整应用的行为、外观与导航；AI 改得动、改坏能退回。
- **灵感即时记录**：念头出现即可录入，不打断当前任务。

> 来源：重定位规格包 §一/§四/§五；产品铁律见 [Doctrine](./principles.md)。
> 说明：以上为方向级概括，具体功能的阶段归属见 [交付路线图](../delivery/roadmap.md)，行为细节不在此列出。

## 二、不做什么（产品级边界）

### 2.1 委托式文件管理：不暴露层级

- **委托式文件管理**：软件按需帮助定位 / 打开文件，默认不暴露层级；用户不管理文件位置，只管理“当前读 / 写什么”。阅读空间与网格均为平铺分类，不出现目录树。
  > 来源：全量需求文档 §0.3「术语裁定表」、§十一「决策记录」；重定位规格包 §五「无『来源』概念，组织维度 = 时间 / 类型 / 主题」。

### 2.2 可折叠阅读空间（取代「无侧栏」）

- 阅读空间是左侧竖排栏，三态：**折叠**（12px 边缘条，正文满宽）/ **悬停浮层**（240px，absolute 覆盖，不挤压正文）/ **钉住**（240px，flex 常驻，正文变窄）。
- 旧「无侧栏」表述（取消左侧边栏 + 文件树、正文区左右上下独立分栏、右侧边栏保留默认隐藏）**已不再是现行方案**；现行方案为可折叠阅读空间，详见 [布局规格](../design/approved/layout-portal/spec.md) 与 [ADR 0009](../architecture/decisions/0009-collapsible-reading-rail-supersedes-no-sidebar.md)。
  > 来源：布局决议（2026-11-01 维护者定稿）；重定位规格包 §五。

### 2.3 内容生成与 HTML 编辑边界

- **生成物 = 编译产物**：contentweave 生成的 `.html` 是源 Markdown 的编译产物，**只读查看**，不进入编辑管线；源 `.md` 是唯一事实源，保存即后台重渲染。
- **外来 HTML 文件可编辑**：用户自带的 `.html` 文件照旧全能力编辑，不受生成物只读约束影响。
- **生成物离线单文件**：产物断网可看、零外部子资源（CDN 字体须有兜底）。
  > 来源：contentweave 并入决议（2026-10-31）；产品铁律 D9；[ADR 0007](../architecture/decisions/0007-generated-artifact-is-compiled-output.md)。

### 2.4 范围治理边界

- **不在需求文档中 = 不实现**：功能范围以进入治理后的规格文档为准，不口头扩张。
  > 来源：全量需求文档 §0.2「裁定规则」；现行阶段归属见 [交付路线图](../delivery/roadmap.md)。

## 不承担的内容

- 逐功能清单、键位映射表、数据模型字段：以 `openspec/specs/` 为准，本文档不复制。
