# 产品方向（product）

## 职责

存放 Biaoyue **稳定的产品定义**：愿景、设计原则、目标用户、范围边界与阶段方向。这些文档回答“我们要做一个什么样的产品、为谁做、不做什么”，不回答“某个功能具体怎么验收”。

## 不放在这里

- 逐功能的可验收行为、键位表、数据字段 → `openspec/specs/`
- 视觉/交互稿与体验决策 → `docs/design/approved/`
- 里程碑排期与交付节奏 → `docs/delivery/`
- 开发状态、待办、进度跟踪 → 不放产品文档（产品文档不含“开发中/已完成”状态列）

## 进入条件

- 内容是**长期有效**的产品判断，而非某个变更里的临时决定。
- 不复制功能行为细节；功能细节以链接指向 `openspec/specs/`。
- 新增文档须带 frontmatter（`title` / `type: product` / `status` / `last_updated`），规范见 `../GOVERNANCE.md`。

## 权威级别

产品方向在权威优先级矩阵中位于第 5 层：**当与活动变更、canonical spec、已接受 ADR、已批准设计冲突时，产品方向不得覆盖高层**。
