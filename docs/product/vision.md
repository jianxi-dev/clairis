# 产品愿景（三更雨 · 灯畔）

本文档定义产品稳定的方向：品牌与产品名、一句话定位、三支柱与「不为谁做」。

## 一·五、品牌叙事（2026-11-03 定案，三更雨·灯畔版）

| 层级 | 文案 |
|------|------|
| 主 slogan | 雨落三更，字在灯畔。 |
| 上墙短句 | 三更有雨，灯畔有你。 |
| 传播钩子 | AI 不在台前，在灯畔。 |
| 首屏副标 | 一款被你拥有、可被 AI 塑形的读写应用。布局、键位、导航，一句话改；改坏了，一句话退回。 |

品牌故事标准表述（第二层：about 页 / README 尾部）：

> 好雨知时节，随风潜入夜，润物细无声。
>
> 三更的雨落在窗外，你坐在灯畔写字。AI 也坐在灯畔——不站台前替你落笔，只在你需要时，像夜雨一样润进你的稿子。夜再深，灯亮着；字有去处，路有方向。

叙事主轴：**知时节、润无声**。灯畔只伴不代——AI 塑形不代笔，改坏了一键退回。灯畔的光承担「陪伴与指引」双义：字被照亮（陪伴），路被照见（指引）。典故使用边界「借诗不借经」（引杜甫诗句为品牌意象，不称产品为诗注解），完整规格见 `openspec/specs/brand-narrative/spec.md`。

## 二、一句话定位

> 三更雨旗下产品灯畔：一款被个人拥有、可被 AI 塑形的阅读与创作应用。普通用户不需要改源码，用自然语言就能调整它的行为、外观与导航。

## 三、三支柱

灯畔的一切设计都落在三根支柱上，三者互为支撑：

| 支柱 | 含义 | 落地 |
|------|------|------|
| **omakase（精选默认）** | 每个能力带精选默认行为，首启即「已被组织好的工作现场」；不把选择推给用户 | 默认主题/字号/布局/密度；override 层藏高级选项 |
| **malleability（一切可变状态皆文本）** | 配置、键位、视图规格、扩展都是约定目录的文本文件；用户与 AI 都能改 | 配置三层 + 视图规格 + 扩展包（SKILL.md 式） |
| **agentic（AI 改得动、改坏能退回）** | AI 能改应用行为，但每次改动都有确认卡、快照与一键恢复 | 确认卡三档 + 撤销条 + 快照（最近 10 份） |

> 来源：重定位规格包 §一/§三；产品铁律见 [Doctrine](./principles.md) D5/D6/D7。

## 四、不为谁做（摘要）

灯畔明确不为以下五类对象做，完整口径见 [Doctrine](./principles.md)「不为谁做」：

1. 不为愿意折腾的系统级玩家做整机级定制（那是 omarchy 的领地）。
2. 不为团队/多人协作做（本定位周期不承诺）。
3. 不为插件市场/公开扩展 API 做（扩展点 = 数据文件）。
4. 不为云端免费服务做（本地优先，API key 用户自持）。
5. 不为多语言市场调整产品节奏（中文体验优先做到极致）。
