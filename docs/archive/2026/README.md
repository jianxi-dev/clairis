# 归档（archive/2026）

## 职责

存放 **2026 年被取代或停用**的文档：旧版需求、旧设计稿、已废弃方案。按年份归档，本目录为 2026 年归档。

## 不放在这里

- 任何当前生效的真相源（产品/spec/ADR/已批准设计）一律不得放在 archive。

## 进入条件

- 文档已被新版本取代（status 为 `superseded` 或 `archived`）。
- 被取代的文档须在 frontmatter 用 `superseded_by` 指向替代者（规范见 `../../GOVERNANCE.md`）。
- 归档时保留 Git 历史，不删除原始提交。

## 权威级别（重要）

archive **默认不参与实现裁定**。在权威优先级矩阵中属于第 6 层（research / history）：只用于“过去是什么样、为什么被取代”的历史调查，实现冲突时不得引用归档内容覆盖任何高层真相源。
