#### 3.2.1 空状态四件套

| 入口 | 触发 | UI |
|------|------|---|
| 启动面板 | 首次打开 | 全屏空状态 |
| 空白空状态 | 关闭所有文档后 | 极简 |
| Omni-Search | **Cmd+P** | 浮动搜索框 |

#### 3.2.2 内置示例文件

| 文件 | 内容 |
|------|------|
| `0-欢迎.md` | 产品介绍 + 快捷键 |
| `1-Markdown示例.md` | GFM 语法覆盖 |
| `2-HTML示例.html` | 自定义 CSS 示例 |

释放到 `~/documents/clairis/`，仅首次启动。

#### 3.2.3 Omni-Search（Cmd+P）统一入口

> **核心修改：v2.1 将 Cmd/P 和 Cmd/K 合并为单一入口，降低认知负荷。**

```
┌─────────────────────────────────────────┐
│  > 搜索文件名、输入 > 执行命令...         │  ← Cmd+P 弹出
├─────────────────────────────────────────┤
│ 最近编辑                                │
│ 📄 资料.md          2分钟前   /笔记/     │  ← 文件名 + 路径片段
│ 📄 长文.md        1小时前  /草稿/      │
│ 📄 读书笔记.md   3天前    /归档/      │
├─────────────────────────────────────────┤
│ 新增文件                                │
│ 🆕 接待方案.md       今天              │
│ 🆕 日常记录.md      今天              │
├─────────────────────────────────────────-┤
│ 命令输入 >                              │
│ > new      新建文档                     │
│ > open     打开文件...                  │
│ > save     保存                       │
│ > focus    专注模式                    │
└─────────────────────────────────────────┘
```

**交互规则：**
- 无输入时：展示最近编辑 + 新增文件 + 下拉命令列表
- 输入文字后：显示文件名匹配结果（模糊匹配）+ 路径片段
- 输入 `>` 后：切换为命令模式
- ↑↓ 键选择，Enter 打开，Esc 关闭
- **卷帘动画**：从顶部向下滑落（300ms）
- **面板记忆**：再次打开时恢复上次尺寸/位置

### 3.4 视觉引擎架构（CanvasFrame）

| 层 | 职责 |
|----|------|
| **Layer 1 渲染** | 纹理（paper/wood/gradient/none）+ 调色板（warm/cool/dark） |
| **Layer 2 交互** | Wind 过渡动画 + 转场系统（none/subtle/gentle/dynamic） |

  palette: 'warm' | 'cool' | 'dark' | 'vibrant' | 'warm-dark' | 'cool-dark'
  animation: 'none' | 'subtle' | 'gentle' | 'dynamic' | 'gentle-scroll'
  particles: boolean           // P2
  lighting?: 'soft' | 'natural'  // P2
  spatial?: 'flat' | 'depth'     // P2
}
```

## 四、展卷仪式系统

> **核心修改：v2.1 确保动画不阻塞 TTI，改为非阻塞设计。**

### 4.1 设计原则

| 规则 | 说明 |
|------|------|
| **非阻塞** | 动画在独立合成线程运行，不阻塞主线程 TTI |
| **可跳过** | 任意键/Esc/点击均可中断动画进入主界面 |
| **TTI 保证** | 展卷动画结束后应用必定 <1s TTI，即使用户跳过也必须满足 |
| **批量操作抑制** | 连续操作时仅首次播放动画，后续静默执行 |

### 4.2 启动开屏仪式

#### 视觉设计

- 加载底色：宣纸米白/浅松烟灰/浅青笺，昼夜自动切换
- 入场载体：极简款（居中笺纸从左向右展开）/ 国风款（木轴向两侧展开，P2）
- 进度条：毛笔淡墨拖痕

#### 交互设计

1. 核心按钮「展卷提笔」→ 点击触发 0.8-1.2s 展开动画
2. 右上角「快速进入」→ 一键跳过
3. 点击/任意键 → 动画完成后显示提示语，点击进入主界面
4. 3 秒无操作自动进入

#### 提示语系统

- 内置：开卷有益 / 静思 / 今日宜书写
- 用户可自定义、添加、导入
- 每次打开随机一条

#### 音效设计（默认 15%，可全局关闭）

- 加载：宣纸翻动沙沙声 / 磨墨白噪音
- 完成：轻古琴/砚台滴水

### 4.3 动画规格

| 项目 | 值 |
|------|---|
| 标准时长 | 0.8s-1.2s（三档：舒缓/标准/快速） |
| TTI 保证 | 动画结束后 1s 内必定可交互 |
| 降级策略 | 检测到低配置设备或系统 Reduce Motion 开启时：关闭动画，直接进入 |

### 4.4 光影配套

| 模式 | 效果 |
|------|------|
| 日间 | 柔和漫射自然光 |
| 夜间 | 暖黄烛光灯晕，降低蓝光 |

### 4.5 自动专注联动

1. 展卷完成 → 自动进入专注模式（隐藏通知/推送）
2. 可选番茄计时：25/45/60 分钟
3. 专注期间界面微微变暗，仅当前文档亮起

### 4.6 收卷仪式

1. **微型总结**（关闭时显示 2s）：今日写了 X 字 · 读了 Y 篇 · 灵感 Z 条
2. **合卷动画**（0.3s）：画面向左侧卷起消失
3. **阅读归位**：退出阅读模式时保存书签位置，下次同一文档自动恢复

> 注：v2.1 移除"超过 68% 的用户"等无法验证的对比文案。

### 4.7 可访问性处理

| 系统设置 | 渐晰行为 |
|---------|---------|
| Reduce Motion = ON | 关闭展卷动画，直接进入主界面 |
| Reduce Motion = OFF | 正常展示展卷动画 |

## 五、性能架构

### 5.1 三级加载时序

```
T0 (0ms)      启动信号 → 立即开始展卷动画（顺序读取，不阻塞 TTI）

[核心层] T0 → ~50ms（必须先于动画结束前完成）
  ├─ 编辑器核心（CM6）
  ├─ 主 UI（Layout + Store）
  ├─ 文件操作（opener + saver + auto-save）
  └─ 配置加载

[功能层] T0+0ms → +500ms
  ├─ 标签页系统（R 阶段）
  ├─ Omni-Search 索引（需文档加载后）
  └─ 视觉引擎基础（CanvasFrame + 纹理注册表）

[扩展层] 用户触发后懒加载
  ├─ AI 后端（Ollama + OpenAI 客户端）

  ├─ 灵感聚类（后台空闲计算）

| **并行保证** | 动画播放期间核心层已完成，动画一结束即可交互 | 必须满足 |

## 八、HTML 渲染方案

> **核心修改：v2.1 修正 srcdoc 无法加载本地资源的问题。**

### 8.1 Phase M 方案：静态限制

- HTML 渲染采用 iframe + sandbox 属性
- 允许：CSS 渲染、静态图片（仅 data: URI + 同源资源）
- 禁止：JS 执行、网络请求、localStorage
- **不引入 srcdoc**（避免相对路径问题）
- 渲染时通过 `blob:` 或 Tauri 自定义资源路径注入 CSS/图片

### 8.2 Phase R 方案（完整）：Tauri 自定义协议

```
tauri://clairis.local/assets/...  → 映射到用户文档同目录
tauri://clairis.cdn/google-fonts  → 允许加载 Google Fonts
```

- Tauri 的 `asset:` protocol 处理本地资源映射
- 白名单机制：允许 Google Fonts、Tailwind CDN（需用户同意）
- CSP 针对 R 阶段放宽：`script-src 'none'; style-src 'self' https://cdn.jsdelivr.net; font-src 'self' https://fonts.gstatic.com; img-src 'self' data: https:;`

## 九、快捷键冲突处理

> **核心修改：v2.1 建立快捷键优先级规则，确保不冲突。**

### 9.1 优先级体系

| 层级 | 类型 | 示例 |
|------|------|------|
| **L1** | macOS 系统保留 | Cmd+Space(聚焦)、 Cmd+Tab、 Cmd+Q、 Cmd+H — 永不占用 |
| **L2** | 编辑器快捷键 | 文字编辑、光标移动、选择 — 仅在编辑状态生效 |
| **L3** | 应用全局快捷键 | Cmd+Shift+N/M/P — 后台仍可触发 |
| **L4** | 应用焦点快捷键 | Cmd+O/S/N/W/=// \\ — 焦点在应用时生效 |
| **L5** | 面板/模式快捷键 | Cmd+1/2/3/4、 Cmd+Shift+O/A/T — 不与其他面板冲突 |
| **L6** | 临时快捷键 | Esc 关闭/退出、↑↓ 选择 — 仅在特定状态生效 |

### 9.2 冲突裁决规则

| 场景 | 裁决 |
|------|------|
| Esc 同时关闭面板和退出沉浸模式 | **就近原则**：先关闭面板，再退出沉浸，需按两次 |
| Cmd+W 关闭标签 vs macOS 习惯 | Cmd+W 在焦点不在编辑器时关闭标签；焦点在编辑器时撤销输入 |
| Cmd+= 字号缩放 vs 浏览器/其他 App 习惯 | 不替代系统缩放功能，仅调整编辑器字号 |
