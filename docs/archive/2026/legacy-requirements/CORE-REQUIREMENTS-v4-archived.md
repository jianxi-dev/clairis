## 一、产品重新定义

### 1.1 从"工具"到"伙伴"

| | v3（旧） | v4（新） |
|------|------|------|
| 角色 | 被动工具 | 主动伙伴 |
| 目的 | 读写文件 | 助力学习成长 |
| 哲学 | 功能完成 | 情绪价值 |
| 交互 | 用户操作 | 系统预判 |
| 成功标准 | 用户完成任务 | 用户变得更好 |

### 1.2 一句话定义

**一款陪伴人类学习成长的智能伙伴。** 利用 AI 时代的能力，为阅读者、写作者、灵感寻求者提供无阻力、有快感、令人上瘾的体验，帮助其降低烦恼、缓解压力、提升心境与能力。
我们优先保证阅读体验的优雅和愉悦，其次才是功能完整度。性能（秒开）是基本线，扩展性是远期考量。
### 1.3 目标用户（重新定义）

| 画像 | 占比 | 核心需求 | 产品角色 |
|------|------|----------|----------|
| **学习者** | 40% | 高效阅读、知识整理、记忆强化 | 私人导师 |
| **写作者** | 30% | 流畅输出、格式美化、灵感激发 | 写作搭档 |
| **成长者** | 20% | 反思记录、目标追踪、情绪梳理 | 心灵伙伴 |
| **灵感寻求者** | 10% | 创意激发、跨界连接、偶然发现 | 灵感催化剂 |

> 注：不再是"普通阅读者 / 轻度编辑者 / 技术用户"，而是按**人生成长阶段**划分。

### 1.4 竞品重新定位

| 产品       | 它们是什么        | 渐明是什么 |
| -------- | ------------ | --------- |
| Typora   | Markdown 编辑器 | 成长伙伴      |
| Obsidian | 知识管理工具       | 心灵助手      |
| Notion   | 笔记/数据库       | 智能陪伴      |
| Arc      | 浏览器          | 思维空间      |
| Readwise | 阅读标记         | 学习引擎      |

> 渐明不与以上任何产品直接竞争。我们解决的**不是"如何写 markdown"**，而是"如何通过写作变得更好"。

## 二、产品哲学（替换 v3 的快/方便/舒服/喜欢）

| 原则 | 含义 | 评审检查问题 |
|------|------|-------------|
| **懂你** 🧠 | 主动理解意图，预判需求，自动完成繁琐步骤 | 系统是否主动为用户做事？用户是否需要"告诉"系统所有细节？ |
| **减负** 🪶 | 减少决策、自动整理、降低认知负荷 | 用户需要做的决策是否最少化？是否可以"不动脑子"就用好？ |
| **惊喜** ✨ | 超出预期，带来 Wow 的瞬间 | 用户会截图分享吗？有"没想到"的瞬间吗？ |
| **上瘾** 🌀 | 使用后满足，不用时想念 | 用户结束后会感到充实还是疲惫？有"再来一次"的冲动吗？ |

## 三、核心体验设计（v4 新增章节）

### 3.1 角色自适应界面

系统根据用户当前行为**自动切换角色模式**，无需手动选择：

| 模式 | 触发条件 | UI 风格 | 核心功能 |
|------|----------|---------|----------|
| **阅读模式** | 打开大段文字 >5 分钟无编辑 | 全屏无 chrome，只剩文字 | 速读、AI 摘要、高亮批注 |
| **写作模式** | 新建文档或编辑区有输入 | 极简工具栏 + 右侧 AI 面板 | 实时润色、排版辅助、风格迁移 |
| **灵感模式** | 频繁切换文档、停顿 >30s | 卡片流、随机推荐、跨界连接 | AI 问答、思维图谱、随机碎片 |
| **反思模式** | 每天首次打开、特定时间 | 温和色、引导问题 | 心情记录、目标回顾、感恩日记 |

> 切换是**平滑过渡**的，不是"弹窗选模式"。AI 感知意图，界面自然变形。

### 3.2 右侧边栏（替代左侧边栏）

左侧边栏是无用的陈旧模式。**全部功能收入右侧边栏**，仅在需要时展开：

| 面板 | 功能 | 图标 |
|------|------|------|
| **AI 对话** | 多轮问答、文档上下文、任务自动化 | 💬 |
| **角色工具** | 根据当前模式切换组件（写作/阅读/灵感/反思） | 🧰 |
| **知识网络** | 显示当前文档与其他文档的语义关联 | 🕸 |
| **时间带** | 写作历史、行为密度、成长轨迹 | ⏰ |
| **墨迹** | 跨文档关键词聚合、共鸣发现 | 🔮 |

> 右侧边栏默认**隐藏**，快捷键或按钮触发，不占用阅读空间。

### 3.3 正文区分栏

正文区支持**独立双方向分栏**：

| 分栏模式 | 方向 | 独立滚轮 | 独立模式 | 用途 |
|----------|------|----------|----------|------|
| 左右分栏 | 水平 | ✅ | ✅ | 阅读+大纲 / 源码+预览 / 双文档对比 |
| 上下分栏 | 垂直 | ✅ | ✅ | 草稿+笔记 / 提纲+正文 / 参考+写作 |

> 左右边栏不影响分栏。分栏仅对 Content 区生效。

### 3.4 无左侧边栏 = 新导航模式

去掉左侧栏后，导航方式改为：

| 交互 | 行为 |
|------|------|
| Cmd+O | 打开文件 |
| Cmd+N | 新建文档 |
| Cmd+P | 搜索/命令面板（文件+动作） |
| 右侧边栏"时间带" | 最近文件 + 写作历史 |
| 右侧边栏"知识网络" | 跨文档漫游 |
| Desk 模式（桌面隐喻） | 空间记忆导航 |

导航不再是"树形文件列表"，而是：
- **时间** → 我写过什么？
- **语义** → 和这个相关的还有什么？
- **空间** → 我记得它放在"书桌左上角"...

## 四、AI 能力深度整合（v4 核心）

### 4.1 AI 作为底层能力

AI 不是"翻译功能"或"聊天机器人"，而是**贯穿所有操作的底层基础设施**：

| 能力 | 触发方式 | 体验 |
|------|----------|------|
| **实时润色** | 输入时实时进行 | 打字时系统自动提示更好的措辞，用户可撤销 |
| **智能摘要** | 长文档自动 | 读取时系统已生成摘要，点击展开，无需等待 |
| **知识关联** | 后台持续 | 写作时右侧自动浮现相关文档片段 |
| **情绪感知** | 分析写作内容 | 系统检测焦虑/压力，推荐放松或调整语气 |
| **主动提问** | 写作停止 >1 分钟 | "卡住了？需要我帮你列个提纲吗？" |
| **自动整理** | 定时/手动 | 零散的笔记自动归类，生成结构化文档 |

### 4.2 AI 功能分类（按用户价值）

| 类别 | 功能 | 快感指数 |
|------|------|----------|
| **减负** | 自动排版、语法纠错、格式转换 | ⭐⭐⭐ |
| **加速** | AI 续写、扩写、缩写、翻译 | ⭐⭐⭐⭐ |
| **启发** | 随机灵感、跨界连接、反向提问 | ⭐⭐⭐⭐⭐ |
| **陪伴** | 语气调整、情绪共鸣、鼓励反馈 | ⭐⭐⭐⭐ |
| **成长** | 学习路径推荐、知识图谱、复盘提醒 | ⭐⭐⭐⭐ |

## 五、P0 需求（v4 基础，必须实现）

### 5.1 无侧栏沉浸阅读

- 无左侧边栏
- 右侧边栏默认可隐藏
- 工具栏默认隐藏，鼠标移入顶部边缘时淡入
- 全文无干扰，只剩文字

### 5.2 正文区基础编辑

- GFM 完整渲染（标题/列表/代码/表格/链接/图片/任务）
- L2 模式可选（v3 已有 CM6 decoration，v4 仍支持但非默认）
- 字号缩放 12-32px，快捷 Cmd+=/Cmd+-
- Dark/Light 自动跟随系统或手动切换

### 5.3 右侧边栏 AI 对话

- 多轮对话，支持上下文记忆
- 可读取当前文档作为参考
- 流式输出
- 任务自动化：用户说"帮我整理这篇文档"，系统执行

### 5.4 角色自适应（初版）

- 阅读模式：全屏无 chrome，工具栏隐藏
- 写作模式：显示极简工具栏 + AI 建议面板
- 手动切换 + 行为感知自动切换

### 5.5 正文分栏

- 左右分栏（独立滚轮/模式）
- 上下分栏（独立滚轮/模式）
- 分栏比例可拖拽调整

### 5.6 文件管理基础

- 打开/新建/保存 .md .html .txt
- 拖拽打开
- 自动保存（2s debounce）
- 最近文件（右侧边栏/命令面板）

### 5.7 多语言

- 界面语言：中文（v4 第一语言）
- 后续：英文、日文、韩文等
- i18n 架构：`useTranslation` + JSON 键值

## 六、P1 需求（v4 差异化：让用户爱上）

### 6.1 灵感模式

| 功能 | 描述 |
|------|------|
| 随机碎片 | 单击按钮/快捷键，显示历史文档中的随机句子 |
| 跨界连接 | AI 自动发现不同文档的隐藏关联 |
| 反向提问 | 针对当前内容，AI 提出反直觉的问题 |
| 视觉刺激 | 进入"万花筒"界面，文字碎片重组拼贴 |
| 环境音效 | 配合场景的背景音（雨/咖啡厅/轻音乐） |

> 灵感模式的目标：**让用户在卡住时，10 秒内获得新的思路。**

### 6.2 知识网络

| 功能 | 描述 |
|------|------|
| 语义关联图 | 所有文档以节点展示，关联度 = 连线粗细 |
| 关键词墨迹 | 跨文档高频词聚合，点击展开所有出现位置 |
| 自动标签 | AI 自动为文档分配关键词，无需用户手动分类 |
| 学习路径 | 系统推荐"下一步该读什么" |

### 6.3 情绪价值

| 功能 | 描述 |
|------|------|
| 心情追踪 | 写作时自动分析情绪（正面/负面/焦虑/平静） |
| 鼓励反馈 | 完成一段写作后，系统给出正面反馈 |
| 压力释放 | 检测到负面情绪时，推荐放松内容或改写建议 |
| 成长报告 | 每周报告：写作字数、阅读篇数、学习时长、心情曲线 |

### 6.4 写作快感

| 功能 | 描述 |
|------|------|
| 实时润色 | 输入时实时提示更好的措辞 |
| 风格迁移 | 选中段落 → AI 改写为"正式/口语/文艺/简洁"等风格 |
| 一键美化 | 全文自动排版优化，消除格式不一致 |
| 字数进度 | 设定目标字数，进度条实时显示 |

### 6.5 原型参考降级

以下原型在 `v6.5` 中经过实验有效，可选择整合：

| 原型 | v6.5 验证结果 | v4 可保留 |
|------|---------------|----------|
| **Erosion 侵蚀** | 视觉惊艳，减少操作阻力 | 作为阅读/写作的视觉主题 |
| **Wind 风动** | 注意力驱动自然，交互惊喜 | 作为导航的隐喻基础 |
| **Kaleidoscope 万花筒** | 重组发现新关联 | 灵感模式 = 进入万花筒 |
| **Ink Desk 书桌** | 空间记忆导航 | Desk 模式的空间隐喻 |
| **DNA 螺旋** | 过于抽象，v4 可延后 | 保留概念，暂不实现 |
| **Magnetic Field 磁场** | 相吸相斥物理引擎过于复杂 | 保留概念，v4 用简化版 |
| **墨水河** | 过于线性 | 放弃 |

## 八、非功能需求（v4 更新）

### 8.1 快感指标（新增）

| 度量 | 目标 | 说明 |
|------|------|------|
| 首次打开到专注 | <3 秒 | 打开文档 3 秒内进入沉浸状态 |
| 模式切换感知 | <200ms | 写作/阅读/灵感切换无等待 |
| AI 响应时间 | <1.5s | AI 润色/摘要/问答的首次响应 |
| 主动服务 | >30% | 超过 30% 的 AI 建议是系统主动触发的 |

### 8.2 上瘾性指标（新增）

| 度量 | 目标 | 测量方式 |
|------|------|----------|
| 单次使用时长 | >25 分钟 | 超过 25 分钟才算"沉浸式" |
| 7 日留存 | >60% | 安装后第 7 天仍有活跃使用 |
| 主动启动率 | >70% | 用户主动打开 vs 被动打开比例 |
| 每周启动次数 | >5 次 | 至少每周 5 次自发使用 |

## 九、技术栈（与 v3 一致，此处归档）

| 层 | 选型 | 理由 |

| API Key 存储 | keyring | 安全，不落盘明文 |

## 十一、决策记录（v4 新增）

| 决策 | 选择 | 理由 |
|------|------|------|
| 去掉左侧边栏 | 全部功能收入右侧边栏 | 旧模式 1995 年的遗产，不符合未来界面 |
| 角色自适应 | 行为感知 + 手动切换 | 减少用户决策，系统主动适配 |
| 左右分栏独立 | 每个分栏独立模式和滚轮 | 对比写作、参考同步场景 |
| 语义导航替代文件树 | 时间带 + 知识网络 + 空间记忆 | 用户不记得文件名，但记得"上周写的"/"和设计相关"/"在左上角" |
| AI 为底层 | AI 不是功能，是基础设施 | 写作辅助、情绪感知、知识关联都依赖 AI |
| 多语言 | 中文 v4 优先 | 印哥母语，先打磨中文体验 |

## 十二、风险（v4 新增）

| 风险           | 影响                | 缓解                            |
| ------------ | ----------------- | ----------------------------- |
| AI 成本失控      | 长文档全文分析消耗大量 token | 分层处理：标题+摘要 → 全文按需加载           |
| AI 打扰用户      | 频繁建议引发反感          | 智能降级：用户在流畅写作时，AI 静默等待，用户可以自定义 |
| 上瘾性指标难量化     | "快感"是主观感受         | 结合行为数据（使用时长、留存、NPS 问卷）        |
| 多语言后语义分析精度下降 | 中文 NLP 与英文不同      | 分语言训练语义模型，不依赖翻译               |
| 用户反感被分析情绪    | 隐私担忧              | 情绪分析本地执行，不存储、不上传              |
