## 4. 功能模块详解

### 4.1 阅读模块（reading）

**功能说明**：打开 Markdown 文档后以阅读模式渲染 GitHub Flavored Markdown（GFM）全部元素——标题、列表、代码块、表格、链接、图片、粗斜体、任务列表、分割线、引用块；支持暗色/亮色主题与全局字号缩放。

**操作步骤**：

1. 打开一篇含多类 GFM 元素的 Markdown 文档，进入阅读模式，正文以完整排版样式渲染，无元素以纯文本回退。
2. 按 `Cmd+=` / `Cmd+-` 调整全局字号（范围 12–32px，标题与正文按固定倍率同步缩放）。
3. （可选）按 `Cmd+\` 进入沉浸阅读模式，隐藏界面 chrome 专注正文（Phase R 功能，申请前以实际版本为准）。

<!-- 截图占位：reading-preview，对应 screens-config.json -->

### 4.2 编辑模块（editing）

**功能说明**：支持预览 / 源码 / 编辑模式一键切换；编辑基于 CodeMirror 6，对加粗、斜体、引用、列表、标题、代码块等核心语法做可视化美化（decoration），且不改变底层 Markdown 源码；保存采用原子写入，并具备未保存守卫与并发覆盖保护。

**操作步骤**：

1. 打开文档后点击顶栏"编辑"切换到源码编辑模式，CodeMirror 编辑器加载（`.cm-editor`），核心语法以美化样式呈现。
2. 在正文中修改或输入 Markdown 内容，可见的编辑语义与源码一致（保存往返无损）。
3. 按 `Cmd+S` 手动保存（原子写入）；编辑停止 2 秒后自动保存。

<!-- 截图占位：editing-source，对应 screens-config.json -->

### 4.3 文件管理模块（file-management）

**功能说明**：按格式分流打开文件（文本类进源码模式、媒体类进预览模式）、拖拽打开、自动保存（2 秒防抖）、`Cmd+N` 新建文档。

**操作步骤**：

1. 点击顶栏"文件"→"选择文件夹"，目录树加载并浏览工作目录文件。
2. 从系统 Finder 将 Markdown 文件拖入窗口松开即打开。
3. 按 `Cmd+N` 新建空白编辑页，首次保存时选择路径与文件名。

<!-- 截图占位：file-management-tree，对应 screens-config.json -->

### 4.4 导航模块（navigation）

**功能说明**："无侧栏"方向下的导航体系——文件树点击打开、`Cmd+[` / `Cmd+]` 历史后退/前进；统一文件面板（Cmd+P）承载目录内导航（Phase R）。

**操作步骤**：

1. 在文件树中点击目标文档，文档以对应模式打开（文本类源码模式）。
2. 在多个文档间导航后按 `Cmd+[` 后退、`Cmd+]` 前进。
3. （Phase R）按 `Cmd+P` 打开统一文件面板，支持搜索与回车直开。

> 说明：`navigation-file-panel`（Cmd+P 统一文件面板）场景当前为 **pending**（B-3 尚未实现，见 `screens-config.json` 场景 note），本阶段不采集截图；申请时若已实现需补拍。

<!-- 截图占位：navigation-tree-open，对应 screens-config.json -->

### 4.5 捕获模块（capture）

**功能说明**：灵感快速录入（Quick Capture）体系——系统级全局录入浮窗、大纲侧栏、Headings Palette 与 Inspector；条目以原子写入方式存入每日 inbox 文件。

**操作步骤**：

1. 打开文档后点击顶栏"目录"（或按 `Cmd+Shift+E`）唤出大纲侧栏，按标题结构浏览文档。
2. 在任意应用内按全局快捷键 `Cmd+Shift+.`（测试环境 `Meta+Shift+.`）唤起 Quick Capture 录入浮窗。
3. 输入灵感内容后按 `Cmd+Enter` 提交，条目存入当日 inbox 文件（支持 prefix 粘滞识别：`-` 待办、`!` 灵感等）。

<!-- 截图占位：capture-overlay，对应 screens-config.json -->

### 4.6 界面外壳模块（application-shell）

**功能说明**：单一顶栏（Chrome Bar，40px 常驻）承载全部工具栏职责，无左侧栏/右侧边栏；空状态渲染欢迎页并叠加"上次停在这"与"最近保存"分块；支持可选正文分栏。

**操作步骤**：

1. 启动应用，观察顶部 40px Chrome Bar 与正文区域布局（无侧栏）。
2. 关闭全部文档后，空状态展示欢迎页与最近文件入口。
3. （可选）按 `Cmd+Option+→` 生成左右分栏，每个窗格拥有独立 TabBar。

## 5. 操作流程（核心路径）

以下为软件的核心操作闭环：**打开文件 → 阅读 → 编辑 → 保存 → 导出**。

1. **打开文件**：按 `Cmd+O` 经文件对话框选择文档，或从 Finder 拖入窗口、或在文件树中点击打开。文本类文件进入源码/编辑模式，媒体类文件进入预览模式。
   <!-- 截图占位：navigation-tree-open，对应 screens-config.json -->
2. **阅读**：文档打开后以 GFM 排版渲染，可调整全局字号、切换主题；滚动时右缘"墨线"指示阅读进度。
   <!-- 截图占位：reading-preview，对应 screens-config.json -->
3. **编辑**：切换到编辑模式，在 CodeMirror 编辑器中修改内容，语法标记实时美化。
   <!-- 截图占位：editing-source，对应 screens-config.json -->
4. **保存**：按 `Cmd+S` 手动保存（原子写入），或停止编辑 2 秒后自动保存；存在未保存修改时切换/关闭会被守卫拦截提示。
5. **导出**：将编辑完成的文档内容交付到其他程序——选中全文复制到剪贴板（`Cmd+A` 全选 + `Cmd+C`）后粘贴至目标应用；或使用系统"打开方式/共享"菜单。> 占位说明：文件导出（PDF/HTML 等格式）能力以 V1.0 实际功能为准，申请前更新本段并与申请书描述保持一致。

## 6. 常见问题

> 以下条目为骨架占位（基于已验收行为如实编写），申请前按 V1.0 实测情况补充、删改。

**Q1：启动后没有打开任何文档，界面显示什么？**

首次启动展示欢迎页（内置示例文档 `0-welcome.md`）；存在使用历史后，欢迎页下方叠加"上次停在这"与"最近保存"入口。

**Q2：为什么打开大文件后部分排版装饰消失？**

超过 500KB 的文件会自动关闭装饰类渲染以维持滚动可用（大文件保护策略），属预期行为。

**Q3：修改内容后没有手动保存，会丢失吗？**

不会。停止编辑 2 秒后应用自动保存；手动 `Cmd+S` 亦可用。存在未保存修改时切换文档或关闭会被拦截提示。

**Q4：Quick Capture 浮窗无法唤起？**

浮窗由全局快捷键 `Cmd+Shift+.` 唤起；若该热键被系统或其他程序占用，首次启动会提示在设置中修改。

**Q5：文档被外部程序修改后再保存会怎样？**

应用会检测到磁盘文件已被外部修改，阻止盲覆盖并交由用户裁定，不会静默覆盖外部修改。
