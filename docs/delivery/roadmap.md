# 交付路线图

本路线图只做**阶段目标摘要**，回答“分几步做、每步要达成什么”。

> ⚠️ **本路线图不自称功能验收真相源。** 逐功能可验收行为（requirement 与 scenario）见 `openspec/specs/`；阶段内的功能细节不在此复制。产品级范围边界见 [范围边界](../product/scope.md)。

## 一、阶段原则

- **阶段唯一原则**：每个功能只标一个阶段。
- **依赖顺序**：地基 → 内容重 → 空间与入口 → 商业化与生态；内容重与地基可并行（contentweave 完善在另一仓库先行）。

## 二、四阶段

| 阶段 | 内容 | 验收 |
|------|------|------|
| **1 · 地基** | 改名（标月 / Biaoyue）→ 配置三层 + 原子写 + 快照回滚 + 热应用 → agent 循环（三工具 + provider 预设 + keyring + SKILL.md）→ AI 入口 V1（⌘K 浮层 + 选区动作 + 确认卡三档 + 撤销/快照 UI） | 一句「换深色主题，字号 18」热应用且可撤销；非法值被拒；换模型仍生效 |
| **2 · 内容重** | contentweave 完善 → sidecar（CLI 形态）→ 生成入口（frontmatter/全局参数 + 保存即重渲染 + 质量徽章） | 生成物单文件零外链；保存即刷新；质量徽章 |
| **3 · 空间与入口** | 布局全量（门户 + pane 树 + 阅读空间 + 网格 + 预览窗 + 设置 + 扩展 + 视图规格 + 快捷键 + 跟随系统外观）→ AI V2/V3 + 语音 | 12 条布局验收全过；语音草稿→落盘→撤销 |
| **4 · 商业化与生态** | 专业版多页/动效（收费）· 本地 LLM/多 agent · web 表面（业务图） | 基础版不被专业版污染 |

> 来源：重定位规格包 §六「新路线图」。

## 三、阶段定位说明

- **阶段 1（地基）**：把「AI 改得动、改坏能退回」的机制打通——配置分层、快照、agent 循环、入口骨架。这是后续所有可塑能力的地基。
- **阶段 2（内容重）**：把 contentweave 生成管线并入，让「生成物离线单文件」落地；源 md 唯一事实源，保存即重渲染。
- **阶段 3（空间与入口）**：门户与布局全量构建（按布局规格 12 条验收逐条过），AI 入口补齐 V2/V3 与语音第二输入源。
- **阶段 4（商业化与生态）**：专业版（多页/动效，收费）、本地 LLM/多 agent、web 表面；基础版不被专业版污染。
