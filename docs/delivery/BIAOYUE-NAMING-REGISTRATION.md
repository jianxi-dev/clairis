## 2. 命名理由

「标月」取自「以月为标」的意象：给混沌一个可指认的坐标。相比旧名，它更短、更易记，中文与拼音形态在检索上也更干净。

核心含义：

* **标**：标记、坐标、标准。把散落的想法钉在一个可回看的位置上。

* **月**：周期、节律、陪伴。不是一次性解决，而是按月、按日持续积累。

* **标月**：给每一个想法一个坐标，让它可被找回、可被续写。

适配当前产品定位：

| 产品方向 | 标月如何承载               |
| ---- | -------------------- |
| 阅读   | 给长文一个可回看的坐标          |
| 写作   | 把混乱想法标记成可续写的段落       |
| 灵感   | 在卡住时留下一个可找回的锚点       |
| 成长   | 按月积累，形成可回溯的轨迹        |
| 心境   | 降低焦虑和内耗，让用户慢慢稳定下来    |

## 6. 第 9/41/42 类近似排查补充

「标月」在第 9、41、42 类的在先注册情况**尚未检索**。Biaoyue 为自创英文词，但汉字「标月」与拼音「BIAOYUE」需分别排查。

重点排查方向：

| 类型       | 需要排查                                             |
| -------- | ------------------------------------------------ |
| 同音 / 近音  | 表月、镖月、标悦、标越                                      |
| 字形近似     | 标玥、标刖、摽月、膘月                                      |
| 拼音近似     | BIAOYUE、BIAO YUE、BIAOYUEX                         |
| **英文近似** | **Biaoyu、Biayue、Biaoyuee、Biaoyue Labs**          |
| 组合近似     | Biaoyue AI、Biaoyue智能、Biaoyue读写、Biaoyue学习         |

**注意**：汉字「标月」与拼音「BIAOYUE」在 CNIPA 检索中是两个独立标样，需分别查；英文「Biaoyue」在海外（USPTO / EUIPO）另需单独检索。建议在第 41/42 类同时申请，该类通常在先记录更少。

## 7. 第 9 类建议项目

第 9 类用于保护 App 本体和可下载软件，建议优先提交。

| 方向      | 建议保护项目                 |
| ------- | ---------------------- |
| App 本体  | 可下载的计算机应用软件、可下载的手机应用软件 |
| 桌面软件    | 已录制的计算机程序、可下载的计算机程序    |
| AI / 软件 | 可下载的计算机软件、数据处理设备相关软件项目 |
| 内容文件    | 可下载的电子出版物（如适用）         |

代理商确认点：

1. 第 9 类是否存在与"标月 / Biaoyue"近似且覆盖可下载软件、App、电子出版物的在先商标。
2. 桌面 App 与未来移动 App 是否均可通过所选项目覆盖。
3. 是否建议"标月"和"Biaoyue"分开申请，还是先申请中文。
