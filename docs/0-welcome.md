# 渐晰

**陪伴学习成长的精神伙伴。**

> 懂你、减负、惊喜、正向陪伴。

---

## 打开就读

按 `Cmd + O` 选一个文件夹。里面的文档全支持：

| 类型 | 格式 |
|------|------|
| 阅读 | Markdown、HTML、纯文本、PDF |
| 预览 | JPG / PNG / GIF、MP4 / MOV |
| 代码 | Python、JS、TS、CSS、JSON、YAML 等 30+ 语言 |

所有文件存在本地，不上传。`Cmd + S` 保存。

---

## 沉浸阅读

按 `Esc` — 工具栏、侧栏全藏起来，只剩内容。再按 `Esc` 回来。

字号跟着人走：`Cmd + =` 放大，`Cmd + -` 缩小。下次打开还是你的偏好。

---

## 找文件

按 `Cmd + P`：

- **没输入**：上次停在哪 + 最近保存
- **输入名字**：全局搜索
- **选中文本**：找相关文档

---

## 随时记录

任何界面下按 `Cmd + Shift + .`，弹出输入框。写灵感、记问题、丢一句话 — 不打断正在做的事。

记录保存在本地 `~/documents/clairis/inspiration/`，随时可查。

---

## 需要改几个字

默认是阅读器。需要编辑时按 `Cmd + Shift + M` 切到编辑模式，改完 `Cmd + S` 保存。

| 操作 | 快捷键 |
|------|--------|
| 粗体 | `Cmd + B` |
| 斜体 | `Cmd + I` |
| 删除线 | `Cmd + U` |
