# ADR 0009 — 可折叠阅读空间取代无侧栏

- **Status**: accepted
- **Date**: 2026-11-01

## Context

旧方案（`docs/product/scope.md` §2.2「无侧栏方向」）主张取消左侧边栏 + 文件树、正文区左右上下独立分栏、右侧边栏保留默认隐藏、导航由统一文件面板承担。十二轮布局迭代后，维护者定稿：旧「无侧栏」表述已不再是现行方案，由**可折叠阅读空间**取代。

## Decision

- **可折叠阅读空间**：左侧竖排栏，三态——**折叠**（12px 边缘条 + 计数徽标，正文满宽）/ **悬停浮层**（240px，absolute 覆盖，不挤压正文，移开 300ms 收回）/ **钉住**（240px，flex 常驻，正文变窄）。
- **双布局**：堆叠（段叠放 + 粘性段头）/ 标签（分段页签 + 单列表）。
- **三密度**：紧凑 32px / 舒适 56px / 卡片 112px（默认；`density.cardHeight` 可调 88–160）。
- **卡片规格**：彩色类型图标 + 标题 + 真摘要 2 行（无图通栏）/ 4:3 缩略图 + 色签 + 任务进度或阅读进度 + 日期 + 可点路径 + 右上纯图标动作。
- **低频控件入滑杆下拉**（布局/密度/快照/设为默认）；分类 = 过滤 chips；搜索独立 + × 清除。
- **推翻旧决策的依据**：可折叠阅读空间在「不抢正文」与「随时可达」之间取得平衡——折叠态满足 D1（内容是王），浮层态满足 P2（所见即可操作），钉住态满足高频用户；旧「无侧栏」把导航完全交给统一面板，牺牲了文件组织的可见性。

## Consequences

- `docs/product/scope.md` §2.2 更新为「可折叠阅读空间」，旧「无侧栏」表述删除，不保留双口径。
- 布局规格见 `docs/design/approved/layout-portal/spec.md` §4；12 条验收清单逐条过。
- 历史记录由 `docs/archive/` 与本 ADR 承担。
