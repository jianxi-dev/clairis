## What（做什么）

### A. 缺陷修复（9 项）

- A1 转换手柄的二级菜单（对齐与缩进、在下方添加行）显示后，鼠标移出应自动消失；手柄菜单显示期间移动鼠标，下层文字不应被误触发新增/转换手柄。
- A2 提示信息形状统一：同一类提示只呈现一种外壳（胶囊或矩形二选一），不再时胶囊时矩形。
- A3 mermaid 转换手柄识别稳定：复现文档中「伪动画时间轴（单图显示全流程）」与「颜色编码流程」两处，手柄不得停在边框右上角；「使用图标增强表现」处须能识别出手柄；「伪动画时间轴」展开的转换菜单须与手柄贴合不脱离。
- A4 分栏：栏目内已有文字时点击进入不得重复显示同一段文字；栏目左上角无意义的小方框要么给出明确作用要么移除；栏目前的 `+` 鼠标滑入须保持可见并显示选择菜单；分栏之间的间隔线须可见。
- A5 分栏与表格单元格的「内」「外」区域渲染效果一致且正确：目前单元格内只能显示源码格式，须像正常正文一样渲染。
- A6 编辑态边框对齐：代码块左右边框当前比引用块窄、引用块右边框比 mermaid 窄——三者左右边框与正文文本块对齐且彼此一致。
- A7 图片编辑工具条：点「裁剪」须呈选中态、裁剪后图片不得自动缩小；「添加描述」默认未选中、描述输入区默认隐藏，点「添加描述」转选中并展示输入区；「添加描述」的图标与文字分离观感差，更换为更贴切的图标。
- A8 图片与视频转换手柄图标：补上拖拽的四点（六点手柄），且显示位置与标题手柄位置对齐。
- A9 编辑态表格：鼠标滑入表格与单元格须显示手柄（参考三张截图：表头转换手柄、单元格转换手柄、单元格新增手柄），单元格的转换/新增手柄菜单与全局菜单观感一致。

### B. 功能优化（7 项）

- B1 新增手柄菜单重构为「基础」「常用」两部分：基础部分只显示图标（仿转换手柄效果），顺序为 H1~H3 标题、有序列表、无序列表、任务、引用、分割线、代码块、链接；常用部分显示文字，含标题、高亮、分栏、表格、图片、视频或文件、公式、内嵌网页。
- B2 状态栏「页面宽度」弹窗：进度条颜色与 4 档选项中被选中块的颜色一致，其余 3 档使用相近色。
- B3 新增手柄中的「分栏」：弹出面板顶部增加说明文字「选择栏目」，用户选择时上方实时显示当前选择的栏数。
- B4 页签文件右键菜单：把「移动到」的图标换成更贴切的图形（不与「打开文件位置」重复）；「导出」子菜单鼠标滑入即自动显示二级菜单（无需点击）。
- B5 插入文件嵌入显示：pdf / md / html / 内嵌页面等插入后不只显示文件名或链接，而是在正文中内嵌真实内容渲染；默认一屏高度；可调整显示高宽；可滚动查看；滚动到某区域后鼠标滑出即定格，再次打开保持该定格（除非再次滚动到其他区域）；可切换「只显示文件名/链接」或「显示内容」；仅显示名称/链接时鼠标滑入弹出悬浮窗预览内容；点击支持本产品打开的链接文件，在新标签页中打开。
- B6 md 编辑态下选中文字弹出的横向工具条，其按钮功能回滚到上一版。
- B7 页签文件名鼠标滑入的提示改为下拉信息窗，含：文件名、完整路径（路径每层文件夹可单击打开）、最近保存时间（参考截图《文件信息》）。

### C. 新增功能（5 项）

- C1 md 标题：每一级标题可自定义字体，字体从本机选择；默认字体参考 md-bundle 预览态的字体。
- C2 鼠标点按「栏目页签空白处」并移动，可拖动窗口移动。
- C3 左边栏：新增固定隐藏/显示与其快捷键；隐藏后即使鼠标滑入触发左边栏的区域也不显示，左侧箭头区域彻底消失；取消固定隐藏后箭头区域恢复、鼠标滑入自动触发显示。设置中增加对应开关。
- C4 文本及脚本文件：编辑器行号区在文本/脚本文件前显示行数；预览态也须支持语法颜色显示与代码块缩进格式。
- C5 颜色菜单：在背景色下方新增「恢复默认」按钮。

## Why（为什么）

- A1/A2/A4/A9 是交互层「点了没反应 / 该消失的没消失 / 该出现的没出现」，直接阻断编辑动作；A7/A8 是工具条状态与手柄可见性错误，用户无法确知当前操作状态。
- A3 让含大量 mermaid 的文档（本仓典型用户场景：读书笔记）转换手柄不可用，等于该块无法通过手柄编辑。
- A5/A6 是渲染与排版正确性：单元格内退化成源码、边框宽度不一致，破坏编辑态与预览态的一致性预期。
- B1/B3/B4/B7/C5 降低菜单与提示的认知成本；B5 把「插入文件」从占位符升级为可读内容，是阅读体验的核心增量。
- B2 的进度条与选中块不同色属配色缺陷，误导当前档位判断。
- C1/C4 提升长文与代码阅读体验；C2/C3 提升窗口与布局操作的可用性；C6（B6）回滚一次回归。

## Scope（范围）

- 编辑器手柄与菜单系统（转换手柄、新增手柄、图片/视频/表格手柄、二级菜单收起、悬浮提示外壳）。
- mermaid 块的手柄定位与菜单贴合（含复现文档三处）。
- 分栏块的渲染、交互与间隔线；分栏/表格单元格内外空间渲染。
- 编辑态边框对齐（代码块 / 引用块 / mermaid）。
- 图片工具条（裁剪态、描述区、图标）与图片/视频手柄。
- 状态栏页面宽度弹窗配色。
- 页签右键菜单（移动到图标、导出 hover 二级）。
- 插入文件的内嵌渲染、尺寸调整、滚动定格、悬浮预览、新标签页打开。
- 横向工具条按钮行为回滚。
- 页签名信息下拉窗。
- md 标题自定义字体（含配置落点）。
- 窗口拖动（栏目页签空白处）。
- 左边栏固定隐藏/显示 + 快捷键 + 设置开关。
- 文本/脚本文件行号 + 预览态语法颜色/缩进。
- 颜色菜单恢复默认按钮。
- 相关 e2e 与必要单测。

## Non-goals（不做）

- 不改导出产物格式与导出管线（除 B4 的菜单承载方式）。
- 不重排既有右键菜单其余项的顺序与行为。
- 不改系统打印能力与打印视图（属 batch18 已交付范围）。
- 不改 mermaid 渲染引擎本身（仅手柄定位/菜单贴合）。
- 不引入新的主题或换肤体系；不重画图标库整体（仅更换/补齐点名图标）。
- 不做移动端/触屏布局。
- md 标题字体不改预览态默认排版规则（默认字体仍按 md-bundle 预览态，仅提供逐级覆盖）。

### 4. 冲突显式

- **A9 ↔ B1**：A9 要求单元格手柄菜单与「全局菜单」一致，B1 重构了全局新增手柄菜单。裁定：**B1 先行**，A9 复用 B1 之后的全局菜单；A9 不承担新菜单结构，只要求单元格入口复用同一菜单组件与项集。
- **A6 ↔ A5**：A6 的编辑态边框对齐与 A5 的单元格 / 分栏「编辑态容器内边距 / 边框」是同一个面。裁定：编辑态容器内边距与边框宽度由 E-8（编辑态与预览态同貌）统一，A5 只负责单元格 / 分栏内外的渲染一致性（内外都按正文渲染）；两票共享同一 CSS 面，不得各改一处。
- **C1 ↔ E-8**：C1 的逐级标题字体覆盖 E-8 的「编辑态与预览态共享正文字体族」——标题字体是标题面的覆盖，正文与代码字体不受影响；默认值取 md-bundle 预览态字体即与 E-8 现状一致。
