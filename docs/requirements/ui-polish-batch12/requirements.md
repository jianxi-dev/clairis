# 需求四要素 — ui-polish-batch12

> 规格票：https://github.com/jianxi-dev/clairis/issues/538
> 需求输入包：`docs/requirements/ui-polish-batch12/input-package.md`

## What

在一个 change 内交付 9 条用户可见变更：

1. 视频以暂停态打开、重启不自动续播；多视频格独立控制且可同时出声。
2. 转换手柄二级菜单展开后指针滑出不收起。
3. MD 编辑态字色与背景色可叠加；清除格式对背景色生效。
4. 页面宽度四档（含 1080）、悬停显隐、色块高度递进与对比度提高。
5. 页签右键菜单迁入「复制路径」并新增「移动到…」；栏目「更多」移除「复制路径」。
6. 新建文件默认保存路径可配置并持久化。
7. 全部自绘悬停提示改胶囊形；选区轮盘扇区悬停显示提示。
8. 阅读空间左栏 HTML 文件卡片缩略图稳定显示。
9. 沉浸模式 PDF 顶栏自动收起；页签栏与 PDF 按钮栏以悬浮栏呈现。

## Why

- 走查发现的实际打断：自动播放与多路音频互斥破坏阅读/对照场景。
- 显隐规则不一致让浮层「点不到 / 常驻遮挡」。
- 行内格式无法叠加限制了标注表达；清除格式失效迫使用户手工清理。
- 文件操作能力缺口（复制路径入口错位、无法移动）迫使离开应用。
- 提示形状与设计系统不一致（§5 已定义 `--radius-full`）。
- 沉浸模式的常驻工具条与占流页签栏持续压缩正文。

## Scope

- 覆盖：`src/`（React/TS/CSS）与 `src-tauri/`（文件移动命令、配置字段）、`e2e/`、`openspec/`、`docs/design/system/decisions.md`。
- 涉及能力：`reading`、`editing`、`application-shell`、`file-management`。

## Non-goals

- 不做播放列表跨格共享、视频转码、字幕轨自动加载。
- 不提供页面宽度任意像素输入，不改档位语义。
- 不重画图标，不改间距/字号/圆角刻度（只追加 decisions.md 单点行）。
- 不自研目录选择组件。
- 不做跨卷移动的特殊处理（失败即报错保持原位）。
