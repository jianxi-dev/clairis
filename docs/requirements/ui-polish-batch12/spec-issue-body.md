## Problem Statement

用户 2026-11-10 第十二次真机走查列出 9 条体验缺陷与缺口，集中在四类问题：

1. **媒体与工作区恢复不符合预期**：打开视频立刻自动播放；程序重启后视频继续自动播放；多栏同时播放视频时只有一路能出声、各自无法独立控制。
2. **浮层与提示的显隐规则不统一**：转换手柄二级菜单指针一滑出就消失；状态栏页面宽度控件滑入才显示按钮但弹窗不跟随；沉浸模式下 PDF 顶部按钮栏常驻，页签栏与 PDF 按钮栏都占着正文高度。
3. **格式与文件操作能力不足**：MD 编辑态给文字设了字体色再设背景色后显示异常（两者不能叠加）；对已设背景的选区点「清除格式」无反应；页面宽度只有 3 档且缺窄屏档位，色块选中态辨识度低；「复制路径」埋在栏目「更多」里而页签右键菜单没有；无法把当前文件移动到其他文件夹；新建文件不能配置默认保存路径。
4. **提示与缩略图的一致性**：悬停提示仍是矩形且样式不统一；选区轮盘各扇区悬停没有提示；阅读空间左栏滚动到 HTML 文件时卡片缩略图有时空白。

## Solution

按 9 条需求逐条修复/扩展，每条交付一个用户可直接在页面上验证的变化：

1. 视频一律以暂停态打开，程序重启不续播；每个视频格独立持有播放状态与控制，多路可同时出声。
2. 转换手柄二级菜单展开后不因指针滑出而收起（仅在选中、外部点击或 Esc 时关闭）。
3. 字体色与背景色可嵌套叠加且同时渲染正确；清除格式对背景色同样生效。
4. 页面宽度滑入显示按钮与弹窗、滑出全部隐藏；档位扩为 4（新增 1080），四个色块按档位递增高度，选中/未选中对比度提高。
5. 页签右键菜单分隔线下方提供「复制路径」与「移动到…」，栏目「更多」移除「复制路径」。
6. 设置页可配置新建文件的默认保存路径，并持久化。
7. 全部自绘悬停提示统一为胶囊形；选区轮盘每个扇区悬停显示中文提示。
8. 阅读空间左栏 HTML 文件卡片缩略图稳定显示。
9. 沉浸模式下 PDF 顶部按钮栏 1.2s 无交互自动收起；页签栏与 PDF 按钮栏以悬浮栏形式浮现，不改变正文高度。

## User Stories

1. 作为阅读者，我希望打开含视频的文档时视频停在暂停态，这样不会突然出声打断我。
2. 作为阅读者，我希望重启程序后视频不会自动续播，这样恢复工作区时不会被打断。
3. 作为阅读者，我希望在分栏里同时播放多个视频时每一路都能单独播放/暂停，这样我可以对比两段素材。
4. 作为阅读者，我希望多路视频同时出声而不是只有一路，这样我能同时听到两边的音频。
5. 作为编辑者，我希望展开转换手柄的二级菜单后移动鼠标去点选时菜单不会消失，这样我不会点空。
6. 作为编辑者，我希望二级菜单只在选中、点击外部或按 Esc 时收起，这样显隐规则可预期。
7. 作为编辑者，我希望先给文字设字体色再设背景色时两者同时生效，这样我做的标注不会丢颜色。
8. 作为编辑者，我希望清除格式能一并去掉背景色，这样我不必逐段手工删除。
9. 作为编辑者，我希望鼠标滑入页面宽度控件时按钮与弹窗一起出现、滑出一起消失，这样界面不常驻杂物。
10. 作为编辑者，我希望页面宽度有 4 个档位并包含 1080，这样窄屏和宽屏都能选到合适宽度。
11. 作为编辑者，我希望四个档位色块的高低按档位递增，这样我能一眼看出档位关系。
12. 作为编辑者，我希望选中档位与未选中档位的颜色对比明显，这样我知道当前在哪一档。
13. 作为编辑者，我希望在页签上右键就能复制该文件路径，这样不用先去找栏目菜单。
14. 作为编辑者，我希望页签右键菜单能把当前文件移动到另一个文件夹，这样我不用离开应用去搬文件。
15. 作为编辑者，我希望栏目「更多」菜单里不再重复出现「复制路径」，这样菜单职责单一不重复。
16. 作为编辑者，我希望在设置里填写新建文件的默认保存路径，这样我新建的文档落在固定位置。
17. 作为用户，我希望所有悬停提示都是胶囊形，这样界面观感统一。
18. 作为编辑者，我希望鼠标滑过选区轮盘的每个扇区时看到提示文字，这样我不必凭图标猜功能。
19. 作为阅读者，我希望滚动到左栏的 HTML 文件卡片时缩略图稳定显示，这样我能靠缩略图认出文件。
20. 作为阅读者，我希望沉浸模式下 PDF 顶部按钮栏会自动收起，这样正文能占满视野。
21. 作为阅读者，我希望沉浸模式下把鼠标移入页签区时页签栏以悬浮形式出现，这样我不退出沉浸也能切换文件。
22. 作为阅读者，我希望沉浸模式下 PDF 按钮栏也以悬浮形式出现，这样它能用但不挤压正文。

## Implementation Decisions

- **视频起播态**：播放器创建时不请求播放、`autoplay` 关闭；工作区恢复只恢复「打开了哪些文件」，不恢复播放进度与播放状态。多路并行由每格独立持有 `<video>` 与播放状态保证，不做单例音频代理、不做互斥静音。已有「媒体播放器按格隔离」的裁决（#493）继续适用。
- **转换手柄二级菜单**：关闭由指针离开触发改为显式触发（选中项 / 外部点击 / Esc）；撤销 batch10 里「移出不消失」之外的指针离开收起路径，并保留指针离开后高亮复位。属于回归修复，按 DQ-3 先红后绿。
- **MD 行内格式**：字色与背景色各为一层独立包装，允许嵌套；渲染层保证内外层各自生效（内层背景不覆盖外层文字色）。清除格式对选区相交的全部包装节点解包，含背景色节点，一次提交可撤销；保留链接节点（既有契约）。
- **页面宽度**：档位从 3 扩到 4（新增 1080），控件为 4 个色块且高度按档位递增；悬停进入控件区域显示按钮与弹窗，离开后两者一起隐藏（同一容器门控，不做两个独立计时器）。选中/未选中用 accent 实色 vs 描边拉开对比。
- **页签右键菜单**：菜单项顺序为「常用文件操作 → 分隔线 → 复制路径 / 移动到…」。复制路径复用既有剪贴板写入路径。移动到…调用系统目录选择器，成功后更新页签对应路径与标题，失败保持原路径并提示。
- **新建文件默认路径**：配置新增默认保存路径字段，缺省 `null` 表示沿用当前行为（首次保存时选择路径，见既有 C-4 场景）；设置页提供读写入口。持久化走既有配置存储，不进 API key ring。
- **悬停提示**：统一为自绘胶囊 tooltip（`--radius-full`），统一延迟与位置规则；原生 `title` 一律替换为自绘实现，避免系统矩形提示混入。轮盘扇区悬停复用同一提示组件，文案为其中文名。
- **阅读空间缩略图**：HTML 卡片缩略图改为「可见时才生成、失败可重试」；生成失败保留可辨识占位而非空白。
- **沉浸模式**：PDF 顶部按钮栏 1.2s 无指针/无焦点自动收起，指针接近顶部或键盘聚焦时复现。页签栏与 PDF 按钮栏在沉浸态以 `position: fixed` 浮层出现，不参与流式高度（复用 #484 的状态栏 peek 原则）。

## Testing Decisions

- 好测试的标准：只断言外部可观测行为——真实浏览器事件（hover、pointermove、click、contextmenu）、真实 `HTMLVideoElement` 状态（`paused` / `muted` / `currentTime`）、`getComputedStyle` 计算值、源码字符串；不断言内部函数返回值，不 mock CodeMirror 内部状态。
- 覆盖模块：`e2e/video-multi-pane.spec.ts`、`e2e/status-width.spec.ts`、`e2e/tab-context-menu.spec.ts`、`e2e/pdf-chrome.spec.ts`、`e2e/immersive-*.spec.ts`、`e2e/rail-cards.spec.ts`、`e2e/block-color.spec.ts`、轮盘相关 `e2e/*roulette*` 及新增 tooltip 用例。
- 既有测试先例：`e2e/video-multi-pane.spec.ts`（双栏播放）、`e2e/status-width.spec.ts`（宽度档位与 hover）、`e2e/tab-context-menu.spec.ts`（右键菜单项）、`e2e/immersive-peek.spec.ts`（沉浸浮层）。
- 新增用例须至少覆盖「状态往返」级：打开→操作→撤销/移出→回初始无残留。
- 证据：每个 UI 票产出 `.artifacts/<票号>/state-coverage.json`，≥4 态。

## Out of Scope

- 不做播放列表跨格共享、不做视频转码、不做字幕轨自动加载。
- 不改页面宽度档位的语义，不提供任意像素输入。
- 不重画图标，不改设计系统刻度；新增单点视觉裁决只追加 `docs/design/system/decisions.md` 一行。
- 不引入自研目录选择组件，移动文件复用系统对话框。
- 不做文件移动的跨卷/U 盘场景特殊处理（失败时报错并保持原位）。
