## 三、一手证据

- 全部需求来自用户本人口述，无第三方转述、无竞品对标推论。
- R-3 的渲染样例为用户直接给出的 HTML 片段：`<span class="mdb-color-green"><span class="mdb-bg-purple">发现遗漏</span></span>`——即「外层文字色 + 内层背景色」的嵌套必须同时生效。
- R-8「有时不能显示」的间歇性：需在实现前以探针复现并记录机制解释（否则按 DQ-4 精神不得以「重跑正常」结案）。
