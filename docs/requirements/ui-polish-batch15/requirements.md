# requirements — ui-polish-batch15

> Spec issue: https://github.com/jianxi-dev/clairis/issues/660
> 生效日期：2026-11-11
> 来源：用户 2026-11-11 第二批口述 10 项。

## What（做什么）

1. 视频：播放结束自动播放下一个；竖拍视频按旋转元数据转正并适配窗口。
2. 轮盘：取消选中文字自动召唤；新增开关快捷键与默认形态（圆心/整盘）配置；双击圆心切换；中键拖动位置并持久化。
3. 轮盘搜索：按一/二级动作名过滤，只显示匹配动作及可执行子动作，不显示层级名、不重复、最多 9 行、首个默认选中、超出滚动；每行右侧显示快捷键（首行回车，其后 cmd/ctrl+2~9），滚动时快捷键列固定。
4. 提示信息：显示时长可配置，单位秒，允许 1 位小数。
5. 块对齐：编辑态隐藏 `:::` 标记，源码态保留。
6. 音视频页签喇叭按文件独立静音。
7. 音频：静音立即停止（消除现有约 1 秒的声音残留）；播放列表自动识别同目录音频。
8. PDF：顶部按钮栏「固定显示 / 固定隐藏」开关与快捷键。
9. 顶栏：去掉产品名与窗口按钮区，按钮按左栏钉住状态落到栏目页签栏或左栏，第一个页签相应避让/复位；去掉左栏「阅读空间」标题。
10. 轮盘：历史分组复制与前进之间插入剪切；颜色二级透明项提升可辨识度。
11. 栏目「更多操作」菜单按窗口边界翻转，不越界。

## Why（为什么）

- 视频连播与旋转是观看连续性的底线；横躺画面直接不可用。
- 轮盘当前「选中即弹」干扰阅读与选择，且不可配、不可移动、无搜索；动作多时只能靠肉眼扫。
- `:::` 作者语法外泄到 WYSIWYG，用户直接看到标记，破坏编辑体验（既有规格只要求写进源码，未要求露出）。
- 页签喇叭不独立导致一个媒体静音牵连其它；静音截断与无播放列表让音频可用性差。
- PDF 按钮栏无法收纳，占用阅读空间。
- 顶栏产品名与窗口按钮位置不符合当前外壳布局，且挤压第一个页签。
- 轮盘历史缺剪切、颜色透明项看不清、栏目菜单被裁，属于高频操作的可达性问题。

## Scope（范围）

- 涉及表面：视频播放器、音频播放器、PDF 视图、选区轮盘（含搜索与颜色二级）、块对齐装饰、顶栏/栏目/左栏、提示组件、设置面板。
- 影响既有规格：`application-shell`（顶栏与菜单位置）、`configuration`（新增配置项）、`reading`（视频/PDF）、`editing`（轮盘/对齐/音频）。
- 数据面：新增提示时长、轮盘开关快捷键、默认形态、位置四项配置，走配置快照回滚。

## Non-goals（不做）

- 不做轮盘整体视觉重设计；只做本清单内的召唤/形态/搜索/位置/配色项。
- 不做视频转码或重新编码。
- 不做音频波形/均衡器。
- 不做顶栏品牌视觉重设计。
- 不做移动端/触摸手势。
