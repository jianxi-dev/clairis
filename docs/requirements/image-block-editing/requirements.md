# requirements — image-block-editing

> Spec issue: https://github.com/jianxi-dev/clairis/issues/649
> 生效日期：2026-11-11
> 来源：用户 2026-11-11 口述 10 项（含截图 1 张）+ Playwright 真机探针复现。

## What（做什么）

**A. 图片块编辑（1–7）**

1. 图片引用后默认居中；支持从剪贴板粘贴插入图片。
2. 去掉悬停浮出的「替换 / 删除 / 定位」三个空操作按钮。
3. 支持上下左右四边拖拽改尺寸（左右改宽、上下改高、四角等比）。
4. 尺寸写回不再产生 `<!--w=N-->`，且不得把标记写进图片路径。
5. 点击图片进入选中态（四角圆点）+ 图片上方居中工具条：AI / 裁剪 / 评论 ｜ 左对齐 / 居中 / 右对齐 ｜ 剪切 / 复制 / 删除。
6. 裁剪：在图片四周拖出裁剪框，只显示裁剪区域；原图与引用不变，可反复调整。
7. 描述：图片下方显示「输入图片描述」占位，输入后显示文字，再次点击收起。
8. 双击图片最大化查看，Esc/双击退出。
9. 图片圆角显示。

**B. 块手柄与转换菜单（5、9、10）**

10. 图片前的转换手柄显示图片图标；菜单项为「缩进与对齐 / 剪切 / 复制 / 删除」在下方排列。
11. 转换菜单的「插入 CSS」「缩进与对齐」及其子功能全部带图标。
12. 二级菜单指针移出即卸载，不再残留。
13. 「转为」网格前两行去掉文字标签，只保留图标。

**C. 高亮块（8 / #566）**

14. 高亮块的块手柄显示高亮图标（当前错显引用图标）。
15. 高亮块图标与标题之间间距 ≤2px（当前实测 9px）。
16. 图标随类型切换的行为保持（#617 已修，补相邻同类型回归用例）。

## Why（为什么）

- 图片是最高频插入物，当前只能"看"：不能居中、不能粘贴、不能选中、不能调尺寸、不能加描述。
- 尺寸持久化用的 HTML 注释会把文档写坏：真机复现 `![带括号](assets/image%20(1)<!--w=155-->.png)`——路径含括号时注释被插进图片 URL，图片裂开且行尾漏出 `.png)`。
- 转换菜单的图标与二级菜单隐藏已写进规格（A-8.1–A-8.4），用户连续反馈 4 次仍未生效；上一批 change 声称修过，说明验收证据没有覆盖真实浏览器行为。
- 高亮块图标在上批被判定已修；真机复测证明「emoji 跟随」已修、但间距仍 9px，且块手柄仍是引用图标。#566 验收条件包含间距项，属未完成。

## Scope（范围）

- 涉及表面：MD 编辑态图片渲染与交互、块手柄、块菜单/转换菜单、高亮块卡片头部、预览渲染器的图片属性消费。
- 影响既有规格：`editing`（E-8、E-11、E-17、转换菜单、高亮块图标）。
- Rust 侧：新增 `import_media_bytes`（粘贴写盘），复用 assets 去重与命名策略。
- 不改：模式切换机制、EditorView 生命周期、Markdown 底层语法包。

## Non-goals（不做）

- 不做完整批注/评论系统；评论按钮只落一行可编辑引用块。
- 不做图片旋转、滤镜、AI 生成/重绘。
- 不做视频/音频/文件卡片的编辑能力。
- 不做触摸手势与移动端适配。
- 不改导出格式。
