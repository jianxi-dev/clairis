# editor-refine-batch1：批1~3 验收返修（菜单快捷键 / 高亮调色 / 图片编辑 / 豆包式行手柄 / 附件卡 8 项）

> 对账确认：2026-11-23「#5 选豆包式行手柄，#8 高度选①，其余全按默认」。
> 上游：editor-foundation-batch1 / editor-interaction-batch2 / editor-batch3-lowcost（均已归档）交付后的用户验收返修。

## Problem Statement

批 1~3 交付后验收发现 8 类问题，用户现在打开页面：

1. 菜单行没有可见的快捷键区域（快捷键只在悬停提示里）；文件名右键菜单还是旧的小圆角，和其他菜单不是一套。
2. 高亮块无法调整颜色——批次 3 交付的三色面板没有可达的调色入口；标注菜单里也没有高亮类型入口。
3. 有序列表的手柄图标显示成了无序列表的图标。
4. 图片编辑与 Quiet 差距大：编辑图标无选中态、图片自动缩小、裁剪标识小、拖动柄样式不对、裁剪一次就弹回、多出「保存」文字、描述区域常驻显示、《中汽系统搭建情况对称1110.md》图片手柄偶发缺失。
5. 转换手柄按块显示、不跟行走。
6. 附件的手柄显示的是图片图标。
7. 表格和高亮块的手柄落在左上角，与其他块位置不统一。
8. 附件卡多格式效果未实现：md 展开后内容居中、无样式调整；docx 无法调位置；引用前加空格整块退化成源码。

## Solution

按已确认的对账处置做八项修复与完善：

1. **菜单快捷键区**：每个菜单行右侧新增快捷键显示区（kbd 样式，无快捷键留白），覆盖块菜单/浮条/轮盘/文件名右键菜单；全部菜单容器圆角统一走菜单圆角 token（12px）。
2. **高亮块调色**：恢复 Quiet 式入口——点击高亮块，上方浮条出现颜色图标，点开可调填充/边框/文字三色；标注类子菜单顶部新增「高亮类型」行。
3. **有序列表图标还原**：手柄图标映射还原有序编号图标。
4. **图片编辑 Quiet 对标**：编辑图标选中态、图片不缩小、裁剪角标加大、裁剪样式拖动柄、裁剪态常驻、移除「保存」文字、描述区默认隐藏仅按钮控制、修复手柄偶发缺失。
5. **豆包式行手柄**：每行一个手柄；上级行转换联动下级，末级行只转当前行；列表转高亮=外套高亮保留列表。
6. **附件手柄图标**：按扩展名映射附件类图标。
7. **手柄位置统一**：表格/高亮块手柄统一到块左侧垂直居中。
8. **附件卡**：md 默认展开（宽度=正文同宽、高度自适应+600px 上限+内部滚动+底缘渐隐）、md/docx 样式调整面板（对齐+宽度）、docx 位置调整、修复空格退化 bug。

## User Stories

1. 作为用户，我想在菜单每行右侧直接看到快捷键，以便不用逐个悬停就能记住常用操作。
2. 作为用户，我想文件名右键菜单的圆角与其他菜单一致，以便整个应用的菜单看起来是一套。
3. 作为用户，我想点击高亮块时上方出现浮条并有颜色图标，以便像 Quiet 一样快速调整颜色。
4. 作为用户，我想在颜色面板里分别调整高亮块的填充/边框/文字三色，以便精确还原我想要的标注效果。
5. 作为用户，我想在标注菜单的子菜单顶部看到「高亮类型」行，以便快速在类型之间切换。
6. 作为用户，我想有序列表的手柄显示有序编号图标，以便一眼区分有序和无序。
7. 作为用户，我想进入图片编辑时编辑图标呈选中态，以便知道编辑模式已激活。
8. 作为用户，我想编辑图片时图片保持原尺寸，以便看清正在编辑的内容。
9. 作为用户，我想裁剪角标足够大且明显，以便准确拖动裁剪边界。
10. 作为用户，我想拖动手柄是裁剪样式的图标，以便理解拖动的用途。
11. 作为用户，我想进入裁剪态后保持常驻，以便连续调整裁剪区域而不用反复重新进入。
12. 作为用户，我想裁剪区下方没有多余的「保存」文字，以便界面干净、保存入口唯一。
13. 作为用户，我想图片描述区域默认隐藏、仅由工具条按钮控制显隐，以便不被常驻描述区干扰。
14. 作为用户，我想裁剪时描述区域强制隐藏，以便裁剪视野干净。
15. 作为用户，我想《中汽系统搭建情况对称1110.md》里的每张图片都有手柄，以便能正常编辑所有图片。
16. 作为用户，我想每一行都有自己的转换手柄，以便像豆包一样在任意行直接操作。
17. 作为用户，我转换上级行时下级行联动转换（2 层无序列表转有序：两级都变，2 级按自身编号规则排号），以便整棵子树一次到位。
18. 作为用户，我转换末级行时只转换当前行，以便不影响兄弟与上级。
19. 作为用户，我把有序/无序列表转高亮时列表格式保留（外套高亮），以便不丢失列表结构。
20. 作为用户，我想附件的手柄显示附件图标（按扩展名），以便一眼识别块类型。
21. 作为用户，我想表格和高亮块的手柄与其他块一样在左侧垂直居中，以便操作位置可预期。
22. 作为用户，我想 md 附件默认展开且与正文同宽，以便直接阅读附件内容。
23. 作为用户，我想长 md 附件在 600px 上限内滚动且底缘有渐隐提示，以便主文档阅读不被撑爆。
24. 作为用户，我想 md/docx 附件有样式调整面板（对齐+宽度），以便控制附件的呈现。
25. 作为用户，我想 docx 卡片可调整显示位置（对齐），以便排版随心。
26. 作为用户，我想在附件引用前加空格不会让整块退化成源码，以便正常编辑引用行。

## Implementation Decisions

1. **菜单快捷键列**：菜单行右侧新增快捷键显示区（kbd 样式）；无快捷键的动作留白；覆盖块菜单、浮条、轮盘、文件名右键菜单。既有「悬停 title 补快捷键」保留，可见列为增量。
2. **圆角统一**：所有菜单/浮窗容器圆角统一走菜单圆角 token（12px），行圆角走行 token（6px）；文件名右键菜单接入同一 token，不再写旧的小圆角字面量。
3. **高亮块调色入口**：恢复 Quiet 式交互——点击高亮块 → 上方浮条 → 颜色图标 → 三色面板（填充/边框/文字 + 恢复默认）。复用批次 3 交付的三色面板与「一次改色一步撤销」机制，只补可达入口与浮条呈现。
4. **高亮类型子菜单**：标注类子菜单顶部新增「高亮类型」单行（既有类型预设列表，含「纯高亮」），交互对齐 Quiet（展开类型列表，选择即转换）。
5. **有序列表手柄图标**：图标映射还原有序编号图标，与无序区分；映射仍按首行内容判定（`^\s*\d+\.` → 有序）。
6. **图片编辑态（Quiet 对标）**：
   - 编辑按钮按下呈选中态高亮；
   - 编辑态图片保持原渲染尺寸不缩小；
   - 裁剪角标（四角括号把手）加大至明显可点；
   - 拖动手柄图标换成裁剪样式图标；
   - 裁剪态常驻：进入后保持，直到用户主动确认/取消；单次拖动不弹回选中态；
   - 移除裁剪区下方「保存」文字，保存走工具条既有双入口；
   - 描述（caption）区域默认隐藏，仅由工具条按钮切换显隐，裁剪态强制隐藏；
   - 修复特定 md 图片手柄偶发缺失：实施时先复现并定位根因（怀疑手柄对账键/重建时机），根因确认后按证据修复。
7. **豆包式行手柄**（对账 #5 裁决）：
   - 手柄按可视文本行显示，每行一个，跟行走；
   - 层级联动转换：上级行手柄触发转换时联同下级一起转换；末级行只转换当前行；
   - 编号规则：联动转换时子级按自身层级的编号规则排号（2 级转有序按 2 级规则排号）；
   - 包裹语义：有序/无序列表转高亮 = 在列表外套上高亮格式，列表保持原格式；
   - 拖动语义：拖动上级行 = 移动该行及其子级树（与联动转换同构）；
   - 表格/代码块等非文本行块不产生行手柄（表格走表格手柄）。
8. **附件手柄图标**：按附件扩展名映射附件类图标，机制同图片扩展名映射（D13）。
9. **手柄位置统一**：表格与高亮块的手柄位置统一到块左侧垂直居中，不再落在左上角。
10. **附件卡**：
    - md 附件默认展开：宽度=正文同宽；高度=内容自适应，上限 600px（对齐 Quiet 附件缩略图 clamp 哲学），超出内部滚动，底缘渐隐提示截断；
    - md/docx 附件提供样式调整面板（对齐+宽度，面板式同图片）；
    - docx 卡片提供显示位置（对齐）调整；
    - 修复：附件引用行首添加空格后整块退化为源码显示的 bug。

## Testing Decisions

- **只测外部行为**（QG-4）：可见性断计算样式（不是元素存在）、转换断文档文本结构、手柄断 DOM 与位置、状态机断六态往返。
- **接缝**：最高接缝 Playwright e2e（复用既有 `window.__biaoyue_store__` / `__biaoyue_openFile__` 桥），不新增 seam。
- **e2e**：每行手柄出现与跟随行走、层级联动转换后的文档结构（含 2 级编号排号）、外套高亮结构、菜单快捷键列可见、圆角计算值、高亮块调色后的 CSS 变量、图片编辑→裁剪态状态机（进入→常驻→主动退出）、附件卡展开高度/滚动/渐隐、空格退化回归。
- **单测（纯函数）**：行↔块映射、层级联动转换规则、扩展名→图标映射；先例：calloutAttrs 测试与手柄纯函数既有测试。
- **CI 门禁**：四件套（tsc / eslint / vitest）+ ui-surface 票 e2e。
