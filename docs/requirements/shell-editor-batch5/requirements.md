# requirements — shell-editor-batch5

> Spec issue: https://github.com/jianxi-dev/clairis/issues/311
> 生效日期：2026-11-08
> 来源：用户 2026-11-08 一次走查的 26 项反馈（无人值守模式下委托）。

## What（做什么）

在一次 change 内，按用户可见"表面"修复/补齐 26 项：

1. 沉浸模式：悬浮页签条跟随指针所在格、补齐跨格拖拽、消除条上露白、空格兜底文件名
2. 页签拖拽：跟手 ghost
3. 左边栏隐藏识别边无色
4. HTML 编辑态异常（预览正常）
5. PDF：去缩放按钮改捏合、卡片真缩略图
6. PDF：滚动页码条移入顶部按钮区、停止随滚动浮现
7. 图标：word/zip/mdpkg 专形、字幕↔快捷键区分、播放器控件尺寸统一、暖色图标、沉浸改图标、钉住切 pinOff
8. 视频切换后页签名同步
9. 页签胶囊高度下调
10. 单格显示全屏图标
11. 阅读空间卡片布局 + 更名"收藏" + 进度/时间右上
12. 既有测试失败（导出二级菜单重渲染）
13. 悬浮预览窗宽度收窄 + 底部按钮区重显三按钮
14. 新增状态栏、顶栏图标移入状态栏右侧
15. 导出 mdpkg 图标
16. 新建默认 .md
17. 双击页签名重命名
18. MD：全角斜杠/顿号转 ASCII；手柄滑入显菜单
19. MD 大纲按钮方形圆角 + 钉住底色
20. MD 标题折叠三角
21. MD 选区工具条（迁移 md-bundle）
22. 首页新建后进栏目页
23. MD/HTML 多步前进后退恢复
24. 手柄颜色/缩进/对齐复用 md-bundle
25. 选区范围调整（未选调整整块）
26. 工具条按 workbuddy 收敛

## Why（为什么）

用户真实使用后集中暴露的可用性与一致性问题：拖拽无反馈、沉浸态信息缺失、编辑态空白、撤销丢数据、图标语义混淆。散落热修会继续漂移，收成一个 change 逐片交付并配 e2e 探针，避免"自测全绿但用户看不到变化"。

## Scope（范围）

- 涉及表面：应用外壳（顶栏/状态栏/页签/分栏/沉浸）、PDF 预览、图标体系、Markdown 编辑器（含大纲/手柄/选区/历史）、阅读空间卡片、视频预览、HTML 可视化编辑。
- 8 条垂直切片，全部带浏览器可观测验收 + e2e 探针。
- 影响既有规格：`application-shell`（G-7 单格全屏、沉浸收纳、页签/状态栏职责）、`navigation`（图标体系）、`reading`（阅读空间卡片）。
- Rust 侧：PDF 缩略图可能需新增渲染路径（评估后定）。

## Non-goals（不做）

- 不改模式切换机制（不 remount EditorView）。
- 不引入第二套渲染管线或新图标库。
- 不做跨平台手势适配（按 macOS 环境验证）。
- 不重构编辑器架构；复用 md-bundle 能力按"迁移所需子集"，不整包引入。
- workbuddy 对齐仅限本 change 明列的两条工具条。
