# editor-surface-batch18 需求四要素

- spec issue: https://github.com/jianxi-dev/clairis/issues/805
- 输入源：用户 2026-11-14 反馈（文件菜单迁移 / 打印走预览态 / 图片文档无法滚到顶部）
- 复现文档：`/Users/mason/Desktop/中汽系统搭建情况对称1110.md`

## What（做什么）

1. 文件右键菜单接管「导出 / 刷新 / 打开文件位置」：导出在「复制路径」上方并就地展开全部二级项；打开文件位置在「复制路径」下方；刷新在「关闭」上方。
2. 格头 ⋯ 菜单移除上述三项；其余项与顺序不变。
3. 打印从导出二级项抽出，成为文件右键菜单里紧贴导出下方的独立项，并始终按 Markdown 预览态输出（正文版式一致、mermaid 为绘制后图形、无编辑器源码与应用外壳）。
4. 含图片的 Markdown 文档在预览中可滚动回文档顶部（第一行可见）。

## Why（为什么）

- 同一动作分散在两个菜单，右键「导出」是关闭后跳转的绕路，用户看到菜单闪跳。
- 打印当前直接打印 DOM：编辑态打出源码，mermaid 未绘制时打出空块，与屏幕预览不一致。
- 含大图裁剪的文档无法回到开头，直接影响可读性。

## Scope（范围）

- 菜单入口与二级承载、打印入口与打印视图、预览图片尺寸约束与滚动可达性。
- 相关 e2e 与必要单测。

## Non-goals（不做）

- 不改导出产物格式与导出管线。
- 不重排右键菜单里悬浮小窗/分栏/移动/关闭其他等既有项。
- 不改系统打印对话框能力（页眉页脚、纸张、双面）。
- 不做移动端/触屏布局。
