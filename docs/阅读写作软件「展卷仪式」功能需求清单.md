# 阅读写作软件「展卷仪式」功能需求清单

## 一、启动开屏前置仪式模块

### 视觉

1. 加载底色：宣纸米白 / 浅松烟灰 / 浅青笺 3 套低饱和底色，昼夜模式自动切换

2. 加载动画：宣纸纹理缓慢铺开，边缘毛边 \+ 淡墨晕流动，进度条为毛笔淡墨拖痕

3. 封面自定义：支持上传图片作为卷首封面，启动自动展示 3 秒

4. 入场载体二选一

    - 极简款：居中折叠虚拟笺纸

    - 国风款：半收式木轴卷轴

### 交互按钮

1. 核心操作按钮：【展卷提笔】/【拉开卷轴】，点击触发正式展卷动画

2. 跳过按钮：角落小型「快速进入」，一键跳过全部仪式动画

### 音效（默认音量 15%，可全局关闭）

1. 加载阶段：轻微宣纸翻动沙沙声、低频磨墨白噪音

## 二、核心展卷动画（标准时长 0\.8–1\.2s，三档速度可调：舒缓 / 标准 / 快速）

分层动画顺序

1. 卷轴 / 笺纸向两侧舒展，生成纸张褶皱、厚度阴影

2. 编辑 / 阅读区域淡入浮现，毛笔笔尖光标缓慢落下

3. 侧边栏、工具栏缓慢收缩淡出，推送红点、弹窗自动隐藏

4. 低透明度水印小字淡入：开卷有益 / 静书，不遮挡文字

### 光影配套

1. 日间模式：页面柔和漫射自然光

2. 夜间模式：暖黄烛光灯晕包裹页面，降低蓝光

### 自动专注联动

1. 展卷完成自动开启专注模式

2. 屏蔽软件内广告、活动推送、消息弹窗

3. 可选番茄专注计时：25/45/60 分钟

## 三、沉浸式听觉氛围模块

1. 展卷完成自动播放，支持定时关闭（15/30/60 分钟 / 永久）

2. 音效分类

    - 国风：翻纸声、细雨、松风、轻古琴、砚台滴水

    - 现代安静：咖啡馆白噪音、壁炉、持续雨声、低频静音

3. 界面微型静音图标，一键关闭全部环境音

## 四、写作专属展卷配套仪式

1. 光标样式替换：普通竖线→细毛笔笔尖，打字附带淡墨扩散微动画

2. 多笺纸模板：空白宣纸、方格稿纸、横线笔记本、古风信笺；切换模板触发小型二次展卷动画

3. 新建文档弹窗文案：铺开新卷，搭配轻展纸动画

4. 删除文档动画：纸张卷起收纳效果

## 五、阅读专属展卷配套仪式

1. 导入书籍 / 文档：模拟实体封面翻开，书页平铺展开动画

2. 静心读卷按钮：点击后全部 UI 控件半透明隐藏，仅保留文字

3. 添加书签交互：纸质书签飘落至书页侧边微动画

4. 滑动翻页：纸张弯曲光影效果，替代生硬平移滑动

## 六、个性化设置开关（全部可独立开启 / 关闭）

1. 总开关：启用 / 关闭整套开卷仪式

2. 动画设置：开关展卷动画、调节动画快慢档位

3. 音频设置：开关开卷音效、开关专注白噪音、统一音量调节

4. 自定义项：自定义启动封面、自定义卷首水印标语、设置默认笺纸、默认背景音

5. 专注模式开关：是否展卷后自动开启免打扰

## 七、设计避坑约束（开发 / UI 规范）

1. 特效禁止强光、频闪、高饱和鲜艳色块，全程低对比度慢节奏

2. 环境音采用间断自然音源，无高频刺耳循环音效

3. 所有仪式流程支持一键跳过，不强制等待，兼顾高效用户

4. 浅色 / 深色两套完整视觉素材，昼夜切换同步替换卷轴光影、纸张色调

5. 动画资源轻量化，不增加启动加载卡顿

1. 适用端：移动端 APP / PC 客户端通用
