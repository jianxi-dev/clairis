## 一、产品定义

### 1.1 产品名称
**渐明** (jiànmíng)

### 1.2 一句话定义
> 一款陪伴人类学习成长的智能伙伴——**懂你、减负、惊喜、上瘾**。

### 1.3 产品哲学

| 来源 | 来源 | 用途 |
|------|------|------|
| V3 设计原则 | 快、方便、舒服、喜欢 | **红线**：任何产品不可违反的底线 |
| V4 产品哲学 | 懂你、减负、惊喜、上瘾 | **方向**：MVP 后迭代的进化目标 |

### 1.4 目标用户

| V3（归档） | V4（新定义） |
|------------|-------------|
| 普通阅读者 70% | **学习者** 40% — 高效阅读、知识整理、记忆强化 |
| 轻度编辑者 20% | **写作者** 30% — 流畅输出、格式美化、灵感激发 |
| 技术用户 10% | **成长者** 20% — 反思记录、目标追踪、情绪梳理 |
| _(已归档)_ | **灵感寻求者** 10% — 创意激发、跨界连接、偶然发现 |

### 1.5 路线图摘要

```
MVP 软著版 (Phase M)        → 阅读 + 基础编辑 + 占位
MVP 发布版 (Phase R)        → Mac App Store 上架
P1 差异化版                 → 右侧 AI 对话 + 知识网络 + 灵感模式
P2 完整版                   → 个人成长系统 + 社区化探索
远 期                       → 团队化 / Windows / 更多语种
```

## 二、UI 与导航架构

### 2.1 核心决策（V4 为准）

| 决策 | V3 | V4 | 本文档裁定 |
|------|----|----|-----------|
| 左侧边栏 | ✅ 有三栏布局（左+中+右） | ❌ 取消 | **取消**。导航改为时间带 + 空间记忆 + 语义网络 |
| 右侧边栏 | ✅ 固定宽度 320px | ✅ 默认隐藏，需要时展开 | **默认隐藏**，展示 AI 对话/工具/时间带 |
| 正文分栏 | ✅ 内容+侧栏整体分栏 | ✅ 仅内容区分栏，侧栏独立 | **仅内容区分栏**（左右/上下），侧栏始终全高 |
| 工具栏 | ✅ 顶部固定 | ✅ 默认隐藏 hover 淡入 | **默认隐藏，触底反弹或 hover 淡入** |
| 命令面板 | ❌ 无 | ✅ Cmd/P 搜索 | **新增**（从 V4 引入） |

### 2.2 无左栏导航体系 — MVP 落地版

> 核心价值：**不暴露文件树，用户不管理文件位置，只管理"当前读/写什么"**

#### 空状态四件套

| 入口 | 触发条件 | UI 形式 | 包含内容 |
|------|----------|---------|----------|
| **启动面板** | 首次安装打开后 | 全屏空状态页 | 打开文件按钮、新建按钮、快捷键提示、3 个内置示例文件 |
| **空白空状态** | 关闭所有文档后回到空白 | 极简空状态 | 打开文件按钮 + 3 个最近编辑文件 |
| **命令面板** | Cmd/P | 浮动搜索框 | 搜索 + 动作 + 最近编辑 3 个 + 最近新增 3 个（下拉默认展示） |
| **双击文件** | 系统文件关联兜底 | 直接打开拖拽到窗口 | — |

#### 内置示例文件（3 个）

| 文件 | 内容 | 用途 |
|------|------|------|
| `0-欢迎.md` | 渐明产品介绍 + 快捷键说明 | 新用户引导 |
| `1-Markdown示例.md` | 覆盖 GFM 全部语法的样例 | 展示阅读渲染效果 |
| `2-HTML示例.html` | 包含 Tailwind CDN + 自定义 CSS 的复杂 HTML | 展示 HTML 预览能力 |

- 首次启动时自动释放到 `~/documents/jianming/` 目录
- 用户在文件管理器中看到的是普通文件，可编辑、可删除
- 仅在首次启动或目录被用户清空后重新释放

#### Cmd/P 命令面板布局

```
┌─────────────────────────────────────┐
│  > 搜索文件名或输入命令...           │
├─────────────────────────────────────┤
│  最近编辑                            │
│  📄 昨天写的文章.md      2分钟前     │
│  📄 工作汇报.html        1小时前     │
│  📄 README.md            3小时前     │
├─────────────────────────────────────┤
│  新增文件                            │
│  🆕 欢迎.md             今天         │
│  🆕 Markdown示例.md     今天         │
│  🆕 HTML示例.html       今天         │
├─────────────────────────────────────┤
│  动作                                │
│  📂 打开文件...                     │
│  ➕ 新建文档                        │
└─────────────────────────────────────┘
```

- 最近编辑区：按 mtime 倒序，取 zustand store 中记录的 3 个
- 新增文件区：按 ctime 倒序，扫描 `~/documents/jianming/` 目录取 3 个
- 若无历史/无新增，该区折叠不显示
- 输入字符后，上述两区隐藏，显示搜索结果

#### 远期导航（P1+）

| 导航方式 | 触发条件 | 行为 | 阶段 |
|----------|----------|------|------|
| 时间带 | 右侧栏展开 | 最近文件历史 + 写作时间线 | P1 |
| 知识网络 | 右侧栏展开 | 跨文档语义漫游 | P1 |
| Desk 空间记忆 | Desk 模式切换 | 桌面隐喻位置导航 | P2 |

#### 空状态设计规则

| 规则 | 含义 |
|------|------|
| **空白但不空旷** | 不是"暂无内容"，而是一个温暖的入口，告诉用户"可以用这里做什么" |
| **一键可达** | 任何功能 ≤2 次点击能完成 |
| **历史是灵魂** | 3 个最近编辑文件让用户"回来就能继续" |
| **快捷键提示** | 空状态底部一行提示 Cmd/O 打开、Cmd/P 搜索、Cmd/N 新建 |

### 2.3 正文区分栏（递归分栏）

#### MVP 布局

```
┌───────────────────────────────────┬─────────┐
│                                   │ Right   │
│   Content Area                    │ Sidebar │
│   (单栏, 默认)                     │ (默认   │
│                                   │  隐藏)  │
└───────────────────────────────────┴─────────┘
```

#### 正文分栏模式（Content Area 内）

```
双栏 (左右)                  双栏 (上下)
┌──────────┬──────────┐      ┌──────────────┐
│ 分栏 A   │ 分栏 B   │      │    分栏 A     │
│ (独立    │ (独立    │      ├──────────────┤
│  滚轮)   │  滚轮)   │      │    分栏 B     │
└──────────┴──────────┘      └──────────────┘
```

#### 递归分栏（MVP 数据结构支持，P2 UI）

分栏内的每个栏目还可以继续分栏，实现 3 栏、4 栏或更多：

```
┌──────────┬──────────┐
│ 分栏 A   │ 分栏 B   │
│ (文档1)  ├──────────┤
│          │ 分栏 C   │
│          │ (文档2)  │
└──────────┴──────────┘

┌──────────┬──────────┐
│ 分栏 A   │ 分栏 B   │
│ (文档1)  │ (文档2)  │
├──────────┼──────────┤
│ 分栏 C   │ 分栏 D   │
│ (文档3)  │ (知识网络)│
└──────────┴──────────┘
```

- 每个分栏有独立的文档、主题、渲染模式
- MVP 阶段 UI 仅支持双栏切换
- P1 起支持递归分栏 UI（双击分栏边缘继续拆分）
