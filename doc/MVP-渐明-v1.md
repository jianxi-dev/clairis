# 渐明 MVP — 最小可行性产品定义
> **版本:** v1.0 整合版
> **创建:** 2026-07-05
> **基线:** V3 基础功能（设计原则 + 非功能需求）为最低标准，矛盾时以 V4 为准
> **目标:** 先满足阅读 → 申请软著 + 占位 → 再扩展编辑和成长功能

---

## 一、产品总纲

### 1.1 产品名称
**渐明** (jiànmíng)

### 1.2 一句话定义
> 一款陪伴人类学习成长的智能伙伴。

### 1.3 进化路径
```
V3 Folio        →  轻量 Markdown/HTML 阅读编辑器（工具）
    ↓
    转型：从"工具"到"伙伴"
    ↓
V4 渐明         →  智能成长伙伴（陪伴 + 成长）
    ↓
    MVP 切出：先阅读，再编辑，终智能
    ↓
MVP 渐明        →  沉浸阅读器 + 基础编辑（先发布）
```

### 1.4 功能继承规则
| V3 内容               | 处理方式                   |
| ------------------- | ---------------------- |
| 设计原则（快/方便/舒服/喜欢）    | **保留** — 基础标准          |
| 核心阅读体验              | **保留且加强** — MVP 核心     |
| 非功能需求（性能/安全/可访问/测试） | **保留** — 最低基线          |
| 多栏布局                | **修改** → V4 无左栏，仅内容区分栏 |
| 左侧边栏 + 文件树          | **取消** → V4 决策记录中已否决   |
| 盈利模式（买断制）           | **修改** → 订阅制（见下文）      |

### 1.5 V3 有矛盾时以 V4 为准的功能
| 功能 | V3 决策 | V4 决策 | MVP 处理 |
|------|---------|---------|----------|
| 左侧边栏 | ✅ 三栏布局（左栏浏览+右栏AI） | ❌ 取消，功能收入右侧边栏 | V4 为准：无左栏 |
| 导航模式 | 文件树 + 最近文件 | 时间带 + 知识网络 + 空间记忆 | MVP 暂用最近文件（右键栏），知识网络 P1 |
| 盈利模式 | Freemium 一次买断 $14.99 | 未覆盖 | 用户定义：年费订阅制 |
| 编辑器默认模式 | L2 WYSIWYG（语法可视化） | V4 不默认，纯阅读优先 | MVP 优先阅读渲染，编辑模式可选 |
| i18n 默认 | 中文 | 中文（V4 确认） | 中文 |

## 二、产品哲学与设计原则

### 2.1 V3 版原则（MVP 红线，必须满足）
| 原则 | 含义 | 评审检查 |
|------|------|----------|
| **快** ⚡ | 启动 <1s，操作零等待，滚动 60fps | 用户感到等待了吗？100ms 内反馈？ |
| **方便** 🖐️ | 高频操作快捷键 ≥80%，少点鼠标 | 能否不碰鼠标完成？单手键盘走通主流程？ |
| **舒服** 😌 | 排版克制，动画平滑，无信息过载 | 截图给朋友看是否自豪？去掉元素是否更好？ |
| **喜欢** ❤️ | 细节有惊喜感，超出预期 | 用户想主动打开吗？有 wow 效果吗？ |

### 2.2 V4 版原则（MVP 参考，P1 逐步实现）
| 原则 | 含义 | 何时落地 |
|------|------|----------|
| **懂你** 🧠 | 主动理解意图，预判需求 | P1+（角色自适应、AI 建议） |
| **减负** 🪶 | 减少决策，自动整理 | P1+（AI 整理、智能分类） |
| **惊喜** ✨ | 超出预期，带来 Wow 瞬间 | P1+（灵感模式、关联发现） |
| **上瘾** 🌀 | 使用后满足，不用时想念 | P2（习惯养成、成长曲线） |

## 三、MVP 功能定义（必须实现）

### 3.1 核心阅读体验（P0 — MVP 主战场）

| 需求 | 描述 | 验收标准 |
|------|------|----------|
| **冷启动秒开** | 双击 markdown 文件后 <1.5s 看到内容可读 | 冷启动到可交互 <1.0s |
| **完整 GFM 渲染** | 标准 GFM 全语法支持 | 标题/列表/代码块/表格/链接/图片/粗斜体/任务/分割线/引用 |
| **HTML 预览** | 安全沙箱内嵌显示 | iframe srcdoc + CSP `script-src: 'none'` + sandbox |
| **纯文本支持** | .md .html .txt 三种格式 | 各自以正确模式打开和渲染 |
| **沉浸阅读** | 隐藏所有工具栏和面板 | Esc/按钮一键进入，动画过渡 |
| **字号缩放** | Cmd+= / Cmd+- 实时调整 | 12-32px，步进 1px，持久化 |
| **Dark/Light 主题** | 自动跟随系统 + 手动切换 | 两套完整配色，切换顺滑 |
| **滚动顺滑** | 60fps 无卡顿 | >500KB 文件流畅滚动 |
| **阅读进度** | 实时显示阅读进度 | 滚动条或进度指示器 |

### 3.2 导航体系 — 无左栏方案（V4 落地）

> 核心价值：**不暴露文件树，用户不管理文件位置，只管理"当前读/写什么"**

#### 空状态四件套

| 入口 | 触发条件 | UI 形式 | 包含内容 |
|------|----------|---------|----------|
| **启动面板** | 首次安装打开后 | 全屏空状态页 | 打开文件按钮、新建按钮、快捷键提示、3 个内置示例文件 |
| **空白空状态** | 关闭所有文档后回到空白 | 极简空状态 | 打开文件按钮 + 3 个最近编辑文件 |
| **命令面板** | Cmd/P | 浮动搜索框 | 搜索 + 动作 + 最近编辑 3 个 + 最近新增 3 个（下拉默认展示） |
| **双击文件** | 系统文件关联兜底 | 直接打开拖拽到窗口 | — |

#### 内置示例文件（3 个）

| 文件 | 内容 | 用途 |
|------|------|------|
| `0-欢迎.md` | 渐明产品介绍 + 快捷键说明 | 新用户引导 |
| `1-Markdown示例.md` | 覆盖 GFM 全部语法的样例 | 展示阅读渲染效果 |
| `2-HTML示例.html` | 包含 Tailwind CDN + 自定义 CSS 的复杂 HTML | 展示 HTML 预览能力 |

- 首次启动时自动释放到 `~/documents/jianming/` 目录
- 用户在文件管理器中看到的是普通文件，可编辑、可删除
- 仅在首次启动或目录被用户清空后重新释放

#### Cmd/P 命令面板布局

```
┌─────────────────────────────────────┐
│  > 搜索文件名或输入命令...           │
├─────────────────────────────────────┤
│  最近编辑                            │
│  📄 昨天写的文章.md      2分钟前     │
│  📄 工作汇报.html        1小时前     │
│  📄 README.md            3小时前     │
├─────────────────────────────────────┤
│  新增文件                            │
│  🆕 欢迎.md             今天         │
│  🆕 Markdown示例.md     今天         │
│  🆕 HTML示例.html       今天         │
├─────────────────────────────────────┤
│  动作                                │
│  📂 打开文件...                     │
│  ➕ 新建文档                        │
└─────────────────────────────────────┘
```

- 最近编辑区：按 mtime 倒序，取 zustand store 中记录的 3 个
- 新增文件区：按 ctime 倒序，扫描 `~/documents/jianming/` 目录取 3 个
- 若无历史/无新增，该区折叠不显示
- 输入字符后，上述两区隐藏，显示搜索结果

#### 空状态设计规则

| 规则 | 含义 |
|------|------|
| **空白但不空旷** | 不是"暂无内容"，而是一个温暖的入口，告诉用户"可以用这里做什么" |
| **一键可达** | 任何功能 ≤2 次点击能完成 |
| **历史是灵魂** | 3 个最近编辑文件让用户"回来就能继续" |
| **快捷键提示** | 空状态底部一行提示 Cmd/O 打开、Cmd/P 搜索、Cmd/N 新建 |


### 3.3 文件管理基础（P0）

### 3.4 基础编辑能力（P0）

### 3.4 HTML 文件支持（MVP 更新 — 2026-07-05）

#### 基准文件
```
/Users/mason/Desktop/AI工具分享/安全管理智能顾问/readme-安全管理领域智能顾问Skill.html
```

#### 依赖分析
| 依赖 | 来源 | 作用 |
|------|------|------|
| Tailwind CDN | `cdn.tailwindcss.com` | 运行时编译 Tailwind class → CSS |
| Google Fonts | `fonts.googleapis.com`, `fonts.gstatic.com` | 加载 Inter + Noto Sans SC + Noto Serif SC + JetBrains Mono |
| 自定义 CSS | `<style>` 块内嵌 | `.glass` / `.text-gradient` / `.noise-bg` / 动画 等 |
| SVG 内联 | 内嵌 data URI | 图标、装饰形状 |

#### 实现方案：方案 A — 放宽 iframe CSP

| 配置项 | 改前（V3） | 改后（MVP） |
|--------|-----------|------------|
| script-src | `'none'` | `https://cdn.tailwindcss.com https://cdn.jsdelivr.net` |
| default-src | `'self' 'unsafe-inline'` | 加 `https:` 通配 |
| font-src | `'self'` | 加 `https://fonts.googleapis.com https://fonts.gstatic.com` |
| sandbox | `allow-same-origin allow-popups` | 保持不变 |

#### 风险说明
- **网络依赖**：Google Fonts 在国内访问不稳定
- **CDN 可用性**：依赖 Tailwind 官方 CDN 持续可用
- **安全代价**：沙箱不再完全隔离外部资源，但信任用户主动打开的本地 HTML 文件模型不变

#### 验收标准
| 场景 | 验收 |
|------|------|
| Tailwind CDN HTML | 含 `.glass` `.text-gradient` 等 class 的文件完整显示 |
| Google Fonts | 字体加载完成 |
| 自定义 CSS | 内嵌 `<style>` 块正常生效 |
| 内嵌 SVG | 装饰形状、图标正常显示 |

#### 被搁置的实现（记录至 09-html-exploration.md）
- Tailwind 运行时 WASM 沙箱（替代 CDN 方案）
- 属性级可视化编辑面板
- 移动节点保存回写
- 源码 + 预览实时同步编辑模式

| 需求 | 描述 | 备注 |
|------|------|------|
| **无左侧边栏** | 取消 V3 的左侧栏 | V4 决策：少即是多 |
| **右侧边栏** | 默认隐藏，快捷键触发 | 未来放 AI 对话/工具/时间带 |
| **工具栏** | 默认隐藏，鼠标移入顶部时淡入 | 极简优雅 |
| **正文单栏** | 中间区域默认单栏文档 | MVP 默认 |
| **正文分栏（可选）** | 左右 + 上下分栏，独立滚轮 | P0 支持，默认隐藏 |

## 五、非功能需求（V3 红线，必须满足，与 V4 无矛盾）

### 5.1 性能指标
| 度量 | 目标 |
|------|------|
| 冷启动到可交互 | <1.0s |
| 文件打开 | <300ms (50KB .md) |
| 编辑响应 | <16ms (60fps) |
| 模式切换 | <100ms |
| 内存占用 | <200MB (正常文档)，<500MB (大文件) |
| 包体积 | <50MB (DMG) |
| 离线可用 | 核心功能完全离线 |

### 5.2 可访问性 (a11y)
| 需求 | 验收标准 |
|------|----------|
| 屏幕阅读器 | macOS VoiceOver 可完整朗读 |
| 键盘导航 | Tab + 快捷键全流程 |
| 颜色对比度 | WCAG AA（正文:背景 ≥ 4.5:1） |
| 字号缩放 | 支持 200% 无溢出 |
| 减少动画 | 遵循 prefers-reduced-motion |

### 5.3 安全性
| 需求 | 方案 |
|------|------|
| 不托管用户数据 | 纯本地，无 telemetry |
| API Key 存储 | OS keyring（无 Core Data Storage） |
| HTML 沙箱 | srcdoc + CSP + sandbox 三道防线 |
| 翻译隐私 | OpenAI 翻译前用户明示同意 |

### 5.4 测试标准
| 类型 | 覆盖范围 |
|------|----------|
| 单元测试 | 工具函数、store 逻辑。覆盖率 ≥80% |
| 组件测试 | 阅读区、编辑器、文件对话框渲染与交互 |
| 集成测试 | Rust 命令、文件 I/O、路径重写 |
| E2E 测试 | 打开→阅读→基础编辑→保存→重开 |

## 六、商业模式（用户定义版）

### 6.1 版本分层
| 版本 | 定价策略 | 功能范围 |
|------|----------|----------|
| **免费版** | ¥0 | 完整阅读体验（GFM/HTML/TXT 渲染、字号缩放、双主题、拖拽打开、自动保存） |
| **专业版** | ¥/年（待定） | 免费版 + 基础编辑 + 分栏 + 设置自定义 + 代码高亮 + 多格式导出（docx/HTML） |
| **高级版** | ¥/年（待定） | 专业版 + AI 润色 + 翻译 + 角色自适应 + 知识网络 + 情绪陪伴 + 成长报告 |

### 6.2 订阅制设计原则
- **先免费**：让用户先用，<strong>无时间限制</strong>的免费版 = 软著申请 + 占位的最佳策略
- **升级触发点**：用户想要编辑、导出、AI 功能时跳转到订阅
- **年费优于月费**：与 V3 买断逻辑不同，减轻用户付费压力，提高续费率
- **macOS 先上架**：mac App Store + 官网双渠道

### 6.3 首年目标
| 指标 | 保守值 | 目标值 |
|------|--------|--------|
| 总下载/安装 | 500 | 2,000 |
| 付费转化率 | 2% | 5% |
| 首年付费用户 | 10 | 100 |
| 首年收入 | ¥1,000 | ¥10,000 |
| 核心目标 | 软著 APP 名称占位 + 用户反馈收集 | — |
