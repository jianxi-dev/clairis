# Folio 颠覆式设计概念 v3 — 让用户爱上写作

> 这不是迭代，是重新定义"编辑器"是什么。
> 目标是：用户每天打开 Folio 不是因为"需要"，而是因为"想"。

---

## 核心理念：编辑器 = 第三空间

编辑器不是工具，是空间。
- 咖啡馆是第三空间（不是家也不是公司）
- Folio 是"你的写作空间"——让你想待在里面

---

## 概念一："帷幕" — 内容至上的空间化设计

### 视觉
整个应用像一个剧院。工具栏是"帷幕"——平时收起在屏幕顶部（12px 细线），鼠标靠近或 Cmd+Option 才优雅降下。内容永远占据 95% 的屏幕。

``` 
┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐  ← 帷幕(收起:2px线)
│                                              │
│                                              │
│          你的文字在呼吸                        │
│          ───────────────                      │
│          文字是舞台上的演员                     │
│          编辑器是剧院                           │
│                                              │
│                              ┌──────────┐    │
│                              │ 大纲浮卡   │    │  ← 半透明，触边自动隐藏
│                              │ (蓝牙式)   │    │
│                              └──────────┘    │
│                                              │
└──────────────────────────────────────────────┘
     ↙ 文件墙 (drag to reveal)
```

### 创新操作
- **文件墙** — 从左侧边缘拖入，不是"点开侧栏"。拖入后看到的是 Pinterest 风格的文档卡片墙（不是列表）。卡片显示：标题 + 首句 + 写作时长 + 情绪色彩标记
- **内容即导航** — 不是"先选文件再编辑"，而是"看到什么就能编辑什么"。预览区直接点击即可编辑（无缝模式切换）
- **智能分组** — 同主题文档自动聚类成"堆"，堆有轻微浮动动画。堆叠的文档像桌上的一叠纸

### 用户黏性设计
- **写作温度** — 每篇文档右下角有微弱的温度指示（🔥 写作热度）：基于写作频率、时长、字数综合计算
- **空间记忆** — 每次打开 Folio 回到你上次离开时的精确位置（光标位置、滚动位置、打开的侧栏状态、分栏比例），像没离开过

## 概念二："液态工具栏" — 工具栏不存在

### 核心思路
传统工具栏是"固定在顶部的按钮行"。液态工具栏是：**工具出现在你需要的地方，用完即走。**

### 实现
- **选择文本 → 工具浮现** — 选中文字后，工具直接在选中文字旁边浮现（类似 Apple 备忘录的弹出工具条）。格式、引用、代码块等选项以一个微型弧形菜单绕在光标周围
- **打字时 → 工具栏消失** — 当你连续输入超过 3 秒，所有 chrome 元素逐渐淡出。只有文字和光标
- **暂停时 → 工具栏呼吸性重现** — 停下思考时（>2 秒无输入），工具栏以极低透明度（0.15）浮现，仅显示最常用的 3 个操作
- **Cmd+K → 一切** — 所有操作通过命令面板完成，面板有模糊搜索+最近使用+智能推荐

```
          ┌──┐
       ┌──│B │──┐
       │  └──┘  │
    ┌──┤        ├──┐
    │I│  ◉ 文字  │H1│  ← 选中文字后，工具围绕文字
    └──┤        ├──┘
       │  ┌──┐  │
       └──│🔗│──┘
          └──┘
```

### 用户黏性设计
- **"没工具栏"的轻盈感** — 用户打开 Folio 的第一感觉是"干净"，不是"又一个编辑器"
- **学习成本≈零** — 选中→格式化，和直觉完全一致
- **Pro 用户快捷键叠加** — 所有操作都有快捷键，Cmd+K 可搜索一切

## 概念三："写作流" — 编辑器有情绪

### 核心思路
编辑器感知你的写作状态，并做出情绪化响应。不是"功能"，是"陪伴"。

### 状态感知
- **心流检测** — 连续输入 >5 分钟 + 无 UI 操作 → 进入 "Flow Mode"
  - 所有 chrome 淡出到 opacity: 0.03
  - 光标变为温和的呼吸光晕（不是硬闪烁）
  - 底部出现极简的 flow timer（你已经写了 23 分钟）
  - 任何鼠标移动 + 按 Esc 退出 flow
  
- **写作疲惫检测** — 删除量 > 输入量 × 3 → 进入 "Pause Mode"
  - 编辑器背景缓缓转为暖色调
  - 显示一句随机写作鼓励（"有时候最好的文字来自休息后"）
  - 建议"站起来走走"的微提醒（非侵入式，5px 文字）

- **清晨/深夜感知** — 检测当前时间
  - 清晨 (6-9am): 温暖的晨光色主题，低对比度，温和
  - 深夜 (0-5am): 深色模式 + 蓝光减少 + 亮度降低 + "夜深了"温柔提醒
  - 写作高峰期自动进入 focus 模式

### 视觉反馈
- **打字涟漪** — 每个字符落下时，有一个极其微弱的涟漪扩散（类似水滴入水），仅 200ms，opacity 0.03—0.08。肉眼几乎不可见，但大脑能感知到"活着"的编辑体验
- **行呼吸** — 当前编辑的行有极其微弱的背景色变化（从透明到 0.02 opacity），缓慢呼吸。光标停留越久，呼吸越明显
- **段落心跳** — 每个写完的段落完成后，段尾有一个微弱的脉动"完成"动画（像心跳一次），仅 300ms

## 概念四："氛围引擎" — 主题是空间，不是颜色

### 核心理念
传统主题 = 颜色配置。氛围引擎 = 完整的感官体验。

### 内置氛围

| 氛围 | 视觉 | 动画 | 适合场景 | 用户感受 |
|------|------|------|---------|---------|
| **破晓** ☀️ | 暖金色渐变，柔和阴影，纸张纹理 | 缓慢光影移动（模拟日出） | 早晨写作 | "新的一天" |
| **专注** 🎯 | 冷灰蓝，高对比度，锐利边界 | 极简，仅光标呼吸 | 深度工作 | "进入状态" |
| ** cozy ** 🕯️ | 琥珀暖光，柔焦，纸质感 | 烛光般摇曳阴影 | 晚间日记 | "温暖陪伴" |
| **霓虹** 🌃 | 深色底 + 霓虹高亮（indigo/粉/青） | 动态光晕漂移 | 深夜编码 | "赛博朋克" |
| **雨日** 🌧️ | 低饱和蓝灰，柔和，安静 | 极缓慢的雨纹（仅背景 0.02 opacity） | 雨天写作 | "宁静" |
| **复古** 📜 | 米黄纸 + 棕墨，行间距宽，衬线字体 | 页面微微泛黄动画 | 长文写作 | "像在写书" |

### 用户黏性设计
- **氛围记忆** — 编辑器记住你每个时间段偏好的氛围：早上自动破晓，深夜自动 cozy
- **氛围过渡动画** — 切换氛围不是瞬间变化，而是 2-3 秒的平滑过渡（颜色渐变 + 动画形态渐变）
- **每日推荐氛围** — 根据天气/季节/写作内容，每天轻微推荐不同氛围（非强制，右下角小提示）

## 概念五："告别" — 结束也是体验

### 核心思路
大多数应用的关闭就是"啪"没了。Folio 的关闭是体验的一部分。

### "再见"屏幕
关闭应用时（非崩溃），显示 2 秒的告别画面：
```
╔══════════════════════════════════╗
║                                  ║
║  今天写了 1,247 字               ║
║  最佳时段：下午 2-3 点            ║
║  连续写作：12 天 🔥              ║
║                                  ║
║  明天见，mason ✋                 ║
║                                  ║
╚══════════════════════════════════╝

(2秒后自动关闭，或点击任意位置跳过)
```

### 黏性心理
- **结束时的正反馈** — 用户离开时带着成就感而非"终于关掉了"
- **期待明天** — "明天见"不是客套，是心理暗示
- **写作 streak** — 连续写作天数，像 GitHub 贡献图一样的连续记录，让人不想断

## 概念六："智能编织" — 文件是活的

### 核心思路
文件不是静态的 .md 文件。它们是活的、连接的、生长的。

### 特性
- **自动反向链接** — 当你在文档 B 中引用"项目路线图"，编辑器自动在"项目路线图.md"中创建反向链接条目。不需要用户做任何操作
- **智能标签** — 不是手动加标签。编辑器分析内容后自动建议标签（"这篇看起来像会议记录，要我标记为 #meeting 吗？"）
- **写作 DNA** — 每个用户有"写作 DNA"（用词习惯、常用句式、标点风格）。编辑器可以识别并给出个性化建议（"你最近用了很多'然而'，试试'不过'？"）
- **内容快照** — 自动保存每 5 分钟的版本。用户可以像 Time Machine 一样"回到 15 分钟前"（不是 Git 式的复杂操作，是一键时光回溯）

### 视觉化
```
┌──────────────────────────────────┐
│  # 项目路线图                      │
│                                  │
│  ## Q1 目标                       │
│                                  │
│  ...内容...                        │
│                                  │
│ ── 反向链接 ────────────────────  │
│  ← 周会记录.md 提到了此文档        │  ← 自动生成，在文档底部
│  ← 产品规划 Q2.md 引用了此文档     │
│                                  │
│ ── 相关内容 ────────────────────  │
│  📄 技术架构.md  ·  📄 设计稿.md   │  ← AI 推荐
│                                  │
└──────────────────────────────────┘
```
