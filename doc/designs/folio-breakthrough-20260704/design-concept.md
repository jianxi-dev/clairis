# 渐明 · 无侧栏桌面 — 突破设计概念

> 三组颠覆式方案，接续 v3 设计概念
> 目标：让"没有文件树"不是缺憾，而是「渐明」最让人上瘾的理由

---

## 概念 A：「灵境」— 空间文档门户

**核心想法：** 侧栏不存在。导航是"进入另一个空间"。

打开渐明 = 全屏文档。想换文件 → 向左滑动或 Cmd+K → 整个场景平滑向左推移，从左侧滑入一个"空间"——文档像浮动岛屿排列在景深空间中。选中文档 → 空间向右滑出，文档占据全屏。

**关键交互：**
- 无工具栏、无侧栏、无 chrome
- 文档阅读/编辑占据 100% 屏幕
- 从左侧边缘拖入 → 空间门户滑入，当前文档缩小退到右侧成为"背景"
- 门户中文档按语义/时间自动排列，带景深和浮动动画
- 搜索时门户进入"聚焦模式"——非匹配文档淡出，匹配文档放大

**为什么突破：**
- 导航不是 UI 组件，是"转场"——你在空间和信息之间穿梭
- 文件管理变成电影级过渡体验
- 用户感受："它不是编辑器，是一个可以走进去的空间"

---

## 概念 B：「心流桌面」— 没有文件概念

**核心想法：** 没有"文件"概念。只有"正在写"和"写过"。

打开渐明 = 一个空白行，光标闪烁。没有最近文件、没有列表。你直接开始写。所有写过的内容按"片段时间轴"自动归档——就像写日记。

**关键交互：**
- 打开就是一张白纸，光标在第一行
- 写完后关闭 → 自动保存，按时间归档
- "回看"模式：从右向左滑动 → 过去的时间片像胶片一样展开
- 时间片按日/周/月分组，每个时间片显示你当时写的内容片段
- 你在"时间"里找文档，不是在"文件夹"里找

**为什么突破：**
- 彻底消除"文件管理"这个心智负担
- 写作感觉像发微博一样自然
- 找回旧内容像翻日记一样有温度
- 最难的是让用户接受"没有文件"的 paradigm shift

---

## 概念 C：「星丛」— 关联优先于位置

**核心想法：** 文件不按位置组织，按"关系"组织。你的文档是一张不断生长的知识网络。

打开渐明 = 看到的是以当前正在写的文档为中心的星丛。关联文档作为卫星环绕。没有层级、没有目录、没有路径。只有连接。

**关键交互：**
- 当前文档居中，关联文档围绕排列
- 关联度 = 距离 + 连线透明度
- 拖拽文档到中心 → 成为新的焦点
- 从中心向外拖 → 建立关联
- 搜索时星丛"重组"——匹配的文档聚拢
- 两根手指/滚轮缩放 → 看到更大范围的网络
- 长时间未打开的文档"暗下去"但从不消失

**为什么突破：**
- 人的思维是网络的，不是树状的
- 关联优先于位置——你在"项目"里找文件，不是在"文件夹"里找
- 每次打开星丛都不同——文档关系随时间演变
- 星丛本身就是"你到底在想什么"的可视化

## 对比

| 维度 | A · 灵境 | B · 心流桌面 | C · 星丛 |
|------|----------|------------|---------|
| **学习成本** | 中 | 最高 | 中高 |
| **视觉惊艳度** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| **情感温度** | 空间感 | 日记感 | 思维感 |
| **实现难度** | 中 | 低 | 高 |
| **最像谁** | Vision Pro 空间 | iA Writer | Obsidian Graph |
| **差异化** | 电影级转场 | 零文件概念 | 活的思维网络 |
| **风险** | 太花哨 | 用户没安全感 | 太抽象 |

## 推荐优先实施

**概念 A · 灵境** — 在"惊艳"和"可用"之间最佳平衡。视觉冲击最强。适合先做原型验证。
