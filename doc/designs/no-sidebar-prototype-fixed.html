无侧栏设计方案.md · 今天 · 2小时前

侧栏的真正功能不是文件管理 — 是安全感。

"你的文件还在，你没丢东西。"

去掉侧栏不能只做减法。必须提供等价的安心感，用全新的方式。

 

推翻的假设：

  · 旧：用户需要"找到"文件 → 新：文件应该来找用户

  · 旧：文件管理 = 层级组织 → 新：文件管理 = 空间记忆 + 认知共鸣

  · 旧：导航 = 视觉扫描列表 → 新：导航 = 召唤 + 场所 + 仪式

  · 旧：打开文件 = 工具操作 → 新：打开文件 = 标志性愉悦
